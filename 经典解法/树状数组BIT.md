# 树状数组 (Fenwick Tree / Binary Indexed Tree)

## 概述

树状数组是一种用于**高效维护前缀和**的数据结构，支持 O(log n) 的**单点更新**和**前缀和查询**。

**核心思想**：利用整数的二进制表示，将区间拆分为"二进制块"，每个块的大小为 2 的幂次。

**时间复杂度**：
- 单点更新：O(log n)
- 前缀查询：O(log n)
- 建树：O(n log n)（逐点插入）或 O(n)（线性建树）

**适用场景**：需要动态维护前缀和的场景，如：
- 动态频率统计（权值树状数组）
- 逆序对计数
- 区间和查询（差分树状数组）

---

## 与线段树的对比

| 特性 | 树状数组 | 线段树 |
|------|:--------:|:------:|
| 代码量 | 极少（~10 行） | 较多（~50 行） |
| 常数 | 极小（位运算） | 较大（递归） |
| 前缀和 | O(log n) | O(log n) |
| 区间和 | O(log n)（差分） | O(log n) |
| 区间最值 | ❌ 不支持 | O(log n) |
| 区间更新+懒标记 | ❌ 有限支持 | O(log n) |
| 空间 | O(n) | O(4n) |
| 理解难度 | 需理解 lowbit 二进制拆分 | 直观的二叉树分割 |

**结论**：能用树状数组的地方尽量用树状数组（代码短、常数小），但树状数组只适用于**前缀可合并**的运算（加法、乘法、异或），无法处理区间最值、区间赋值等场景。

## 核心定义

### lowbit 函数

```java
int lowbit(int x) {
    return x & -x;
}
```

**含义**：返回 `x` 的二进制中最低位的 1 所对应的值（即 2^k）。

**示例**：

| x (十进制) | x (二进制) | -x (二进制) | lowbit(x) |
|:----------:|:----------:|:-----------:|:---------:|
| 1 | 0001 | 1111 | 0001 (1) |
| 2 | 0010 | 1110 | 0010 (2) |
| 3 | 0011 | 1101 | 0001 (1) |
| 4 | 0100 | 1100 | 0100 (4) |
| 6 | 0110 | 1010 | 0010 (2) |
| 8 | 1000 | 1000 | 1000 (8) |

### tree 数组的含义（极其关键）

`tree[x]` 并不是存单点值，而是存一个**区间和**：

```
tree[x] = sum(nums[x - lowbit(x) + 1 ... x])
```

即：每个节点管理一个**以 x 结尾**的区间，区间长度恰好为 `lowbit(x)`。

**举例**（n=8 时）：

| x | lowbit(x) | 管理区间 | 区间长度 |
|:-:|:---------:|:--------:|:--------:|
| 1 | 1 | [1,1] | 1 |
| 2 | 2 | [1,2] | 2 |
| 3 | 1 | [3,3] | 1 |
| 4 | 4 | [1,4] | 4 |
| 5 | 1 | [5,5] | 1 |
| 6 | 2 | [5,6] | 2 |
| 7 | 1 | [7,7] | 1 |
| 8 | 8 | [1,8] | 8 |

## 核心操作

### 1. 前缀和查询 (query)

```java
int query(int x) {
    int sum = 0;
    while (x > 0) {
        sum += tree[x];
        x -= lowbit(x);
    }
    return sum;
}
```

**正确性证明**：

定义：
```
x0 = x
x1 = x0 - lowbit(x0)
x2 = x1 - lowbit(x1)
...
xm = 0
```

每一步对应区间：
```
Ii = [xi - lowbit(xi) + 1, xi]
```

**不重叠**：因为 `xi+1 = xi - lowbit(xi)`，所以 `Ii+1` 的右端点 `xi+1` 恰好等于 `Ii` 的左端点减 1，区间严格相邻。

**不遗漏**：区间总长度 `Σ lowbit(xi) = x`（二进制展开和），完整覆盖 `[1, x]`。

**本质理解**：`query(x)` 实际上在将 `x` 按二进制展开：
```
x = Σ (2^k)   （二进制展开）
```
每个 `lowbit(xi)` 对应一个 `2^k`，把 `[1, x]` 按二进制块拆分。

**示例**（x=13）：

```
x = 13 = 1101
拆分过程：
  13 → lowbit(13)=1   → [13,13]   (1)
  12 → lowbit(12)=4   → [9,12]    (4)
  8  → lowbit(8)=8    → [1,8]     (8)
```

这三个区间不重叠且完整覆盖 [1,13]。

### 2. 单点更新 (add)

```java
void add(int x, int delta) {
    while (x <= n) {
        tree[x] += delta;
        x += lowbit(x);
    }
}
```

**目标**：将位置 `x` 的变化更新到所有**包含位置 x** 的区间节点中。

**为什么 x += lowbit(x) 能找到父节点？**

因为覆盖位置 x 的节点 tree[i] 必须满足：
```
i - lowbit(i) + 1 ≤ x ≤ i
```

每执行一次 `x += lowbit(x)`，就跳到覆盖范围更大的下一个节点（父节点），相当于在一棵隐式树中从叶子不断向上更新祖先节点。

**示例**（更新位置 3）：

```
x=3, lowbit(3)=1  → tree[3] += delta, x=4
x=4, lowbit(4)=4  → tree[4] += delta, x=8
x=8, lowbit(8)=8  → tree[8] += delta, x=16
```

更新了 3, 4, 8 三个节点，它们都包含位置 3 在其管理区间中。

### 3. 区间和查询（利用差分思想）

树状数组只能直接求前缀和，区间和可以通过两次前缀和求得：
```
sum[l, r] = query(r) - query(l - 1)
```

### 4. 区间更新 + 单点查询（差分树状数组）

维护差分数组 `diff`，用树状数组维护 `diff` 的前缀和：
- 区间更新 [l, r] + delta：`add(l, delta)` + `add(r+1, -delta)`
- 单点查询位置 x：`query(x)`

### 5. 区间更新 + 区间查询（结合数学）

需要两个树状数组：
- `tree1` 维护 `diff[i]`
- `tree2` 维护 `i * diff[i]`

```
sum[l, r] = (r+1) * query1(r) - query2(r) - [l * query1(l-1) - query2(l-1)]
```

## 树状数组与"树"结构的关系

### 隐式树结构

`tree[x]` 的区间长度为 `lowbit(x) = 2^k`，所有区间长度都是 2 的幂。区间之间的包含关系形成一个层级结构。

**关键观察**：
- 如果 `y = x + lowbit(x)`，则 `tree[x]` 的区间被 `tree[y]` 的区间完全包含
- 如果两个区间有交集，则其中一个必然包含另一个
- 这个包含关系构成了一棵隐式树，叶子节点对应奇数位置（lowbit=1）

**示例**（n=8 时的树结构）：

```
tree[8]: [1,8]
├── tree[4]: [1,4]
│   ├── tree[2]: [1,2]
│   │   ├── tree[1]: [1,1]
│   │   └── 无
│   └── tree[3]: [3,3]  （通过父指针：3 → 4）
└── tree[6]: [5,6]
    ├── tree[5]: [5,5]
    └── tree[7]: [7,7]  （通过父指针：7 → 8）
```

### 与线段树的本质关系

**树状数组 = 二进制隐式表示的线段树**

线段树每次折半划分区间，树状数组按 lowbit 二进制块划分。两者都能实现 O(log n) 的更新和查询，但树状数组：
- 只能处理**前缀可合并**的问题（和、积、异或）
- 不能处理区间最值、区间赋值

---

## 为什么数组大小是 n + 1？

树状数组必须使用 **1-based 索引**：

1. `lowbit(0) = 0`，如果用 0：
   - `x += lowbit(x)` → 死循环
   - `x -= lowbit(x)` → 一直不变
2. 区间定义 `[x - lowbit(x) + 1, x]` 在 x=0 时无意义

因此数组大小必须为 `n + 1`（下标 1 ~ n）。

## 标准模板代码

```java
class FenwickTree {
    private int[] tree;
    private int n;

    public FenwickTree(int n) {
        this.n = n;
        tree = new int[n + 1];
    }

    public void add(int index, int delta) {
        while (index <= n) {
            tree[index] += delta;
            index += index & -index;
        }
    }

    public int query(int index) {
        int sum = 0;
        while (index > 0) {
            sum += tree[index];
            index -= index & -index;
        }
        return sum;
    }

    // 区间和 [l, r]
    public int rangeQuery(int l, int r) {
        return query(r) - query(l - 1);
    }
}
```

## 应用场景

### 场景一：动态频率统计（权值树状数组）

统计动态数据流中每个值的出现次数，查询小于等于某个值的元素个数。

**典型题目**：315. 计算右侧小于当前元素的个数

关键步骤：
1. 离散化：将原始值映射为 1~n 的排名
2. 从右往左遍历：
   - `query(rank - 1)`：查询比当前元素小的个数
   - `add(rank, 1)`：将当前元素加入

### 场景二：逆序对计数

从左到右遍历，对每个元素查询已遍历元素中比它大的个数：
```
answer += i - query(rank[i])  // 已遍历个数 - 小于等于当前值的个数
add(rank[i], 1)
```

### 场景三：动态前缀和

维护一个可修改的数组，支持单点更新和前缀和查询。
**典型题目**：307. 区域和检索 - 数组可修改

### 场景四：二维树状数组

扩展到二维，支持 O(log² n) 的二维前缀和查询和更新。

```java
class FenwickTree2D {
    int[][] tree;
    int n, m;

    public void add(int x, int y, int delta) {
        for (int i = x; i <= n; i += i & -i) {
            for (int j = y; j <= m; j += j & -j) {
                tree[i][j] += delta;
            }
        }
    }

    public int query(int x, int y) {
        int sum = 0;
        for (int i = x; i > 0; i -= i & -i) {
            for (int j = y; j > 0; j -= j & -j) {
                sum += tree[i][j];
            }
        }
        return sum;
    }
}
```
