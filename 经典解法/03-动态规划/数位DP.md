# 数位DP（Digit DP）

## 1. 什么是数位DP

数位DP是一种**按数位逐位枚举 + 记忆化搜索**的DP技巧，用于解决「在区间 [L, R] 内，满足某些数位相关条件的数字个数 / 总和 / 某种属性」的问题。

核心思想是将数字**拆成逐个数位**，DFS 遍历每一位可能的取值（0~9），同时用一个 `limit` 参数控制不超出上界，用记忆化数组缓存中间状态，避免重复计算。

## 2. 适用场景

满足以下特征的问题，大概率可以用数位DP解：

| 特征 | 说明 |
|------|------|
| **区间统计** | 问题形式为"求 [L, R] 内满足某条件的数字个数/总和" |
| **前缀和可减性** | `f(L,R) = f(0,R) - f(0,L-1)`，即可以将区间问题转为单边界问题 |
| **条件与数位相关** | 条件基于数字的每一位（如是否存在相邻数字的峰值、是否有前导零、数位和等） |
| **范围较大** | L、R 通常可达 10^9~10^15，无法直接遍历 |

## 3. 核心模板

### 3.1 基础参数说明

```java
// 模板签名
long[] dfs(int pos,      // 当前处理到第几位（从高位到低位，0-indexed）
           int pre,      // 最近一位有效数字（或某个历史状态），-1 表示不存在
           int pre2,     // 倒数第二位有效数字（按需扩展）
           boolean limit,    // 当前前缀是否仍与上界 n 的前缀一致
           boolean leadZero) // 当前是否仍在处理前导零
```

| 参数 | 含义 | 为何需要 |
|------|------|----------|
| `pos` | 当前处理的下标 | 决定递归出口（pos == n）和记忆化维度 |
| `pre` / `pre2` | 最近的有效数字 | 判断相邻位关系（峰/谷/连续1等） |
| `limit` | 是否受上界约束 | `true` 时当前位只能取 0~n[pos]，反之可取 0~9 |
| `leadZero` | 是否处于前导零 | 前导零不应参与"峰/谷"等判断，必须单独标记 |

### 3.2 标准模板（计数型）

```java
class DigitDP {
    int[] nums;            // n 的各数位
    int n;                 // 位数长度
    Long[][] memo;         // 记忆化数组：memo[pos][pre] —— 必须 limit=false 时才缓存

    long calc(int num) {
        char[] ch = String.valueOf(num).toCharArray();
        n = ch.length;
        nums = new int[n];
        for (int i = 0; i < n; i++) nums[i] = ch[i] - '0';
        memo = new Long[n][...];  // 按需初始化
        return dfs(0, 0, true, true);
    }

    long dfs(int pos, int pre, boolean limit, boolean leadZero) {
        if (pos == n) return 1;   // 出口：构造出一个完整数字
        // 记忆化：必须 !limit 且 !leadZero 才安全
        if (!limit && !leadZero && memo[pos][pre] != null)
            return memo[pos][pre];

        int up = limit ? nums[pos] : 9;
        long count = 0;
        for (int i = 0; i <= up; i++) {
            // 自行实现条件判断
            count += dfs(pos + 1, i, limit && i == up, leadZero && i == 0);
        }
        if (!limit && !leadZero) memo[pos][pre] = count;
        return count;
    }
}
```

### 3.3 双信息模板（同时统计 count + sum）

有些问题不仅需要统计数量，还需要计算**每个合法数字的某种属性值之和**。此时 dfs 返回一个**二元组** `(count, sum)`：

```java
long[] dfs(int pos, int pre, ...) {
    if (pos == n) return new long[]{1, 0};  // {count=1, sum=0}

    long count = 0, sum = 0;
    for (int i = 0; i <= up; i++) {
        long[] child = dfs(pos + 1, i, ...);
        // 数量直接累加
        count += child[0];
        // 和 = 子问题的和 + 当前位置对所有子数字的贡献 × 子数字个数
        sum += child[1];
        if (/* 当前位置产生额外贡献 */) {
            sum += child[0];  // 每个子数字都多一个贡献
        }
    }
    return new long[]{count, sum};
}
```

**关键理解**：当某个位置对后续所有数字都产生一次贡献时，贡献值 = `贡献值 × childCount`。

## 4. 状态设计原则

数位DP的状态设计是决定能否解题的关键：

### 4.1 必备状态

- `pos`：必须，决定递归维度和出口
- `limit`：必须，控制上界
- `leadZero`：当条件涉及前导零时（如"不能以0开头"、"峰谷判断"）必须

### 4.2 业务状态

根据题目条件，按需添加：

| 条件类型 | 状态设计示例 |
|----------|-------------|
| 相邻位关系（峰/谷） | `pre`, `pre2`（最近两个有效数字） |
| 数位和 / 乘积 | `sum` / `product` |
| 是否出现某数字 | `hasX`（boolean） |
| 数位差的绝对值 | `pre` + 当前位比较 |
| 模运算 | `mod`（对 k 取余的结果） |

### 4.3 记忆化条件

**核心规则**：只有当 `!limit && !leadZero` 时才能写入/读取记忆化缓存。因为此时后续状态只依赖 `(pos, pre, ...)`，不受具体前缀影响。

```java
if (!limit && !leadZero) {
    memoCount[pos][pre][pre2] = count;
}
```

## 5. 经典例题

### 5.1 计数型：233. 数字1的个数

问题：统计 [0, n] 中所有数字里数位 1 出现的总次数。

有两种实现风格：

**风格一：传参累加型** — 向下传递当前已统计的 1 的个数，终止时返回。

```java
dfs(pos, cnt, limit, leadZero):
    出口：返回 cnt
    枚举 digit：
        累加 dfs(pos+1, cnt + (digit==1 ? 1 : 0), ...)
```

**风格二：返回聚合型（推荐）** — 返回 (count, sum) 二元组，每层聚合子结果。

```java
dfs(pos, limit, leadZero):
    出口：return {1, 0}
    枚举 digit：
        next = dfs(pos+1, ...)
        count += next.count
        sum += next.sum
        if (digit == 1) sum += next.count
    return {count, sum}
```

风格二的优点是不需要传递计数参数，逻辑更清晰。详细解答见：[解题记录/数字1的个数[233].md](../../解题记录/数字1的个数[233].md)

### 5.2 条件型：600. 不含连续1的非负整数

问题：统计 [0, n] 中二进制表示不含连续 1 的数字个数。

状态设计：`pre` 为上一位的值（0或1），枚举当前位时跳过 `pre==1 && digit==1`。

详细解答见：[解题记录/不含连续1的非负整数[600].md](../../解题记录/不含连续1的非负整数[600].md)

### 5.3 非连续数字集合：902. 最大为 N 的数字组合

问题：用给定的数字集合（`'1'-'9'` 的子集，**不含 0**）组成 ≤ N 的正整数个数。

**与标准模板的区别**：
- 枚举范围不是 0~9，而是给定集合中的数字
- 集合不含 0，因此不需要 `leadZero` 参数
- 短位数数字用排列组合公式 `m^k` 计算，DFS 只跑同位数

**状态设计**：`(cur, isLimit)` —— 省去了 `leadZero`

**缓存**：`!isLimit` 时，`memo[cur] = 剩余自由位的组合数`

详细解答见：[解题记录/最大为N的数字组合[902].md](../../解题记录/最大为N的数字组合[902].md)

### 5.4 双信息型：3751. 范围内总波动值 I

问题：求 [num1, num2] 内所有数字的总波动值之和。

**波动值定义**：在一个数字的数位中，一个数位如果同时满足：
- 比左边小且比右边小 → 谷（贡献1）
- 比左边大且比右边大 → 峰（贡献1）

**状态设计**：
- `pos`：当前位置
- `pre`：最近一个有效数字
- `pre2`：最近第二个有效数字
- `limit`：是否受上界约束
- `leadZero`：是否处于前导零

**贡献时机**：当 pre、pre2 都有效（!leadZero），且枚举到当前 digit 时，可以判断 pre 是否形成峰或谷。若形成，则贡献 `childCount` 次（因为后续的每个合法数字都会经过这个 pre）。

**前缀和技巧**：
```
ans(num1, num2) = calc(num2) - calc(num1 - 1)
```
这样只需要实现 `calc(n)`，避免同时维护上下界。

详细解答见：[解题记录/范围内总波动值[3751].md](../../解题记录/范围内总波动值[3751].md)

### 5.5 补集转化型：1012. 至少有 1 位重复的数字

问题：统计 `[1, n]` 中至少有一位数字重复的正整数个数。

**补集转化思路**：
- 正面统计"至少一位重复"需要传递频次数组（int[10]），状态无法合并
- 转化为统计"所有位都不重复"，只需要 10 位 bitmask 记录已用数字，状态可 memo

**状态设计**：`(cur, bitMask, isLimit, leadZero)`

**关键细节**：
- `bitMask` 第 k 位 = 1 表示数字 k 已用过，枚举时若选已用数字则剪枝
- 前导 0 阶段选 0 时不更新 bitMask（前导 0 不占用数字 0）
- base case 排除数字 0（`leadZero ? 0 : 1`）
- 最终结果 = `n - dfs(0, 0, true, true)`

**与标准模板的区别**：
- 不需要 `pre` 等历史状态，只需记录"集合"（是否出现过）
- 不直接统计目标数，而是先统计补集再相减——这是一种重要的**正难则反**策略

详细解答见：[解题记录/至少有1位重复的数字[1012].md](../../解题记录/至少有1位重复的数字[1012].md)

## 6. 常见变体与技巧

| 变体 | 技巧 |
|------|------|
| **区间内求和** | dfs 返回二元组 (count, sum)，sum 传递时 `child[1] + 当前贡献 × child[0]` |
| **数位DP + 模运算** | 增加 `mod` 状态，记忆化维度相应扩展 |
| **二进制数位DP** | up 改为 1，枚举只有 0/1 |
| **非连续数字集合** | 枚举范围从 0~up 改为遍历给定集合，可用 `break` 剪枝（已排序） |
| **非十进制** | 定制 `up` 的上限（如八进制 up=7） |
| **同时维护上下界** | 增加 `limitLow` 参数（一般用前缀和相减避免） |
| **前导零特殊处理** | 前导零阶段不参与"峰/谷/是否包含某数字"等判断 |

## 7. 时间复杂度

数位DP的复杂度取决于**状态空间大小**：
- 设 num 位数为 L，每个业务状态最多有 S 种取值
- 固定 limit=false, leadZero=false 后，状态数 ≈ `L × S`
- 每个状态枚举最多 10 个数位
- 总复杂度：O(L × S × 10)

对于本题 3751：S = 10 × 10（pre 和 pre2 各 0~9），故 O(L × 100 × 10) = O(L × 1000)，L ≤ 15，非常高效。

## 8. 数位DP vs 其他DP

| 对比维度 | 普通DP | 数位DP |
|----------|--------|--------|
| 枚举对象 | 具体数字 | 数位 |
| 适用规模 | n 较小（如 n ≤ 10^6） | n 可达 10^15 甚至更大 |
| 状态定义 | dp[i] 表示某个具体含义 | dfs(pos, state) 按数位递归 |
| 实现方式 | 递推 / 记忆化搜索 | 几乎总是 DFS + 记忆化 |
| 边界处理 | 通常简单 | 需要 limit + leadZero 精细控制 |

## 9. 总结口诀

> **数位DP三要素：逐位枚举、limit限界、记忆化缓存**
>
> **状态设计两核心：pos必须带、业务条件按需加**
>
> **区间问题一个套路：f(L,R) = f(R) - f(L-1)**
>
> **缓存一个原则：只有 !limit && !leadZero 才记**
