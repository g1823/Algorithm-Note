# 堆与优先队列

## 概述

堆（Heap）是一种特殊的**完全二叉树**，分为：
- **大顶堆**：父节点值 ≥ 子节点值（用于找第 K 大）
- **小顶堆**：父节点值 ≤ 子节点值（用于找第 K 小）

Java 中的 `PriorityQueue` 默认是**小顶堆**。

## 常用操作

```java
// 小顶堆
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
// 大顶堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
// 自定义比较器（按 Map 中的值排序）
PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> map.get(a) - map.get(b));

// 操作
pq.offer(x);  // 插入
pq.poll();    // 弹出堆顶
pq.peek();    // 查看堆顶
pq.size();    // 堆大小
```

## 应用一：215. 数组中的第K个最大元素

**思路**：用小顶堆维护前 K 大元素。堆大小超过 K 时弹出最小元素，最后堆顶即为第 K 大。

```java
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int num : nums) {
        pq.offer(num);
        if (pq.size() > k) pq.poll();
    }
    return pq.peek();
}
```

时间复杂度：O(n log k)

## 应用二：347. 前 K 个高频元素

**思路**：统计频次 → 用小顶堆按频次排序 → 堆中保留前 K 个。

## 应用三：295. 数据流的中位数

**思路**：用两个堆——大顶堆存较小的一半，小顶堆存较大的一半。中位数由两个堆顶计算。

## 堆排序

```java
// 利用 PriorityQueue 实现堆排序
PriorityQueue<Integer> pq = new PriorityQueue<>();
for (int num : nums) pq.offer(num);
for (int i = 0; i < nums.length; i++) nums[i] = pq.poll();
```
