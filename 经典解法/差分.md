# 差分数组 (Difference Array)

## 概述

差分数组是**前缀和的逆运算**。对于原数组 `a`，定义差分数组 `d`：

```
d[0] = a[0]
d[i] = a[i] - a[i-1]   (i ≥ 1)
```

**核心性质**：对差分数组 `d` 求前缀和可还原出原数组 `a`。

**与前缀和对比**：

| 方法 | 区间修改（[l,r]加x） | 单点查询 | 适用场景 |
|------|:-------------------:|:--------:|----------|
| 前缀和 | O(n) | O(1) | 数组不变，多次区间和查询 |
| **差分数组** | **O(1)** | O(n) 或 O(1)* | 多次区间修改 + 最终结果查询 |
| 树状数组 | O(log n) | O(log n) | 区间修改 + 单点查询 |

> *若只有单次最终查询，可 O(n) 累加；若需多次查询区间和，需配合前缀和（二维树状数组）。

---

## 核心思想

将**区间操作**转化为**端点操作**：

```
对原数组 a[l..r] 每个元素 +x
    ⇓ 等价于
d[l] += x
d[r+1] -= x   （若 r+1 在范围内）
```

**原理**：差分数组的前缀和就是原数组，所以 `d[l] += x` 会让 `l` 之后的所有位置都 +x，再在 `r+1` 处 -x 抵消掉 `r` 之后的影响。

## 应用

### 370. 区间加法

##### 题目描述

假设你有一个长度为 `n` 的数组，初始所有元素均为 `0`，给定 `k` 个更新操作。每个操作表示为三元组 `[l, r, d]`，表示将子数组 `nums[l..r]` 中每个元素增加 `d`。返回所有操作执行后的最终数组。

**示例：**

```
输入: length = 5, updates = [[1,3,2],[2,4,3],[0,2,-2]]
输出: [-2,0,3,5,3]
```

**解释：**

```
初始: [0,0,0,0,0]
[1,3,2] → [0,2,2,2,0]
[2,4,3] → [0,2,5,5,3]
[0,2,-2] → [-2,0,3,5,3]
```

##### 分析

差分数组的经典应用。每次区间 `[l, r]` 加 `d`，只需操作两个端点：

- `ans[l] += d`
- `ans[r+1] -= d`（注意边界）

最后对 `ans` 求一次前缀和即得结果。

~~~java
public int[] getModifiedArray(int length, int[][] updates) {
    int[] ans = new int[length];
    for (int[] update : updates) {
        int l = update[0];
        int r = update[1];
        int d = update[2];
        ans[l] += d;
        if (r + 1 < length) {
            ans[r + 1] -= d;
        }
    }
    for (int i = 1; i < length; i++) {
        ans[i] += ans[i - 1];
    }
    return ans;
}
~~~

### 732. 我的日程安排表 III

##### 题目分析

每次 `book(start, end)` 添加一个日程（区间 `[start, end)`），需返回当前所有日程中**任意时刻的最大重叠次数**。

采用差分思想：在 `start` 处 +1，`end` 处 -1，用 TreeMap 维护排序后的端点，扫描累加追踪最大值。

~~~java
class MyCalendarThree {
    private TreeMap<Integer, Integer> diff;

    public MyCalendarThree() {
        diff = new TreeMap<>();
    }

    public int book(int start, int end) {
        diff.put(start, diff.getOrDefault(start, 0) + 1);
        diff.put(end, diff.getOrDefault(end, 0) - 1);

        int cur = 0, max = 0;
        for (int val : diff.values()) {
            cur += val;
            max = Math.max(max, cur);
        }
        return max;
    }
}
~~~

### 二维差分

将差分思想扩展到二维矩阵。对子矩阵 `(x1,y1)` 到 `(x2,y2)` 加 `d`：

```
diff[x1][y1]     += d
diff[x1][y2+1]   -= d
diff[x2+1][y1]   -= d
diff[x2+1][y2+1] += d
```

最后对 `diff` 做二维前缀和还原。

## 差分 vs. 扫描线

| 特性 | 差分数组 | 扫描线 |
|------|----------|--------|
| 数据结构 | 数组 / TreeMap | TreeMap / 排序列表 |
| 操作方式 | 端点 +1/-1，遍历累加 | 按端点排序，事件入队出队 |
| 适用场景 | 值域连续且范围已知 | 端点稀疏或需区间查询 |
| 复杂度 | O(n + m) | O(m log m) |

二者本质相通：差分是扫描线在离散坐标上的特例。当端点需要排序时，差分配合 TreeMap 即可退化为"扫描线"。
