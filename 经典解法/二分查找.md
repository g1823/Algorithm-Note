# 二分查找 (Binary Search)

## 概述

二分查找是一种在**有序序列**中快速定位目标值的技巧，每次将搜索范围缩小一半，时间复杂度 O(log n)。

## 基础模板

```java
// 精确查找 target
public int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

// 查找左边界（第一个 >= target 的位置）
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left;
}
```

## 核心要点

1. **避免溢出**：使用 `left + (right - left) / 2` 而非 `(left + right) / 2`
2. **边界条件**：`left <= right` vs `left < right` 取决于搜索区间开闭
3. **mid 偏向**：当长度为偶数时，`mid = left + (right - left) / 2` 取左中位数

## 高级应用：答案二分

当答案满足**单调性**时（如"越大越能完成"），可以二分答案而不是二分数组。

### 875. 爱吃香蕉的珂珂

**题目**：求最小速度 K，使得在 H 小时内吃完所有香蕉。

**二分策略**：速度 K 在 [1, max(piles)] 范围内二分，判断给定速度下能否在 H 小时内吃完。

```java
public int minEatingSpeed(int[] piles, int h) {
    int left = 1, right = 0;
    for (int p : piles) right = Math.max(right, p);
    while (left < right) {
        int mid = left + (right - left) / 2;
        int hours = 0;
        for (int p : piles) hours += (p + mid - 1) / mid;  // 向上取整
        if (hours <= h) right = mid;    // 可以，尝试更小
        else left = mid + 1;            // 不可以，需要更大
    }
    return left;
}
```
