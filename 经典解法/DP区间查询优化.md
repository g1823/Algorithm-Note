# DP 中的区间查询优化

## 概述

许多 DP 的状态转移需要查询某个**区间**内的信息（是否存在可达点、最小/最大值、区间和等）。朴素做法是每次 O(区间长度) 遍历整个区间，总复杂度 O(n²) 往往超时。

**核心思路**：不要直接 for 遍历区间，先思考"真正需要区间里的**什么信息**"，再选择对应的数据结构做 O(1) 或 O(log n) 查询。

> 本文思想提炼自 [1871. 跳跃游戏 VII](../解题记录/跳跃游戏VII[1871].md) 的代码注释。

## 区间需求 → 数据结构速查表

| 区间需求 | 推荐数据结构 | 复杂度 |
|----------|-------------|:------:|
| 区间和 / 区间个数 | **前缀和**、树状数组、线段树 | O(1) / O(log n) |
| 区间最大值 / 最小值 | **单调队列**、线段树、ST 表 | O(1) / O(log n) |
| 区间是否存在某个元素 | 前缀计数、哈希表、位运算 | O(1) |
| 动态滑动区间（随 i 右移） | **滑动窗口**、双指针 | O(1) 均摊 |

## 实例：1871. 跳跃游戏 VII

**问题**：`dp[i] = 存在 j ∈ [i-maxJump, i-minJump] 使得 dp[j] = true`

**需求分析**：只需要知道区间内"是否存在"可达点 → **区间内可达点个数是否 > 0**。

### 方案一：前缀和（区间计数）

```java
int[] pre = new int[n];  // pre[i] = [0, i] 可达点个数
for (int i = 1; i < n; i++) {
    int left = i - maxJump, right = i - minJump;
    int count = pre[right] - (left > 0 ? pre[left - 1] : 0);
    dp[i] = (count > 0 && s.charAt(i) == '0') ? 1 : 0;
    pre[i] = pre[i - 1] + dp[i];
}
```

### 方案二：滑动窗口（动态区间）

区间 `[i-maxJump, i-minJump]` 随 i 增加而整体右移，可维护窗口内可达点数量：

```java
int reachable = 0;  // 窗口内可达点数量
for (int i = 1; i < n; i++) {
    int enter = i - minJump;       // 新进入窗口的元素
    int leave = i - maxJump - 1;   // 离开窗口的元素
    if (enter >= 0 && s.charAt(enter) == '0') reachable += dp[enter];
    if (leave >= 0 && s.charAt(leave) == '0') reachable -= dp[leave];
    dp[i] = (s.charAt(i) == '0' && reachable > 0) ? 1 : 0;
}
```

## 总结

遇到 DP 依赖区间时，按以下步骤分析：
1. **明确需求**：区间和 / 最大值 / 是否存在 / 个数？
2. **选数据结构**：对照速查表
3. **注意边界**：窗口左右端的进入/离开时机，前缀和的左边界处理
