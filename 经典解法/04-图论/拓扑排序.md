# 拓扑排序 (Topological Sort)

## 概述

拓扑排序用于**有向无环图（DAG）**，将图中所有顶点排成一个线性序列，使得每条有向边 (u → v) 都满足 u 在 v 之前。

**必须满足**：图中无环，否则不存在拓扑排序。

---

## DAG（有向无环图）详解

### 什么是 DAG？

DAG = Directed Acyclic Graph = **有向无环图**，同时满足两个条件：
1. **有向**：边有方向，u→v 和 v→u 是两条不同的边
2. **无环**：不存在一条路径从某个节点出发又回到自身

### DAG 的关键性质

**性质一：一定有拓扑序**

任何 DAG 都存在至少一个拓扑排序。反之，如果图存在环，则不存在拓扑排序。

**性质二：按拓扑序递推时，每个节点的结果一旦确定就不需要再更新**

这是拓扑序用于 DP 的**最核心性质**。原因是：
- 所有能到达节点 u 的节点都排在 u 前面
- 按拓扑序遍历时，处理到 u 时，所有入边来源都已处理完
- 所以 `dist[u]` 已经是最终值，不需要再更新

对比非 DAG（有环图）：
- 可能先找到一条路径到 u，后来从另一条绕路的更短路径更新 u
- 所以需要优先队列 + 过期数据剪枝（Dijkstra）

**性质三：子图仍是 DAG**

删除 DAG 中的边或节点，得到的子图仍然是 DAG。这意味着先算一次拓扑序，后续可以在不同限制条件下（如过滤边权）复用。

### DAG 上最短路径 vs Dijkstra

| | Dijkstra（通用图） | 拓扑 DP（DAG） |
|--|-------------------|---------------|
| 适用图 | 非负权图（可有环） | DAG（必须无环） |
| 复杂度 | O((n+m)logn) | O(n+m) |
| 数据结构 | 优先队列 | 普通队列 + for 循环 |
| 处理次数 | 每个节点可能多次入队 | 每个节点**恰好一次** |
| 过期数据 | 需要 `if (cost != dist[node]) continue` 剪枝 | 无需，无过期数据 |

### 常见 DAG 场景

- **编译依赖**：源文件 A 依赖 B，B 依赖 C
- **课程体系**：先修课关系
- **项目管理**：任务依赖关系
- **有向无环图 DP**：如本题、最小路径和（本质上也是 DAG）

## 两种实现方式

### 方法一：Kahn 算法（BFS + 入度）

#### 为什么入度为 0 的节点可以立即处理？

入度 = 指向该节点的边的数量。入度为 0 意味着**没有其他节点必须排在它前面**，所以它可以作为拓扑序的第一个节点。

删除这个节点后，它的所有出边也被移除，导致后继节点的入度减少。当某个后继节点的入度减为 0 时，说明"所有排在我前面的节点都已经处理完了"，可以入队。

#### 为什么可以检测环？

最终处理的节点数 < 总节点数 → 剩下的节点形成一个环（环中每个节点的入度都至少为 1，永远不会变为 0）。

#### 流水线类比

Kahn 算法就像生产流水线：每个工序等所有上游零件到齐后开始加工，加工完后送往下游。如果存在循环依赖（A 等 B，B 等 A），整个流水线就会死锁。

#### 完整流程

1. 计算所有顶点的入度
2. 入度为 0 的顶点入队
3. 不断出队，删除该顶点的所有出边（邻接点入度减 1），入度变为 0 的入队
4. 若最终处理的顶点数 < 总顶点数 → 存在环

```java
// Kahn 算法：返回拓扑序列（若有环则返回空列表）
public List<Integer> topologicalSort(int n, List<Integer>[] graph) {
    int[] indegree = new int[n];
    for (int u = 0; u < n; u++) {
        for (int v : graph[u]) {
            indegree[v]++;
        }
    }
    Queue<Integer> q = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (indegree[i] == 0) q.offer(i);
    }
    List<Integer> result = new ArrayList<>();
    while (!q.isEmpty()) {
        int u = q.poll();
        result.add(u);
        for (int v : graph[u]) {
            if (--indegree[v] == 0) q.offer(v);
        }
    }
    return result.size() == n ? result : new ArrayList<>(); // 有环返回空
}
```

### 方法二：DFS + 状态标记

用三种状态标记顶点：0=未访问、1=访问中、2=已完成。若 DFS 过程中再次遇到状态为 1 的顶点，说明存在环。

```java
// DFS 后序反转：先递归所有后继，再把当前节点加入结果
// 最后反转结果得到拓扑序
public List<Integer> topologicalSortDFS(int n, List<Integer>[] graph) {
    int[] state = new int[n]; // 0=未访问, 1=访问中, 2=已完成
    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        if (state[i] == 0) {
            if (!dfs(i, graph, state, result)) return new ArrayList<>(); // 有环
        }
    }
    Collections.reverse(result);
    return result;
}

private boolean dfs(int u, List<Integer>[] graph, int[] state, List<Integer> result) {
    state[u] = 1; // 访问中
    for (int v : graph[u]) {
        if (state[v] == 1) return false; // 遇到访问中的节点 → 有环
        if (state[v] == 0) {
            if (!dfs(v, graph, state, result)) return false;
        }
    }
    state[u] = 2; // 已完成
    result.add(u); // 后序加入
    return true;
}
```

## 在 DAG 上做 DP（核心应用）

Kahn 算法不仅可以排拓扑序，更关键的是**可以在拓扑序上递推**。

### 模板：DAG 上按拓扑序求最短路径

```java
long[] dist = new long[n];
Arrays.fill(dist, Long.MAX_VALUE);
dist[source] = 0;

for (int u : topo) {        // 按拓扑序遍历
    if (dist[u] == INF) continue;
    for (int v : graph[u]) {
        long nd = dist[u] + weight(u, v);
        if (nd < dist[v]) {
            dist[v] = nd;   // 每个节点只被更新一次
        }
    }
}
```

**不需要优先队列**，因为拓扑序保证所有入边来源都已处理完，dist[u] 不会再被更新。
