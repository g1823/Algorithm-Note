# Dijkstra 算法详解

## 1. 能做什么

Dijkstra 算法用于求解**带非负权重的有向图或无向图**中，从单一源点 `s` 到图中所有其他顶点的**最短路径**。若图中存在负权边，算法可能失效。

典型应用场景包括：

- 地图导航中计算两点之间的最短行驶距离或最短耗时。
- 网络路由协议（如 OSPF）中寻找代价最小的转发路径。
- 资源调度、物流规划等需要最短路径信息的领域。

------

## 2. 核心思想

算法采用**贪心策略**：维护一个顶点集合 `S`，该集合中的顶点到源点 `s` 的最短距离已被确定。初始时 `S = {s}`。每一轮从未确定最短距离的顶点中，选择一个当前估计距离 `d[v]` 最小的顶点 `u` 加入 `S`，并利用 `u` 的出边对其邻居进行**松弛操作**，试图更新邻居的估计距离。重复该过程直到所有可达顶点均被加入 `S`。

松弛操作的定义：

​	对于边 (u, v)，若 d[u] + w(u, v) < d[v]，则更新 d[v] = d[u] + w(u, v)。

算法正确性建立在**非负边权**和**贪心选择性质**之上。

------

## 3. 流程

### 3.1 算法步骤

1. 初始化：
   - 设置距离数组 `d`：`d[s] = 0`，其余顶点 `d[v] = ∞`。
   - 集合 `S = ∅`（或直接使用优先队列隐式管理）。
   - 使用最小优先队列 `Q` 存储所有未确定顶点，关键字为 `d` 值。
2. 当 `Q` 非空时循环：
   - 从 `Q` 中取出 `d` 值最小的顶点 `u`（首次取出的是源点 `s`）。
   - 将 `u` 加入集合 `S`（表示其最短距离已确定）。
   - 对 `u` 的每条出边 `(u, v)` 执行松弛操作：
     - 若 `d[u] + w(u, v) < d[v]`，则更新 `d[v] = d[u] + w(u, v)`，并更新优先队列中 `v` 的关键字。
3. 循环结束后，`d` 数组即保存了从 `s` 到各顶点的最短距离。

### 3.2 伪代码

```java
算法 Dijkstra(Graph, source):

输入：带非负权值的有向图 Graph，源点 source
输出：dist 数组（源点到各顶点的最短距离），prev 数组（最短路径树的前驱记录）

// 初始化阶段
for 图中的每个顶点 v:
	dist[v] = 无穷大
	prev[v] = 空
	将 v 加入优先队列 Q，键值为 dist[v]
	dist[source] = 0
	更新 Q 中 source 的键值为 0

// 主循环阶段
while 优先队列 Q 不为空:
	u = 从 Q 中取出键值最小的顶点
	for u 的每个邻居 v:
		候选距离 = dist[u] + 边(u, v)的权值
		if 候选距离 < dist[v]:
			dist[v] = 候选距离
			prev[v] = u
		更新 Q 中 v 的键值为 候选距离

返回 dist 和 prev

说明：
	dist[v] 记录从源点到顶点 v 的当前最短距离估计。
	prev[v] 记录在最短路径树中顶点 v 的前驱，用于最终重构具体路径。

优先队列 Q 需支持“取出最小值”和“更新键值”两种操作。若使用的优先队列不支持高效的“更新键值”，可采用惰性删除策略：将更新后的 (候选距离, v) 直接插入队列，并在取出时若发现 v 已被处理则跳过。该变种的时间复杂度仍为 O((V+E) log V)。
```

### 3.3 文本示意图：算法执行过程

```
图例：
    s --1--> a --2--> b
     \       |       /
      4      3      1
       \     |     /
        +-> c <----+

初始状态：
    d[s]=0, d[a]=∞, d[b]=∞, d[c]=∞
    S = {}

第一轮：取出 s (d=0)
    松弛 s→a: d[a] = min(∞, 0+1) = 1
    松弛 s→c: d[c] = min(∞, 0+4) = 4
    S = {s}

第二轮：取出 a (d=1)
    松弛 a→b: d[b] = min(∞, 1+2) = 3
    松弛 a→c: d[c] = min(4, 1+3) = 4 (不变)
    S = {s, a}

第三轮：取出 b (d=3)
    松弛 b→c: d[c] = min(4, 3+1) = 4 (不变)
    S = {s, a, b}

第四轮：取出 c (d=4)
    无出边或已无未处理邻居
    S = {s, a, b, c}

最终距离：
    d[a]=1, d[b]=3, d[c]=4
```

## 4. 两种证明

算法正确性的核心是证明：每次从优先队列中取出并加入 `S` 的顶点 `u`，其当前 `d[u]` 值恰好等于真实最短距离 `δ(s, u)`。以下介绍两种主流证明风格。

### 4.1 流派 A：基于路径片段长度的直接证明

**归纳假设**：当集合 `S` 包含 `k` 个顶点时，对于任意 `v ∈ S`，有 `d[v] = δ(s, v)`。

**基础情形**：`k = 1` 时，`S = {s}`，`d[s] = 0 = δ(s, s)`，成立。

**归纳步骤**：假设 `|S| = k` 时成立，现证明第 `k+1` 个顶点 `u`（当前 `S` 外 `d` 值最小者）满足 `d[u] = δ(s, u)`。

采用反证法：假设 `d[u] > δ(s, u)`。

设 `P` 为任意一条 `s → u` 的**真实最短路径**，长度为 `δ(s, u)`。因 `s ∈ S` 而 `u ∉ S`，路径 `P` 上必然存在第一条边 `(x, y)` 满足 `x ∈ S` 且 `y ∉ S`。

1、当 `x` 被加入 `S` 时，算法对边 `(x, y)` 执行了松弛操作，故有：

​	`d[y] ≤ d[x] + w(x, y)`

根据归纳假设，`d[x] = δ(s, x)`，代入得：d[y] ≤ δ(s, x) + w(x, y)

2、注意 `δ(s, x) + w(x, y)` 正是路径 `P` 上从 `s` 到 `y` 的实际长度。由于 `P` 是一条 `s → u` 路径且边权非负，显然有：

​	`δ(s, x) + w(x, y) ≤ δ(s, u)`

结合步骤 1 得到：`d[y] ≤ δ(s, u)`

3、根据 `u` 的选择规则，`u` 是当前 `S` 外 `d` 值最小的顶点，而 `y ∉ S`，因此：

​	`d[u] ≤ d[y]`

4、综合步骤 2 和 3，得出：

​	`d[u] ≤ δ(s, u)`

这与反证假设 `d[u] > δ(s, u)` 矛盾。故假设不成立，`d[u] = δ(s, u)`。

**关键点**：该证明直接将松弛操作的上界 `d[y]` 与最短路径的物理片段长度绑定，简洁直观。

### 4.2 流派 B：基于最优子结构的形式化证明

**归纳假设**与反证假设同流派 A。

同样构造 `P`、`x`、`y`。

1、由松弛操作与归纳假设，得到：

​	`d[y] ≤ δ(s, x) + w(x, y) (1)`

2、利用最短路径的**最优子结构性质**：若 `P` 是 `s → u` 的最短路径，则其子路径 `s → y` 也是最短路径。因此子路径长度等于 `δ(s, y)`，即：

​	`δ(s, y) = δ(s, x) + w(x, y) (2)`

由 (1) 和 (2) 可得：

​	`d[y] ≤ δ(s, y) (3)`

3、由于 `y` 在路径 `P` 上位于 `u` 之前（或等于 `u`），且所有边权非负，最短距离满足单调性：

​	`δ(s, y) ≤ δ(s, u) (4)`

4、结合 (3) 和 (4) 得到：

​	`d[y] ≤ δ(s, u) (5)`

5、由 `u` 的选择规则有 `d[u] ≤ d[y]`，结合 (5) 推出 `d[u] ≤ δ(s, u)`，与假设矛盾。

**关键点**：该证明显式运用了最短路径的最优子结构性质，将算法估计值与全局最优解通过 `δ(s, y)` 串联，是贪心算法证明的标准模板。

### 4.3 两种证明的对比

| 维度       | 流派 A                             | 流派 B                                 |
| :--------- | :--------------------------------- | :------------------------------------- |
| 核心不等式 | `d[y] ≤ δ(s,x)+w(x,y) ≤ δ(s,u)`    | `d[y] ≤ δ(s,y) ≤ δ(s,u)`               |
| 依赖性质   | 松弛操作 + 路径片段长度 ≤ 路径总长 | 松弛操作 + 最优子结构 + 非负边权单调性 |
| 直观性     | 更直接，无需显式引入 `δ(s,y)`      | 更形式化，强调子问题最优性             |
| 教学侧重   | 算法行为本身                       | 贪心算法设计范式                       |

## 5. 与其他相似算法类比

| 算法               | 适用场景                             | 时间复杂度                       | 能否处理负权边 | 特点                                          |
| :----------------- | :----------------------------------- | :------------------------------- | :------------- | :-------------------------------------------- |
| **Dijkstra**       | 非负权图，单源最短路径               | O((V+E) log V)（二叉堆优化）     | 否             | 贪心策略，效率高，应用最广                    |
| **Bellman-Ford**   | 任意权值图，单源最短路径             | O(VE)                            | 能             | 可检测负权环，但速度较慢                      |
| **Floyd-Warshall** | 任意权值图，全源最短路径             | O(V³)                            | 能             | 动态规划，适合稠密图，代码简洁                |
| **A\***            | 启发式搜索，单源单目标最短路径       | 依赖于启发函数，通常优于Dijkstra | 依赖图权值性质 | 需设计可采纳的启发函数，常用于游戏寻路与导航  |
| **SPFA**           | 任意权值图，单源最短路径（队列优化） | 平均 O(E)，最坏 O(VE)            | 能             | Bellman-Ford 的队列优化版，实际运行快但易被卡 |

**选择建议**：

- 若无负权边，优先使用 Dijkstra。
- 若存在负权边或需检测负权环，使用 Bellman-Ford 或 SPFA。
- 若需要所有点对间的最短距离且图较小，使用 Floyd-Warshall。
- 若已知目标位置且有有效启发信息，使用 A*。

------

## 6. 总结

Dijkstra 算法是图论与算法设计中的经典范例，其价值不仅在于高效求解最短路径问题，更在于它所体现的**贪心选择性质**与**最优子结构**的完美结合。

**核心要点回顾**：

1. **适用范围**：非负权图。
2. **核心操作**：贪心选取最小估计距离顶点 + 松弛出边。
3. **正确性基石**：非负边权保证“路径延伸长度不降”，使得贪心选择安全。
4. **证明方法**：既可从路径片段长度直接推导，也可通过最优子结构形式化论证。
5. **算法变种**：使用不同优先队列实现可权衡时间与空间；双向 Dijkstra 可加速点到点查询。

掌握 Dijkstra 算法的推导与证明，是深入理解图算法、贪心策略以及算法正确性分析的重要阶梯。
