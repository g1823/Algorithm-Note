# 滑动窗口 (Sliding Window)

## 概述

滑动窗口是一种在**数组/字符串**上维护一个**连续区间**的技巧。窗口左右边界单调移动（只增不减），在 O(n) 时间内遍历所有可能的连续子区间。

## 基本模板

```java
int left = 0, right = 0;
while (right < n) {
    // 扩展窗口：加入 right 位置的元素
    window.add(arr[right]);
    right++;

    // 收缩窗口：当条件不满足时，移动 left
    while (window不满足条件) {
        window.remove(arr[left]);
        left++;
    }

    // 更新结果
    updateResult();
}
```

## 应用一：3. 无重复字符的最长子串

维护一个不含重复字符的窗口，遇到重复字符时收缩左边界。

```java
public int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int left = 0, maxLen = 0;
    for (int right = 0; right < s.length(); right++) {
        while (set.contains(s.charAt(right))) {
            set.remove(s.charAt(left++));  // 收缩直到不重复
        }
        set.add(s.charAt(right));
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
```

## 应用二：438. 找到字符串中所有字母异位词

维护一个固定大小的窗口（p 的长度），判断窗口内字母频次是否匹配。

```java
public List<Integer> findAnagrams(String s, String p) {
    List<Integer> result = new ArrayList<>();
    if (s.length() < p.length()) return result;
    int[] sCount = new int[26], pCount = new int[26];
    for (int i = 0; i < p.length(); i++) {
        sCount[s.charAt(i) - 'a']++;
        pCount[p.charAt(i) - 'a']++;
    }
    if (Arrays.equals(sCount, pCount)) result.add(0);
    for (int i = p.length(); i < s.length(); i++) {
        sCount[s.charAt(i) - 'a']++;                  // 窗口右移
        sCount[s.charAt(i - p.length()) - 'a']--;      // 窗口左移
        if (Arrays.equals(sCount, pCount)) result.add(i - p.length() + 1);
    }
    return result;
}
```

## 滑动窗口 vs 前缀和

| 特性 | 滑动窗口 | 前缀和 |
|------|----------|--------|
| 适用条件 | 窗口单调性（收缩时有确定条件） | 任意区间 |
| 时间复杂度 | O(n) | O(n) 预处理 + O(1) 查询 |
| 典型场景 | 最长/最短子串、固定大小窗口 | 子数组和、区间查询 |
