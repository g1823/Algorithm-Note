# 线段树 (Segment Tree)

## 概述

线段树是一种**二叉树**数据结构，每个节点代表一个**区间**（线段），用于高效处理数组的**区间查询**和**区间更新**问题。

**核心思想**：将整个数组递归地二分，每个节点维护对应区间的聚合信息（和、最大值、最小值、出现次数等）。

**时间复杂度**：建树 O(n)，单次查询/更新 O(log n)

**与其他方法对比**：

| 数据结构 | 区间和/区间统计 | 区间最值 | 区间更新 | 适用场景 |
|----------|:--------------:|:--------:|:--------:|----------|
| 前缀和 | O(1) 查询 | 不支持 | 不支持 | 数组不变，多次区间和查询 |
| 树状数组 | O(log n) | 不支持 | 单点更新 | 单点更新+前缀和查询 |
| **线段树** | **O(log n)** | **O(log n)** | **O(log n)** | **区间更新+区间查询** |
| ST 表 | O(1) 查询 | O(1) 查询 | 不支持 | 离线最值查询 |

---

## 核心操作

### 1. 建树 (Build)

递归地将区间 `[l, r]` 二分，直到叶子节点（`l == r`），叶子节点对应原数组的单个元素。

### 2. 单点更新 (Point Update)

修改某个位置的值，递归找到对应的叶子节点，更新后自底向上重新计算路径上每个节点的聚合值。

### 3. 区间查询 (Range Query)

查询 `[ql, qr]` 的聚合信息：
- 当前节点区间完全在查询区间内 → 直接返回节点值
- 当前节点区间完全不在查询区间内 → 返回单位元（如 0）
- 部分重叠 → 递归左右子树，合并结果

### 4. 区间更新 + 懒标记 (Lazy Propagation)

更新某个区间内所有元素时，如果逐层递归到叶子，最坏情况下每次更新 O(n)。**懒标记** 优化：
- 当前节点区间完全在目标区间内 → 更新节点值，设置懒标记，不再递归下层
- 后续查询或更新需要向下走时 → 将懒标记**下推 (push down)** 到子节点

## 两种实现方式

### 方式一：真实二叉树节点（指针实现）

```java
class SegmentTree {
    class Node {
        int l, r;
        int value;
        Node left, right;

        public Node(int l, int r) {
            this.l = l;
            this.r = r;
        }
    }

    Node root;

    public SegmentTree(int n) {
        root = build(1, n);
    }

    private Node build(int l, int r) {
        if (l == r) return new Node(l, r);
        Node node = new Node(l, r);
        int mid = l + (r - l) / 2;
        node.left = build(l, mid);
        node.right = build(mid + 1, r);
        return node;
    }
}
```

**优点**：直观易懂，结构清晰，适合初学者。
**缺点**：每个节点额外存储指针，占用更多内存；频繁 new 对象 GC 压力大。

### 方式二：数组隐式表示（推荐）

利用完全二叉树的特性：节点 `i` 的左子节点为 `2*i`，右子节点为 `2*i+1`。

```java
class SegmentTree {
    int[] tree;
    int n;

    public SegmentTree(int n) {
        this.n = n;
        tree = new int[4 * n];  // 4n 足以容纳所有节点
    }

    private void pushUp(int node) {
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    public void update(int index, int delta) {
        update(1, 1, n, index, delta);
    }

    private void update(int node, int start, int end, int index, int delta) {
        if (start == end) {
            tree[node] += delta;
            return;
        }
        int mid = (start + end) / 2;
        if (index <= mid) {
            update(node * 2, start, mid, index, delta);
        } else {
            update(node * 2 + 1, mid + 1, end, index, delta);
        }
        pushUp(node);
    }

    public int query(int l, int r) {
        return query(1, 1, n, l, r);
    }

    private int query(int node, int start, int end, int l, int r) {
        if (start > r || end < l) return 0;
        if (l <= start && end <= r) return tree[node];
        int mid = (start + end) / 2;
        return query(node * 2, start, mid, l, r) +
               query(node * 2 + 1, mid + 1, end, l, r);
    }
}
```

**数组大小 4n 的原因**：线段树高度 h = ceil(log2(n)) + 1，完全二叉树最多 2^h - 1 个节点，代入得 4n - 1，因此 4n 安全。

**优点**：无额外指针开销，内存连续、访问更快。
**缺点**：需要递归时传递区间边界参数。



### 方式三：指针动态开点（动态开点线段树）

**为什么需要动态开点**：数组表示法（4n）在值域范围极大时不可行。例如值域 `[0, 10⁹]`，4n = 4×10⁹ 个 int 不可能开出。而实际访问的节点通常远少于全量（操作数 N ≤ 几百到几千）。

**核心思想**：不预先建树，只创建被访问到的节点。

```java
class SegmentTree {
    class Node {
        int count, lazy;
        Node left, right;
    }

    Node root = new Node();

    void update(Node node, int l, int r, int ql, int qr) {
        if (ql >= r || qr <= l) return;
        if (ql <= l && r <= qr) {
            node.count++; node.lazy++; return;
        }
        int mid = l + (r - l) / 2;
        if (node.left == null)  node.left  = new Node();
        if (node.right == null) node.right = new Node();
        pushDown(node);
        update(node.left,  l, mid, ql, qr);
        update(node.right, mid, r,  ql, qr);
        node.count = Math.max(node.left.count, node.right.count) + node.lazy;
    }

    void pushDown(Node node) {
        if (node.lazy == 0) return;
        node.left.count  += node.lazy;
        node.left.lazy   += node.lazy;
        node.right.count += node.lazy;
        node.right.lazy  += node.lazy;
        node.lazy = 0;
    }
}
```

**边界传递**：l, r 通过递归参数传入，Node 只存 count/lazy，比预建树的指针实现更简洁。

### 方式四：HashMap + 完全二叉树编号（虚拟动态开点）

结合数组下标和动态开点的优点：

```java
class SegmentTree {
    Map<Integer, Integer> tree = new HashMap<>();
    Map<Integer, Integer> lazy = new HashMap<>();

    void update(int idx, int l, int r, int ql, int qr) {
        if (r < ql || qr < l) return;  // 闭区间
        if (ql <= l && r <= qr) {
            tree.put(idx, tree.getOrDefault(idx, 0) + 1);
            lazy.put(idx, lazy.getOrDefault(idx, 0) + 1);
            return;
        }
        int mid = (l + r) >> 1;
        update(idx * 2,     l,      mid, ql, qr);
        update(idx * 2 + 1, mid + 1, r,  ql, qr);
        tree.put(idx,
            lazy.getOrDefault(idx, 0)
            + Math.max(tree.getOrDefault(idx * 2, 0),
                       tree.getOrDefault(idx * 2 + 1, 0)));
    }
}
```

核心巧妙点：
- 用 `2*idx` / `2*idx+1` 隐式编码父子关系（同数组表示法），无需 left/right 指针
- 用 HashMap 实现动态扩容，只存被访问到的 idx
- lazy 不下发物理节点，回溯时直接从 lazy Map 取值

### 四种实现方式对比

| 特性 | 方式一（指针预建） | 方式二（数组预建） | 方式三（指针动态） | 方式四（HashMap动态） |
|:----:|:----------------:|:----------------:|:-----------------:|:--------------------:|
| 需要预知范围 | ✅ | ✅ | ❌ | ❌ |
| 空间 | O(N) 节点+指针 | O(4R) 连续数组 | O(N log R) 节点+指针 | O(N log R) Map条目 |
| 代码复杂度 | 低 | 中 | 中 | 低 |
| 适用场景 | 数据已知、N 小 | 值域已知且小 | 值域大、动态数据 | 值域大、动态数据 |

## 预建树 vs 动态开点的思维差异

在预建树的题目（如 315. 计算右侧小于当前元素的个数、3459. 分离正方形面积）中，所有数据都能在初始化时获得（离散化或直接已知范围），套路是：

> **先确定范围 → 建树（数组或 Node[]）→ 再更新/查询**

而动态开点面临的是数据**动态流入**的场景（如 732. 我的日程安排表 III），无法在初始时获知全集。必须切换为：

> **递归参数携带区间 [l, r)，遇到需要递归的节点时才 new Node()**

这要求逻辑上始终持有"值域全局视角"（如 root 代表 [0, 10⁹]），但物理上只创建走过的路径。**按中点固定切分**保证了树的高度始终为 O(log R)，与数据分布无关。

## 代码案例（含懒标记）

### 案例一：区间更新 + 懒标记（扫描线求矩形并集面积）

> 代码见 `SeparateSquares.Solution3`，扫描线算法 + 线段树维护 x 轴被覆盖的总宽度。

```java
class SegmentTree {
    static class Node {
        int l, r;
        int value;   // 当前区间被覆盖的总宽度
        int lazy;    // 懒标记：当前区间出现次数
        Node left, right;

        Node(int l, int r) { this.l = l; this.r = r; }
    }

    Node root;
    int[] xs;  // 离散化的 x 坐标

    public SegmentTree(Set<Integer> xSet) {
        xs = xSet.stream().sorted().mapToInt(Integer::intValue).toArray();
        root = build(0, xs.length - 2);
    }

    private Node build(int l, int r) {
        if (l > r) return null;
        Node node = new Node(l, r);
        if (l == r) return node;
        int mid = (l + r) / 2;
        node.left = build(l, mid);
        node.right = build(mid + 1, r);
        return node;
    }

    public void update(int ql, int qr, int val) {
        update(root, ql, qr, val);
    }

    private void update(Node node, int ql, int qr, int val) {
        if (node == null) return;
        int xL = xs[node.l], xR = xs[node.r + 1];
        if (xR < ql || xL > qr) return;
        if (xL >= ql && xR <= qr) {
            node.lazy += val;  // 懒标记累加
        } else {
            update(node.left, ql, qr, val);
            update(node.right, ql, qr, val);
        }
        if (node.lazy > 0) {
            node.value = xR - xL;  // 被完全覆盖
        } else if (node.l == node.r) {
            node.value = 0;         // 叶子节点且未覆盖
        } else {
            node.value = (node.left == null ? 0 : node.left.value) +
                         (node.right == null ? 0 : node.right.value);
        }
    }

    public int queryTotal() {
        return root.value;  // 当前被覆盖的总宽度
    }
}
```

> 代码见 `CountSmaller.solution3`，数组实现 + 离散化。

### 案例三：动态开点 + 区间更新（日程安排表 III）

> 代码见 `MyCalendarThree.solution3` / `solution4`，值域 [0, 10⁹]，动态开点线段树。

每次 `book(start, end)` 对区间 `[start, end)` 做 +1，返回全局最大值：

```java
class SegmentTree {
    class Node {
        Node left, right;
        int count, lazy;
    }
    Node root = new Node();

    void update(Node node, int l, int r, int ql, int qr) {
        if (ql >= r || qr <= l) return;
        if (ql <= l && r <= qr) {
            node.count++; node.lazy++; return;
        }
        int mid = l + (r - l) / 2;
        if (node.left == null)  node.left  = new Node();
        if (node.right == null) node.right = new Node();
        pushDown(node);
        update(node.left,  l, mid, ql, qr);
        update(node.right, mid, r,  ql, qr);
        node.count = Math.max(node.left.count, node.right.count) + node.lazy;
    }

    void pushDown(Node node) {
        if (node.lazy == 0) return;
        node.left.count  += node.lazy;
        node.left.lazy   += node.lazy;
        node.right.count += node.lazy;
        node.right.lazy  += node.lazy;
        node.lazy = 0;
    }
}
```

**与案例一的区别**：
- 案例一需预知所有 x 坐标离散化，建树时确定范围
- 本案例值域 10⁹ 无法离散化，必须动态开点，节点在递归过程中按需创建
