## 文件说明

| 文件 | 作用 | 维护方式 |
|---|---|---|
| `算法知识图谱.md` | 模块与子专题内容，含必/进/了分级与笔记落点 | 内容变更时才改，不写状态与题目 |
| `掌握度与薄弱点.md` | 96 项掌握度矩阵、17 条薄弱点、证据与待确认事项 | 每次学习后增量更新证据与状态 |
| `学习计划.md` | 复习（R/C 组）与新学（N 组）任务清单 | 完成一项改一项状态，P0 完成后从 P1 补位 |

## 维护规则

1. 用户确认过的掌握度，不自动覆盖。
2. 计划不绑日期、不绑每周时长、不绑具体题目；任务粒度是「专题 + 产出 + 完成标准」。
3. P0 同时进行不超过 5 项。
4. 新增专项前先并入知识图谱，再进学习计划。
5. 长期未更新时提示重新评估，但不擅自重排。
