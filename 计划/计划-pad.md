# 计划-pad（移动端草稿本）

> 用途：只在当前设备上记录「计划与掌握度」的完善过程，**不直接修改** `学习计划.md`、`掌握度与薄弱点.md`、`算法知识图谱.md`。
> 回填时机：回到电脑上统一合并；合并完成后在本文件末尾的「回填记录」里登记，并给对应条目打上 `已回填`。
> 建立日期：2026-11-09

## 使用约定

1. **只追加，不改历史记录**。写错了就新写一条更正，不覆盖前面的内容。
2. 每条记录必须有：日期 + 涉及编号（R01 / N03 / C02 / 专题名）+ 本次做了什么。
3. 掌握度只写「我自我感觉到了哪一步 + 证据」，不写「已掌握」——最终判定回电脑上做。
4. 不在这里重排优先级、不改 P0 名额；只记录依据，回电脑上再决定。
5. 一次记录只对应一个专题，避免一条记录里混多个主题。

## 单条记录模板

```
### YYYY-MM-DD [编号] 专题名

- 本次做了：
- 关键结论：
- 卡点 / 薄弱点：
- 证据（题号、能否复述、能否默写）：
- 待回填：学习计划.md 的状态 / 掌握度与薄弱点.md 的证据 / 知识图谱是否要增删子专题
```
