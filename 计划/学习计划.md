# 学习计划

> 目标：面试 + 系统补全
> 依据：`算法知识图谱.md`（96 项应掌握）、`掌握度与薄弱点.md`（33 已掌握 / 26 熟悉 / 15 薄弱 / 22 未开始）
> 更新时间：2026-11-14
> 说明：纯优先级清单，不按周、不绑日期、不绑每周时长；任务粒度是「专题 + 指定 LeetCode 题目 + 产出 + 完成标准」，每道题都是 LeetCode 真实题目

## 使用规则

1. **P0 同时进行不超过 5 项**，完成一项再从 P1 补位。
2. **复习优先于新学**：复习任务先收尾，再推进新学。
3. **「指定题目」是固定练习清单，不再是参考样例**。R / C 组取自已掌握或熟悉的题目，用于复现与默写；N 组为待练题目。如需替换，必须是同专题的 LeetCode 真题，并同步改本表。
4. 每完成一项，回填本表状态，并同步 `掌握度与薄弱点.md` 的证据。
5. 完成一批 P0 后复盘一次；长期未更新会提示重新评估。
6. 已掌握（33 项）不占日常时间，只做周期性抽查（C 组）。
7. 所有题号已按 LeetCode 中文站题库逐个校验：真实存在、题号与题目对应、均为免费题；题名以 LeetCode 中文站为准，已登记过的题沿用 `汇总/解题记录.md` 的题名。
