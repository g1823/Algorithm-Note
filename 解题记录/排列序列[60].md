# 排列序列 [60]

## 1. 解题思路

**问题**：给定 n 和 k，返回 1~n 所有排列按字典序排序后的第 k 个排列。

**核心难点**：不能生成所有排列再取第 k 个（n 最大 9，9! = 362880，可暴力但非最优）。应直接定位。

**核心思想：阶乘分组**

对于 n 个数字，固定首位后，剩余的 (n-1) 个数字有 (n-1)! 种排列。这些排列天然分成 n 组，每组大小 = (n-1)!。

- 每组大小 `size = (剩余数字 - 1)!`
- 第 k 个排列落在第 `k / size` 组
- 进入该组后继续定位：`k %= size`

**关键细节：k 要减一**  
题目中 k 是 1-based（第 1 个、第 2 个...），但数组下标、除法分组天然是 0-based。必须 `k--` 转换。

## 2. 代码实现

```java
/**
 * 60. 排列序列 — 阶乘分组 + 模拟构造
 *
 * 核心思路：
 * 固定当前位后，剩余数字的排列数为 (m-1)!。
 * k / (m-1)! 确定当前位选剩余数字中的第几个。
 * k % (m-1)! 进入下一层继续。
 *
 * 时间复杂度 O(n²)，空间 O(n)
 */
public String getPermutation(int n, int k) {
    // 预处理阶乘：factorial[i] = i!
    int[] factorial = new int[n];
    factorial[0] = 1;
    for (int i = 1; i < n; i++) {
        factorial[i] = factorial[i - 1] * i;
    }

    // nums[i] == 0 表示数字 i 未使用，1 表示已使用
    int[] nums = new int[n + 1];
    StringBuilder sb = new StringBuilder();

    // 关键：1-based → 0-based
    k--;

    // 逐位确定答案
    for (int i = 0; i < n; i++) {
        // 当前块大小 = (剩余数字数 - 1)!
        int size = factorial[n - i - 1];

        // 当前位应选剩余数字中的第 index 个（0-based）
        int index = k / size;

        // 进入当前块继续定位
        k %= size;

        // 从小到大找第 index 个未使用数字
        for (int j = 1; j <= n; j++) {
            if (nums[j] == 0) {
                if (index == 0) {
                    nums[j] = 1;
                    sb.append(j);
                    break;
                }
                index--;
            }
        }
    }
    return sb.toString();
}
```

## 3. 踩坑记录

- **k 不减一会出错**：第 1 个排列在 0-based 中对应下标 0，第 n! 个对应下标 n!-1。若 `k--` 漏掉，分组计算会偏移一个块。
- **阶乘溢出**：n≤9 时阶乘在 int 范围内，安全。若 n 更大需用 long 或数学解法。
