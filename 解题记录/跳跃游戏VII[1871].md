# 跳跃游戏 VII [1871]

## 1. 解题思路

**问题**：给定二进制字符串 `s`（'0' 可跳，'1' 不可跳），以及跳的步数范围 `[minJump, maxJump]`。从下标 0 出发，判断能否到达末尾。

**核心难点**：朴素 DP 的区间遍历是 O(n²)，会超时。需要优化"判断区间内是否存在可达点"这一步。

**核心思想：DP + 区间优化**

定义 `dp[i]`：下标 i 是否可达。

状态转移：`dp[i] = 存在 j ∈ [i-maxJump, i-minJump] 使得 dp[j] = true`

关键是：不需要知道区间内**哪些**位置可达，只需要知道**是否有**可达位置。

### 优化方案一：前缀和优化

维护 `pre[i]`：`[0, i]` 范围内可达元素个数。
- `dp[i] = (pre[right] - pre[left-1]) > 0` — O(1) 查询

### 优化方案二：滑动窗口优化

区间 `[i-maxJump, i-minJump]` 随 i 增加而整体右移，可用滑动窗口动态维护窗口内可达点数量。

## 2. 代码实现

### 前缀和版本

```java
/**
 * DP + 前缀和优化：O(n) 时间，O(n) 空间
 */
public boolean canReach(String s, int minJump, int maxJump) {
    int n = s.length();
    int[] dp = new int[n];
    int[] pre = new int[n];
    dp[0] = 1;
    pre[0] = 1;
    char[] chars = s.toCharArray();

    for (int i = 1; i < n; i++) {
        if (chars[i] == '0') {
            int left = i - maxJump;
            int right = i - minJump;
            if (right >= 0) {
                int leftCount = left > 0 ? pre[left - 1] : 0;
                if (pre[right] - leftCount > 0) {
                    dp[i] = 1;
                }
            }
        }
        pre[i] = pre[i - 1] + dp[i];
    }
    return dp[n - 1] > 0;
}
```

### 滑动窗口版本

```java
/**
 * DP + 滑动窗口优化：O(n) 时间
 */
public boolean canReach2(String s, int minJump, int maxJump) {
    int n = s.length();
    char[] chars = s.toCharArray();
    int[] dp = new int[n];
    dp[0] = 1;
    int reachable = 0;  // 窗口内可达点数量

    for (int i = 1; i < n; i++) {
        // 窗口右端进入新元素
        int addIndex = i - minJump;
        if (addIndex >= 0 && chars[addIndex] == '0') {
            reachable += dp[addIndex];
        }
        // 窗口左端移出元素
        int removeIndex = i - maxJump - 1;
        if (removeIndex >= 0 && chars[removeIndex] == '0') {
            reachable -= dp[removeIndex];
        }
        // 判断当前位置是否可达
        if (chars[i] == '0' && reachable > 0) {
            dp[i] = 1;
        }
    }
    return dp[n - 1] == 1;
}
```

## 3. 踩坑记录

- **前缀和的边界**：`left = i - maxJump` 可能为负数，此时 `leftCount = 0`
- **滑动窗口的 removeIndex**：窗口左端移出的是 `i - maxJump - 1`，需要 `-1` 因为 `i - maxJump` 还在窗口内
- **字符串中的 '1' 不可跳**：判断可达后仍需确认 `chars[i] == '0'`

## 4. 技巧总结

- 核心思维提升：**当 DP 状态转移依赖区间时，不要直接 for 遍历区间，先思考真正需要区间里的什么信息**（和、个数、是否存在、最大值等），再用前缀和/滑动窗口/单调队列优化
