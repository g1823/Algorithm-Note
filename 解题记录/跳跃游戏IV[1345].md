# 跳跃游戏 IV [1345]

## 1. 解题思路

**问题**：给定数组 `arr`，从下标 0 出发。每一步可以：
1. 跳到任意相同值的位置 `arr[i] == arr[j]`
2. 向左/右跳一步

求到达最后一个位置的最少步数。

**核心难点**：相同值的跳转能一步跳到任意位置，若朴素处理，每个相同值都要遍历，可能达到 O(n²)。

**核心思想：图论建模 + BFS**

将数组索引视为图的节点：
- 相同值的节点之间存在边
- 相邻节点之间存在边
- 问题转化为：无权图中从节点 0 到节点 n-1 的最短路径 → **BFS 层序遍历**

**优化策略**：
1. **值→索引映射**：用 `HashMap<值, List<索引>>` 快速找到相同值的位置
2. **清除已访问映射**：处理完某个值的所有索引后，立即 `clear()` 该值的列表，防止后续重复遍历

## 2. 代码实现

```java
/**
 * 1345. 跳跃游戏 IV — BFS + 哈希表优化
 *
 * 时间复杂度 O(n)：每个节点最多入队一次，每条"同值边"只触发一次
 * 空间复杂度 O(n)
 */
public int minJumps(int[] arr) {
    // 值 → 索引列表 映射
    Map<Integer, List<Integer>> map = new HashMap<>();
    for (int i = 0; i < arr.length; i++) {
        map.putIfAbsent(arr[i], new ArrayList<>());
        map.get(arr[i]).add(i);
    }

    int[] visited = new int[arr.length];
    Queue<Integer> queue = new LinkedList<>();
    queue.add(0);
    visited[0] = 1;
    int res = 0;

    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int cur = queue.poll();

            // 到达目标
            if (cur == arr.length - 1) return res;

            // 左跳
            if (cur > 0 && visited[cur - 1] == 0) {
                queue.add(cur - 1);
                visited[cur - 1] = 1;
            }
            // 右跳
            if (cur < arr.length - 1 && visited[cur + 1] == 0) {
                queue.add(cur + 1);
                visited[cur + 1] = 1;
            }
            // 同值跳转：遍历所有相同值的索引
            for (int j : map.get(arr[cur])) {
                if (visited[j] == 0) {
                    queue.add(j);
                    visited[j] = 1;
                }
            }
            // ★ 关键优化：清除映射，避免后续重复遍历
            map.get(arr[cur]).clear();
        }
        res++;
    }
    return res;
}
```

## 3. 踩坑记录

- **同值跳转不能省略 clear**：若有 1000 个相同值，不清除则每次遇到该值都遍历 1000 个索引 → O(n²) → 超时
- **visited 标记时机**：入队时就标记（而非出队时），否则同一节点可能被多次入队
- **左跳/右跳也要检查 visited**：否则可能无限循环（如 [7,7,7,7] 可以来回跳）

## 4. 技巧总结

- 这道题展示了如何将**数组跳跃问题建模为图的最短路径** → BFS
- 属于 [搜索法](../算法思想/搜索法.md) 的图论建模
- **清除 visited 映射**是这类"值→索引"BFS 问题的经典优化（如单词接龙也类似）
