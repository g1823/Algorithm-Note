# 最早完成时间 I [3633]

## 1. 解题思路

**问题**：给定两类游乐设施的开放时间和游玩时长，选择先玩一类再玩另一类，求最早完成时间。

**核心难点**：朴素枚举"先玩哪个 + 再玩哪个"是 O(n×m)，需要优化。

**核心洞察：单调性分析 → 只需保留极值**

设先玩第一类项目，结束时间 `finish1 = start1 + duration1`。

再玩第二类项目时，最终完成时间：
```
finish2 = max(finish1, start2) + duration2
```

对于固定的第二类项目，`duration2` 和 `start2` 是常量，`max(finish1, start2)` **随 finish1 的增大单调不减**。

因此：
> 选择更晚结束的第一类项目，不可能让最终完成时间更早。

**结论**：第一类项目只需保留**最早结束时间**，不用枚举所有。将 O(n×m) 降为 O(n+m)。

### 贪心成立的三要素验证

1. **局部决策**：对每个第二类项目，选最早结束的第一类项目
2. **单调性保证**：`max(x, start2)` 对 x 单调不减 → 局部最优即全局最优
3. **无需回溯**：第一类项目的选择不依赖第二类

## 2. 代码实现

```java
/**
 * 3633. 最早完成时间 I — 贪心（只需保留极值）
 *
 * 核心思路：对于固定的第二类项目，finish1 越小，max(finish1, start2) 越小。
 * 因此第一类项目只需保留最早结束时间。
 */
public int earliestFinishTime(int[] landStartTime, int[] landDuration,
        int[] waterStartTime, int[] waterDuration) {
    // 两种顺序：先陆地后水上 / 先水上后陆地
    int landFirst = getMinTime(landStartTime, landDuration, waterStartTime, waterDuration);
    int waterFirst = getMinTime(waterStartTime, waterDuration, landStartTime, landDuration);
    return Math.min(landFirst, waterFirst);
}

private int getMinTime(int[] firstStart, int[] firstDur,
        int[] secondStart, int[] secondDur) {
    // 第一步：找第一类项目的最早结束时间
    int firstMin = firstStart[0] + firstDur[0];
    for (int i = 1; i < firstStart.length; i++) {
        int finish = firstStart[i] + firstDur[i];
        if (finish < firstMin) firstMin = finish;
    }

    // 第二步：枚举第二类项目，取最终结束时间的最小值
    int result = Integer.MAX_VALUE;
    for (int i = 0; i < secondStart.length; i++) {
        result = Math.min(result, Math.max(firstMin, secondStart[i]) + secondDur[i]);
    }
    return result;
}
```

## 3. 踩坑记录

- **不能跳过等待**：`secondStart[i] > firstMin` 时仍需计算 `max(firstMin, secondStart[i])`，因为第二类项目可能尚未开放，需要等待
- **两种顺序都要算**：先陆地后水上 ≠ 先水上后陆地，取两者最小值

## 4. 技巧总结

- 本题展示了贪心法中的**"只需保留极值"**范式：当某变量对决策函数单调时，只需保留该变量的极值，其余值一定不会更优
- 属于 [贪心法](../算法思想/贪心法.md) 的"单调性分析"子技巧
