# 预测赢家 [486]

## 1. 解题思路

**问题**：给定数组 `nums`，两名玩家轮流从数组两端取一个数字，取完为止，数字总和较大者胜。预测先手玩家是否必胜（或不败）。

**核心难点**：零和博弈中，当前选择不仅影响当前得分，还影响对手后续的选择空间。需要同时考虑自己和对手的最优策略。

**核心思想：博弈 DP（区间 DP）**

定义 `dp[l][r]`：在区间 `[l, r]` 内，**当前玩家**相对于对手最终能领先多少分。

由于是零和博弈：**当前玩家获得的优势 = 当前拿到的分数 - 对手后续能获得的优势**。

**状态转移**：
- 选左边：`nums[l] - dp[l+1][r]`（对手在 `[l+1, r]` 上领先多少，取负即为我的优势）
- 选右边：`nums[r] - dp[l][r-1]`
- 当前玩家选最大值：`dp[l][r] = max(nums[l] - dp[l+1][r], nums[r] - dp[l][r-1])`

**初始化**：`dp[i][i] = nums[i]`（只有一个数字，直接拿走）

**最终判断**：`dp[0][n-1] >= 0` 表示先手至少不输。

## 2. 代码实现

```java
/**
 * 486. 预测赢家 — 博弈 DP（区间 DP）
 *
 * dp[l][r] = max(nums[l] - dp[l+1][r], nums[r] - dp[l][r-1])
 *
 * 时间复杂度 O(n²)，空间复杂度 O(n²)
 */
public boolean PredictTheWinner(int[] nums) {
    int n = nums.length;
    int[][] dp = new int[n][n];

    // 初始化：长度为 1 的区间
    for (int i = 0; i < n; i++) {
        dp[i][i] = nums[i];
    }

    // 按区间长度填表（斜线方向）
    for (int len = 1; len < n; len++) {
        for (int l = 0; l + len < n; l++) {
            int r = l + len;
            dp[l][r] = Math.max(
                nums[l] - dp[l + 1][r],
                nums[r] - dp[l][r - 1]
            );
        }
    }

    return dp[0][n - 1] >= 0;
}
```

## 3. 踩坑记录

- **状态定义容易混淆**：`dp[l][r]` 是**当前玩家**的优势，而非全局先手或后手的特定视角。理解"当前玩家"这个角色是理解博弈 DP 的关键。
- **dp 含义不是得分**：`dp[l][r]` 不是当前玩家的原始得分，而是**相对于对手的净胜分**。因此转移公式是 `num - dp[next]` 而非 `num + dp[next]`。
- **填表顺序**：当前状态依赖更小区间，必须按区间长度从小到大填表（斜线方向）。

## 4. 技巧总结

- **博弈 DP** 的核心范式：`dp = max(拿到的 - 对手在剩下区间的优势)`
