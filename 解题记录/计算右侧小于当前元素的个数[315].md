# 计算右侧小于当前元素的个数 [315]

## 1. 解题思路

### 问题描述

给定一个整数数组 `nums`，返回一个新数组 `counts`，其中 `counts[i]` 是 `nums[i]` 右侧小于 `nums[i]` 的元素个数。

### 核心难点

暴力解法 O(n²) 显然可行，但需要优化到 O(n log n)。关键在于如何在不重复比较的前提下，统计每个元素右侧比它小的元素数量。

三个核心转化点：

1. **从右往左遍历** → "右侧" → "已遍历过的元素中更小的" → 动态维护集合
2. **集合需要支持**：插入元素 + 查询比当前值小的元素个数 → 数据结构问题
3. **排序思路**：归并过程中统计逆序关系

### 四种解法

**解法一：归并排序（O(n log n)，推荐）**

本质：在排序过程中统计"右半部分比左半部分元素先进入"的次数。

核心洞察：归并排序的 merge 过程中，当右半部分的元素先进入结果数组时，意味着左半部分所有未处理的元素都遇到一个"右侧更小元素"。

**解法二：树状数组（O(n log n)）**

从右往左遍历，用树状数组维护频率分布：
- 离散化原数组为 1~n 的排名
- 查询 `query(rank - 1)` 得到比当前小的已遍历元素数
- 更新 `add(rank, 1)`

**解法三：线段树（指针实现，O(n log n)）**

与树状数组思路相同，但用真正的二叉树线段树实现。

**解法四：线段树（数组实现，O(n log n)）**

用 4n 数组隐式表示完全二叉树。

## 2. 代码实现

### 解法一：归并排序（推荐，最优解）

```java
public List<Integer> countSmaller(int[] nums) {
    int[] temp = new int[nums.length];
    int[] resultNum = new int[nums.length];
    for (int i = 0; i < nums.length; i++) {
        temp[i] = i;
    }
    mergeSort(nums, temp, 0, nums.length - 1, resultNum);
    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < resultNum.length; i++) {
        result.add(resultNum[i]);
    }
    return result;
}

private int[] mergeSort(int[] nums, int[] temp, int left, int right, int[] result) {
    if (left >= right) {
        return new int[]{temp[left]};
    }
    int mid = left + (right - left) / 2;
    int[] leftSortNums = mergeSort(nums, temp, left, mid, result);
    int[] rightSortNums = mergeSort(nums, temp, mid + 1, right, result);

    int[] mergeNums = new int[right - left + 1];
    int i = 0, l = 0, r = 0, count = 0;
    while (l < leftSortNums.length && r < rightSortNums.length) {
        if (nums[leftSortNums[l]] <= nums[rightSortNums[r]]) {
            int idx = leftSortNums[l];
            mergeNums[i++] = idx;
            l++;
            // 右侧已有 count 个元素先进入结果
            // 这些元素都在左侧当前元素右边且比它小
            result[idx] += count;
        } else {
            mergeNums[i++] = rightSortNums[r++];
            // 右侧一个更小元素先进入，左侧未处理元素各加 1
            count++;
        }
    }
    while (l < leftSortNums.length) {
        int idx = leftSortNums[l];
        mergeNums[i++] = idx;
        l++;
        result[idx] += count;
    }
    while (r < rightSortNums.length) {
        mergeNums[i++] = rightSortNums[r++];
    }
    return mergeNums;
}
```

**关键技巧**：
- 排序的是下标数组 `index[]`，不是原数组 `nums[]`，排序过程中通过 `nums[index[i]]` 比较值，通过 `result[index[i]]` 更新答案
- `rightCount` 记录右侧已经进入 merge 数组的元素个数，等价于"当前左侧元素遇到了多少个比自己小的右侧元素"
- 必须使用 `<=` 保证稳定性，避免相等元素被错误统计

### 解法二：树状数组

```java
public List<Integer> countSmaller(int[] nums) {
    // 1. 离散化
    Set<Integer> set = new HashSet<>();
    for (int num : nums) set.add(num);
    int[] sortedNums = set.stream().sorted().mapToInt(Integer::intValue).toArray();
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < sortedNums.length; i++) {
        map.put(sortedNums[i], i + 1);
    }

    // 2. 从右往左遍历，树状数组维护频率
    int[] tree = new int[sortedNums.length + 1];
    List<Integer> result = new ArrayList<>();
    for (int i = nums.length - 1; i >= 0; i--) {
        int index = map.get(nums[i]);
        result.add(query(tree, index - 1));  // 查询比当前小的个数
        add(tree, index);                     // 当前元素加入树状数组
    }
    Collections.reverse(result);
    return result;
}

private void add(int[] tree, int index) {
    while (index < tree.length) {
        tree[index]++;
        index += index & -index;
    }
}

private int query(int[] tree, int index) {
    int sum = 0;
    while (index > 0) {
        sum += tree[index];
        index -= index & -index;
    }
    return sum;
}
```

### 解法三：线段树（指针）

```java
class SegmentTree {
    class Node {
        int l, r, count;
        Node left, right;
        public Node(int l, int r, int count) {
            this.l = l; this.r = r; this.count = count;
        }
    }

    Node root;
    public SegmentTree(int n) {
        root = build(1, n);
    }

    private Node build(int l, int r) {
        if (l == r) return new Node(l, l, 0);
        Node node = new Node(l, r, 0);
        int mid = l + (r - l) / 2;
        node.left = build(l, mid);
        node.right = build(mid + 1, r);
        return node;
    }

    public void update(int index) {
        update(root, index);
    }

    private void update(Node node, int index) {
        if (node.l > index || node.r < index) return;
        if (node.l == node.r) {
            node.count++;
            return;
        }
        int mid = node.l + (node.r - node.l) / 2;
        if (index <= mid) update(node.left, index);
        else update(node.right, index);
        node.count = node.left.count + node.right.count;
    }

    public int query(int l, int r) {
        return query(root, l, r);
    }

    private int query(Node node, int l, int r) {
        if (node.l > r || node.r < l) return 0;
        if (node.l >= l && node.r <= r) return node.count;
        return query(node.left, l, r) + query(node.right, l, r);
    }
}

public List<Integer> countSmaller(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int num : nums) set.add(num);
    int[] sortedNums = set.stream().sorted().mapToInt(Integer::intValue).toArray();
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < sortedNums.length; i++) {
        map.put(sortedNums[i], i + 1);
    }

    SegmentTree segmentTree = new SegmentTree(sortedNums.length);
    List<Integer> result = new ArrayList<>();
    for (int i = nums.length - 1; i >= 0; i--) {
        int index = map.get(nums[i]);
        result.add(segmentTree.query(1, index - 1));
        segmentTree.update(index);
    }
    Collections.reverse(result);
    return result;
}
```

### 解法四：线段树（数组）

```java
class SegmentTree {
    int[] tree;
    int n;

    public SegmentTree(int n) {
        this.n = n;
        tree = new int[4 * n];
    }

    public void update(int index) {
        update(1, 1, n, index);
    }

    private void update(int node, int start, int end, int key) {
        if (start == end) {
            tree[node]++;
            return;
        }
        int mid = (start + end) / 2;
        if (key <= mid) update(node * 2, start, mid, key);
        else update(node * 2 + 1, mid + 1, end, key);
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    public int query(int l, int r) {
        return query(1, 1, n, l, r);
    }

    private int query(int node, int start, int end, int l, int r) {
        if (start > r || end < l) return 0;
        if (l <= start && end <= r) return tree[node];
        int mid = (start + end) / 2;
        return query(node * 2, start, mid, l, r) +
               query(node * 2 + 1, mid + 1, end, l, r);
    }
}
```

## 3. 踩坑记录

- **树状数组必须 1-based**：`lowbit(0) = 0`，如果用 0 会死循环。离散化映射时从 1 开始。
- **归并排序的稳定性**：比较时必须用 `<=` 而非 `<`。相等时让左元素先进入，否则会错误地把相等元素统计为"更小元素"。
- **归并排序的是下标而非值**：排序过程中元素位置会变，需要通过下标中间数组找到原始位置。
- **离散化时去重**：不去重会导致相同值的排名不同，影响统计正确性。哈希去重后排序再映射。
- **线段树数组大小 4n**：完全二叉树最多 4n-1 个节点，取 4n 安全。
- **树状数组数组大小 n+1**：下标从 1 开始，需要多一个位置。

## 4. 技巧总结

### 归并排序技巧
- 排序过程不仅可以排序，还可以附带统计信息（逆序对、右侧更小等）
- 排序下标数组是固定套路：需要保持"原始位置"和"排序后顺序"的对应关系

### 树状数组技巧
- 树状数组在需要**动态维护前缀和**的场景下极其高效
- 与线段树的对比：树状数组代码更短、常数更小，但只能处理前缀可合并的问题（和、积、异或等）
- 本质是**二进制拆分区间**：每个节点管理 `[x - lowbit(x) + 1, x]`

### 算法思想关联
- 归并排序解法本质：**分治法** —— 排序 + 统计
- 树状数组/线段树解法本质：**动态维护频率分布** —— 从右往左遍历，将"右侧"转化为"已遍历"

## 5. 思考过程

### 从蛮力到优化的完整推导

**第一步：暴力 O(n²) 到数据结构优化**

最直觉的做法是双重循环，对每个元素遍历右侧全部元素。这显然低效。

问题转化为：能否在遍历过程中维护一个"右侧元素集合"，支持快速查询"集合中有多少元素小于当前值"？

可选的动态集合数据结构：
- 有序数组 + 二分 ⟹ 插入 O(n)，太慢
- 平衡 BST ⟹ O(log n)，实现复杂
- 树状数组/线段树 ⟹ O(log n)，代码简洁

**第二步：从右往左的视角切换**

顺着"维护右侧集合"的思路，从右往左遍历：
- 当遍历到 `nums[i]` 时，已经遍历过的元素正好就是 `nums[i]` 右侧的所有元素
- 对每个新元素，只需查询"已遍历元素中比当前值小的个数"
- 这样就彻底转化成了**动态频率统计**问题

此时树状数组/线段树方案已经呼之欲出。

**第三步：归并排序的发现**

在实现树状数组/线段树后，发现本题在 LeetCode 的标签中有"归并排序"。最初的疑问是：归并排序怎么统计右侧更小？

关键洞察：
- 在归并排序的 merge 过程中，左半部分对应原数组左侧，右半部分对应原数组右侧
- 当右半部分的某个元素先于左半部分元素进入 merge 结果时，说明：这个右侧元素比左半部分所有未处理的元素都小
- 每发生一次"右侧先进入"，左侧未处理的元素就多一个"右侧更小元素"

**第四步：从归并进一步理解**

归并排序解法最巧妙的地方在于：**不需要显式维护"右侧集合"**，排序过程本身就在隐式地进行统计。这让代码非常简洁，且自带 O(n log n) 复杂度。

这也揭示了本题的本质：**在排序过程中统计逆序关系**。与以下问题是同类：
- 逆序对问题
- 493. 翻转对
- 327. 区间和的个数
