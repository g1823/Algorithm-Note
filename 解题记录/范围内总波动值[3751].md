# 范围内总波动值 [3751]

> LeetCode 3751. 范围内总波动值 I & 3753. 范围内总波动值 II
>
> 难度：中等 / 困难（二者解法一致，仅数据范围不同）

## 1. 解题思路

### 1.1 问题理解

**波动值定义**：把数字写成十进制形式，每一位和它左右相邻位比较：
- 若某位比左边小且比右边小 → 称为**谷**，贡献 1
- 若某位比左边大且比右边大 → 称为**峰**，贡献 1
- 首位和末位不参与比较

例如数字 130：
```
1  3  0
  ↙↘
  峰：3 > 1 且 3 > 0 → 波动值 = 1
```

要求：计算区间 `[num1, num2]` 内**所有数字的波动值之和**。

### 1.2 核心难点

1. **范围极大**：num 最大可达 10^15，无法逐个数字计算
2. **条件跨位**：一个数位是否为峰/谷，依赖于左右两个邻居，不能孤立判断
3. **前导零陷阱**：对于位数少于 n 的数字（如 25 = "25"），前导零不应参与峰谷判断

### 1.3 解法选择

这是典型的**区间统计 + 数位相关条件**问题，满足数位DP的三要素：
- 区间统计（可用前缀和相减）
- 条件基于数位（峰/谷判断依赖相邻位）
- 范围大（需要按位处理）

**核心公式**：
```
ans(num1, num2) = calc(num2) - calc(num1 - 1)
```

这样只需要实现 `calc(n)`：计算 `[0, n]` 内所有数字的总波动值。

### 1.4 状态设计

| 参数 | 含义 | 说明 |
|------|------|------|
| `pos` | 当前处理到第几位（0-indexed，从左到右） | 递归出口：pos == n |
| `pre` | 最近一个有效数字（-1 表示暂无） | 用于判断峰谷 |
| `pre2` | 倒数第二个有效数字（-1 表示暂无） | 与 pre、当前 digit 形成三元组 |
| `limit` | 当前前缀是否与上界 n 一致 | `true` → 当前位最多取 n[pos]；`false` → 可取 0~9 |
| `leadZero` | 当前是否仍处于前导零 | 前导零阶段 pre/pre2 不更新为真实数字 |

### 1.5 转移过程

```
枚举当前位 digit ∈ [0, up]：
  1. 计算新状态：
     newLimit = limit && digit == up
     newLeadZero = leadZero && digit == 0
     newPre = newLeadZero ? -1 : digit
     newPre2 = pre

  2. 递归得子结果：
     (childCount, childSum) = dfs(pos+1, newPre, newPre2, newLimit, newLeadZero)

  3. 判断 pre 是否为峰/谷（前提：!leadZero, pre != -1, pre2 != -1）：
     若 pre2 > pre && pre < digit → 谷 → sum += childCount
     若 pre2 < pre && pre > digit → 峰 → sum += childCount

  4. 累加：
     count += childCount
     sum += childSum
```

**关键理解**：当 `pre` 形成峰/谷时，这个贡献对后续**每一个合法数字**都生效，所以贡献值 = `1 × childCount`。

### 1.6 记忆化条件

只有当 `!limit && !leadZero && pre != -1 && pre2 != -1` 时才缓存。因为此时后续状态只依赖 `(pos, pre, pre2)`，与具体前缀无关。

### 1.7 图例：DFS 枚举树

以 n = 25 为例，数位DP的搜索树如下（简化表示）：

```
                         root(pos=0, limit=true, lead0=true)
                    /         |         |    ...    \
              d=0            d=1                    d=2
        (limit=false,  (limit=false,           (limit=true,
         lead0=true)    lead0=false,             lead0=false,
                        pre=1,pre2=-1)           pre=2,pre2=-1)
              |              |                       |
           d=0~9          d=0~9                   d=0~5
         (全部自由)      (全部自由)              (limit继承)

当 pos=2（末位）时，每个路径形成一个完整数字
```

- 黄色路径（d=2, limit=true → 继续受限）：第二位只能取 0~5
- 绿色路径（d=1, limit=false → 不再受限）：第二位可自由取 0~9
- 蓝色路径（d=0, leadZero=true → 仍在处理前导零）：pre/pre2 都是 -1

## 2. 代码实现

```java
package leetCode.moderately;

import java.util.Arrays;

/**
 * @description: 3751. 范围内总波动值 I
 * @algorithm: 数位DP（Digit DP）+ 前缀和
 */
public class TotalWaviness {

    public int totalWaviness(int num1, int num2) {
        // 利用前缀和思想：f(num1, num2) = f(0, num2) - f(0, num1-1)
        return Math.toIntExact(getWaviness(num2) - getWaviness(num1 - 1));
    }

    private long getWaviness(int num) {
        Waviness waviness = new Waviness(num);
        long[] result = dfs(waviness, 0, -1, -1, true, true);
        return result[1];  // result[0]=count, result[1]=sum
    }

    /**
     * 数位DP的辅助类：封装记忆化数组和上界数位
     */
    class Waviness {
        long[][][] memoCount;  // memoCount[pos][pre][pre2] = 该状态下可构造的数字个数
        long[][][] memoSum;    // memoSum[pos][pre][pre2] = 该状态下所有数字的总波动值
        int[] nums;            // 上界 n 的各位数字
        int n;                 // 位数

        Waviness(int num) {
            char[] chars = String.valueOf(num).toCharArray();
            nums = new int[chars.length];
            for (int i = 0; i < chars.length; i++) {
                nums[i] = chars[i] - '0';
            }
            n = chars.length;
            // 最大15位，pre有10种(0~9)，pre2有10种(0~9)
            memoCount = new long[16][10][10];
            memoSum = new long[16][10][10];
            for (int i = 0; i < 16; i++) {
                for (int j = 0; j < 10; j++) {
                    Arrays.fill(memoCount[i][j], -1);
                    Arrays.fill(memoSum[i][j], -1);
                }
            }
        }
    }

    /**
     * 数位DP的DFS核心函数
     *
     * @param pos      当前处理的位置
     * @param pre      最近一个有效数字（-1表示暂无）
     * @param pre2     倒数第二个有效数字（-1表示暂无）
     * @param limit    当前前缀是否与上界一致（true=不能超过上界对应位）
     * @param leadZero 当前是否仍在处理前导零
     * @return long[2]：{该状态下可构造的数字个数, 这些数字的总波动值}
     */
    private long[] dfs(Waviness waviness, int pos, int pre, int pre2,
                        boolean limit, boolean leadZero) {
        // 递归出口：已处理完所有数位，恰好构造出一个数字
        if (pos == waviness.n) {
            return new long[]{1, 0};
        }

        // 记忆化：只有不受限且已脱离前导零且至少有两个有效数字时才读取缓存
        if (!leadZero && !limit && pre != -1 && pre2 != -1
                && waviness.memoCount[pos][pre][pre2] != -1) {
            return new long[]{
                waviness.memoCount[pos][pre][pre2],
                waviness.memoSum[pos][pre][pre2]
            };
        }

        int up = limit ? waviness.nums[pos] : 9;
        long count = 0;
        long sum = 0;

        for (int digit = 0; digit <= up; digit++) {
            boolean newLimit = limit && digit == up;
            boolean newLeadZero = leadZero && digit == 0;

            // 前导零阶段，pre和pre2不更新（不把前导零当作有效数字）
            int newPre = newLeadZero ? -1 : digit;
            int newPre2 = pre;

            long[] child = dfs(waviness, pos + 1, newPre, newPre2,
                               newLimit, newLeadZero);

            // 判断pre是否为峰/谷（需要三个数字都有效）
            if (!leadZero && pre != -1 && pre2 != -1) {
                // 谷：pre2 > pre && pre < digit
                if (pre2 > pre && pre < digit) {
                    sum += child[0];  // 每个后续数字都有一个谷贡献
                }
                // 峰：pre2 < pre && pre > digit
                if (pre2 < pre && pre > digit) {
                    sum += child[0];  // 每个后续数字都有一个峰贡献
                }
            }

            count += child[0];
            sum += child[1];
        }

        // 写入缓存（条件同读取）
        if (!leadZero && !limit && pre != -1 && pre2 != -1) {
            waviness.memoCount[pos][pre][pre2] = count;
            waviness.memoSum[pos][pre][pre2] = sum;
        }

        return new long[]{count, sum};
    }
}
```

## 3. 踩坑记录

### 3.1 前导零导致 pre/ pre2 错误

**问题**：对于位数少于 num 的数字（如 n=100 时，"25" 这个数字实际表示为 "025"），如果前导 0 被当成有效数字 pre=0，那么会错误地判断 "0 > 2 > 5" 形成峰/谷。

**解决**：使用 `leadZero` 标识，前导零阶段 `pre` 保持 -1，`pre2` 保持 -1，不参与峰谷判断。

### 3.2 记忆化条件不严谨

**问题**：有同学可能只用 `!limit` 作为记忆化条件，忽略了 `leadZero` 的影响。即使 `limit=false`，如果仍在 `leadZero=true` 阶段，pre/pre2 仍然是 -1，后续状态会完全不同。

**解决**：记忆化条件必须是 `!limit && !leadZero && pre != -1 && pre2 != -1`。

### 3.3 贡献值计算

**问题**：当 pre 形成峰/谷时，最初可能想 `sum += 1`，但这只考虑了当前这条路径，忽略了后续递归产生的所有子数字。

**解决**：正确做法是 `sum += childCount`，因为 pre 的峰/谷贡献会出现在当前状态下**每一个**后续数字中。

### 3.4 同时维护上下界的复杂度

**问题**：最初尝试同时维护 `limitLow` 和 `limitHigh`，状态数翻倍，转移复杂。

**解决**：利用前缀和可减性：
```
ans(L, R) = calc(R) - calc(L - 1)
```
只维护单边界，大幅简化。
