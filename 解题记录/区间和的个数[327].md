# 区间和的个数 [327]

## 1. 解题思路

### 问题描述

给定一个整数数组 `nums` 和两个整数 `lower`、`upper`，返回数组中和在 `[lower, upper]` 范围内的子数组个数。

### 核心难点

暴力枚举所有子数组 O(n²) 不可行。关键转化点：

1. **前缀和转化**：`sum[i..j] = prefix[j+1] - prefix[i]`，问题转化为统计满足 `lower ≤ P[j] - P[i] ≤ upper` 的 `(i, j)` 对（i < j）
2. **条件变形**：`P[i] ∈ [P[j] - upper, P[j] - lower]`。对每个 `j`，统计之前有多少个 `P[i]` 落在这个区间内
3. **动态数据结构**：需要在遍历过程中支持"插入一个值 + 查询区间内元素个数"

三种解法解决这个动态统计问题：

| 解法 | 数据结构 | 核心思想 |
|------|----------|---------|
| **线段树** | 线段树 + 离散化 | 权值线段树，单点更新 + 区间查询 |
| **树状数组 BIT** | 树状数组 + 离散化 | 权值树状数组，前缀和差分实现区间查询 |
| **归并排序** | 分治 + 双指针 | 在合并左右有序子数组时统计跨半数对 |

## 2. 代码实现

### 解法一：线段树 + 离散化

```java
class solution {
    public int countRangeSum(int[] nums, int lower, int upper) {
        long[] preSum = new long[nums.length + 1];
        Set<Long> set = new HashSet<>();
        preSum[0] = 0;
        set.add(0L);
        set.add(0L - lower);
        set.add(0L - upper);
        for (int i = 0; i < nums.length; i++) {
            preSum[i + 1] = preSum[i] + nums[i];
            set.add(preSum[i + 1]);
            set.add(preSum[i + 1] - lower);
            set.add(preSum[i + 1] - upper);
        }
        long[] arr = new long[set.size()];
        int index = 0;
        for (Long integer : set) arr[index++] = integer;
        Arrays.sort(arr);
        Map<Long, Integer> map = new HashMap<>();
        for (int i = 0; i < arr.length; i++) map.put(arr[i], i);

        SegmentTree segmentTree = new SegmentTree(arr.length);
        int res = 0;
        for (long sum : preSum) {
            int left = map.get(sum - upper);
            int right = map.get(sum - lower);
            res += segmentTree.query(left, right);
            segmentTree.update(map.get(sum));
        }
        return res;
    }

    class SegmentTree {
        int[] nodes;
        int n;
        SegmentTree(int n) { this.n = n; nodes = new int[n * 4]; }

        void update(int index) {
            if (index < 0 || index >= n) return;
            update(1, 0, n - 1, index);
        }

        private void update(int node, int l, int r, int idx) {
            if (l == r) {
                if (l == idx) nodes[node]++;
                return;
            }
            if (idx < l || idx > r) return;
            int mid = l + (r - l) / 2;
            if (idx <= mid) update(node * 2, l, mid, idx);
            else update(node * 2 + 1, mid + 1, r, idx);
            nodes[node] = nodes[node * 2] + nodes[node * 2 + 1];
        }

        int query(int L, int R) {
            if (L > R || L < 0 || R >= n) return 0;
            return query(1, 0, n - 1, L, R);
        }

        private int query(int node, int l, int r, int ql, int qr) {
            if (l >= ql && r <= qr) return nodes[node];
            if (l > qr || r < ql) return 0;
            int mid = l + (r - l) / 2;
            if (qr <= mid) return query(node * 2, l, mid, ql, qr);
            else if (ql > mid) return query(node * 2 + 1, mid + 1, r, ql, qr);
            else return query(node * 2, l, mid, ql, mid) + query(node * 2 + 1, mid + 1, r, mid + 1, qr);
        }
    }
}
```

**关键点**：
- `query` 在 `update` **之前**：只统计之前已插入的前缀和，不包含当前值
- 离散化收集所有可能查询的值：所有 `P[j]`、`P[j]-upper`、`P[j]-lower`
- 线段树叶子节点代表单个离散化值，存储出现次数

### 解法二：树状数组 BIT + 离散化

```java
class solution2 {
    public int countRangeSum(int[] nums, int lower, int upper) {
        long[] preSum = new long[nums.length + 1];
        Set<Long> set = new HashSet<>();
        preSum[0] = 0;
        set.add(0L);
        set.add(0L - lower);
        set.add(0L - upper);
        for (int i = 0; i < nums.length; i++) {
            preSum[i + 1] = preSum[i] + nums[i];
            set.add(preSum[i + 1]);
            set.add(preSum[i + 1] - lower);
            set.add(preSum[i + 1] - upper);
        }
        long[] arr = new long[set.size()];
        int index = 0;
        for (Long integer : set) arr[index++] = integer;
        Arrays.sort(arr);
        Map<Long, Integer> map = new HashMap<>();
        for (int i = 0; i < arr.length; i++) map.put(arr[i], i);

        int[] tree = new int[arr.length + 1];
        int res = 0;
        for (long sum : preSum) {
            int left = map.get(sum - upper) + 1;
            int right = map.get(sum - lower) + 1;
            res += query(tree, right) - query(tree, left - 1);
            update(tree, map.get(sum) + 1);
        }
        return res;
    }

    private int lowbit(int x) { return x & -x; }

    private void update(int[] tree, int index) {
        while (index < tree.length) {
            tree[index]++;
            index += lowbit(index);
        }
    }

    private int query(int[] tree, int index) {
        int res = 0;
        while (index > 0) {
            res += tree[index];
            index -= lowbit(index);
        }
        return res;
    }
}
```

**关键点**：
- BIT 必须 1-indexed：离散化下标从 0 开始，使用时 +1
- `lowbit(0) = 0`，如果传入 0 会死循环
- 区间查询 = `query(R) - query(L-1)`，利用前缀和差分

### 解法三：归并排序（最优解）

```java
class solution3 {
    public int countRangeSum(int[] nums, int lower, int upper) {
        long[] preSum = new long[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            preSum[i + 1] = preSum[i] + nums[i];
        }
        return mergeSort(preSum, 0, preSum.length - 1, lower, upper);
    }

    private int mergeSort(long[] P, int left, int right, int lower, int upper) {
        if (left >= right) return 0;
        int mid = left + (right - left) / 2;
        int count = mergeSort(P, left, mid, lower, upper)
                  + mergeSort(P, mid + 1, right, lower, upper);

        // 双指针统计跨半数对：左半每个 i，右半找 P[j] ∈ [P[i] + lower, P[i] + upper]
        int i1 = left, i2 = left;
        for (int j = mid + 1; j <= right; j++) {
            while (i1 <= mid && P[i1] < P[j] - upper) i1++;
            while (i2 <= mid && P[i2] <= P[j] - lower) i2++;
            count += i2 - i1;
        }

        // 标准归并合并
        long[] temp = new long[right - left + 1];
        int i = left, j = mid + 1, k = 0;
        while (i <= mid && j <= right)
            temp[k++] = P[i] < P[j] ? P[i++] : P[j++];
        while (i <= mid) temp[k++] = P[i++];
        while (j <= right) temp[k++] = P[j++];
        System.arraycopy(temp, 0, P, left, temp.length);
        return count;
    }
}
```

**关键点**：
- 对前缀和数组归并排序（不是原数组），因为排序不影响跨半数对的原始下标关系
- 双指针 `i1`、`i2` 都只在左半移动，随 `j` 右移而单调递增 → 计数阶段 O(n)
- 先计数、再合并，确保计数时左右半各自有序

## 3. 踩坑记录

### 线段树 & BIT 的共同坑

1. **离散化集合缺值**：必须收集所有可能查询的值（`P[j]`、`P[j]-upper`、`P[j]-lower`），包括 `P[0]=0` 及其 ±upper/lower。缺了就 NPE。

2. **先 query 后 update**：如果先 update 再 query，会把当前前缀和自身计入，导致多算"空子数组"。

3. **int 溢出**：前缀和要用 `long`。n=10⁵，nums[i] ≤ 2³¹-1，前缀和远超 int 范围。

4. **`map.get()` 可能返回 null**：离散化缺值或自动拆箱导致 NPE。

### BIT 独有坑

5. **BIT 必须 1-indexed**：`lowbit(0) = 0` → 死循环。离散化下标 +1 后再传给 BIT。

### 归并排序独有坑

6. **base case 条件**：`if (left >= right) return 0`（单元素或无元素），不要写成 `right >= left`。

7. **比较运算符**：
   - `P[i] < P[j] - upper` → 跳过（区间和 < lower）
   - `P[i] <= P[j] - lower` → 包含（区间和 ≤ upper）
   边界用 `<=` 保证包含等于 `upper` 的情况。

8. **合并时用 `<` 而非 `<=`**：归并排序相等时谁先都行，不影响计数。

## 4. 技巧总结

### 区间和 → 前缀和相减

这是子数组求和问题的标准转化，配合有序集合可以高效统计满足值域条件的区间。

### 动态数据结构 + 离散化

当值域远大于元素个数时，离散化收集所有可能值，将值域缩小到数组大小级别。

| 数据结构 | 适用场景 | 代码量 | 常数 |
|----------|---------|:------:|:----:|
| 线段树 | 通用区间操作（最值、和、计数） | 大 | 大 |
| BIT | 仅前缀和类操作 | 小 | 小 |
| 归并排序 | 数对统计型问题 | 中 | 最小 |

### 归并排序计数本质

将问题转化成统计满足条件的数对 `(i, j)` 且 `i < j`。归并排序的分治结构天然将数对分为三类：全在左、全在右、跨半。前两类递归处理，跨半的在合并时用双指针 O(n) 统计。

同类问题：
- 315. 计算右侧小于当前元素的个数
- 493. 翻转对
- 327. 区间和的个数

### 算法思想关联

- **分治法**：归并排序解法
- **权值线段树 / 权值 BIT**：线段树 / BIT 解法
- **离散化 + 离线处理**：将在线问题转化为已知全集

## 5. 思考过程

### 从 O(n²) 到 O(n log n)

**最初想法**：先算前缀和，再双重循环枚举所有子数组。问题在于 n=10⁵ 时 O(n²) 完全不可行。

**关键转变**：意识到区间和可以用前缀和相减表示，问题转化为找满足值域条件的前缀和数对。对一个固定的 `j`，只需要知道之前有多少前缀和落在 `[P[j]-upper, P[j]-lower]` 内。

**数据结构选择**：需要"动态插入 + 区间统计"的数据结构。想到了线段树和树状数组，需要离散化因为值域是 long。

**归并排序的发现**：这个问题和 315 本质一样，都是统计满足条件的数对。归并排序的分治过程天然适合做这种统计，代码也最简洁。

三种解法对比下来，归并排序的代码最短、常数最小、不需要离散化，是本题最优解。
