# 接雨水 [42]

## 1. 解题思路

### 问题
给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子下雨后能接多少雨水。

### 核心难点
每个位置能接的雨水量取决于该位置**左右两边最高柱子的较小值**减去自身高度。关键是如何高效计算每个位置的左右最大值。

### 四种解法

**解法一：双指针（O(n)，空间 O(1)，最优）**
维护左右两个指针和两个最大值。指针从两端向中间移动，每次移动较矮的一侧。因为接水量由较矮的一侧决定。

**解法二：动态规划（O(n)，空间 O(n)）**
预处理两个数组 `leftMax[i]`、`rightMax[i]`，记录每个位置 i 的左侧和右侧最大高度。

**解法三：单调栈（O(n)，空间 O(n)）**
用单调递减栈。遇到比栈顶高的柱子时，弹出栈顶计算中间凹陷区域的积水量。

**解法四：按列计算（O(n²)，最直观）**
每列分别计算左右最大值再求接水量。

## 2. 代码实现

### 双指针法（推荐，最优解）

```java
/**
 * 双指针法：时间复杂度 O(n)，空间复杂度 O(1)
 *
 * 核心思路：
 * 每个位置 i 的接水量 = min(leftMax, rightMax) - height[i]
 * 使用双指针从两端向中间收缩，每次移动矮的一侧指针。
 * 因为矮的一侧决定了该位置的水位上限。
 *
 * @param height 柱子高度数组
 * @return 接雨水的总量
 */
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (left < right) {
        // 更新左右两侧遇到的最大高度
        leftMax = Math.max(leftMax, height[left]);
        rightMax = Math.max(rightMax, height[right]);

        if (leftMax < rightMax) {
            // 左侧较矮，处理 left 位置的接水量
            // leftMax 就是 left 位置的"有效水位上限"
            water += leftMax - height[left];
            left++;
        } else {
            // 右侧较矮或相等，处理 right 位置的接水量
            water += rightMax - height[right];
            right--;
        }
    }
    return water;
}
```

### 动态规划法

```java
/**
 * 动态规划预处理法：O(n) 时间，O(n) 空间
 */
public int trapDP(int[] height) {
    int n = height.length;
    if (n == 0) return 0;

    // leftMax[i]: 位置 i 左侧（不含 i）的最大高度
    int[] leftMax = new int[n];
    leftMax[0] = height[0];
    for (int i = 1; i < n; i++) {
        leftMax[i] = Math.max(leftMax[i - 1], height[i]);
    }

    // rightMax[i]: 位置 i 右侧（不含 i）的最大高度
    int[] rightMax = new int[n];
    rightMax[n - 1] = height[n - 1];
    for (int i = n - 2; i >= 0; i--) {
        rightMax[i] = Math.max(rightMax[i + 1], height[i]);
    }

    int water = 0;
    for (int i = 0; i < n; i++) {
        // 每个位置的接水量 = min(左侧最高, 右侧最高) - 自身高度
        water += Math.min(leftMax[i], rightMax[i]) - height[i];
    }
    return water;
}
```

### 单调栈法

```java
/**
 * 单调递减栈法：遇到比栈顶高的柱子时，计算凹陷区域
 */
public int trapStack(int[] height) {
    Deque<Integer> stack = new LinkedList<>();
    int water = 0;
    for (int i = 0; i < height.length; i++) {
        // 当前柱子比栈顶高 → 形成凹槽
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = stack.pop();           // 凹槽底部
            if (stack.isEmpty()) break;         // 左边无柱子，无法接水
            int left = stack.peek();            // 凹槽左侧柱子
            int width = i - left - 1;           // 凹槽宽度
            int heightDiff = Math.min(height[left], height[i]) - height[bottom]; // 凹槽高度
            water += width * heightDiff;
        }
        stack.push(i);
    }
    return water;
}
```

## 3. 踩坑记录

- **双指针法的移动方向**：必须是 `leftMax < rightMax` 时移动 left。因为 left 位置的接水量由 `min(leftMax, rightMax)` 决定，若 `leftMax < rightMax`，则该 min 值为 `leftMax`，此时移动 left 是安全的。若写成 `height[left] < height[right]` 会有 bug。
- **单调栈法中的宽度计算**：弹出 bottom 后宽度 = `i - stack.peek() - 1`，不是简单的 `i - bottom`，要考虑到中间可能还有别的柱子被弹出。

## 4. 技巧总结

- **接雨水**和**柱状图中最大矩形(84)**是 Hard 难题中的"双子星座"，都是单调栈的经典应用，但方向相反
- 双指针法体现了**减治法**的思想：每次确定一个位置的水量后缩小问题规模
- 理解"每个位置的接水量由左右两侧决定"是本题的核心洞察
