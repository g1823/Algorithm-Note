# 最大子数组和 [53]

## 1. 解题思路

### 问题
给定整数数组 `nums`，找出具有**最大和**的连续子数组（至少包含一个元素），返回其最大和。

### 核心难点
关键在于当子数组和变为负数时该如何处理。负数 + 任何数 = 更小的数，所以应该**立即舍弃**当前子数组。

### 三种解法

**解法一：贪心法（O(n)）**
每一步都判断当前子数组和是否大于 0，若非正则舍弃重来。这是最简洁的解法。

**解法二：动态规划（O(n)）**
`dp[i]` 表示以 nums[i] 结尾的最大子数组和。
- `dp[i] = max(nums[i], dp[i-1] + nums[i])`
- 要么从当前元素重新开始，要么接上之前的子数组

**解法三：分治法（O(n log n)）**
将数组平分为左右两部分，最大子数组有三种可能：
1. 完全在左半部分
2. 完全在右半部分
3. 跨越中点（从右向左找左半部分最大后缀 + 从左向右找右半部分最大前缀）

## 2. 代码实现

### 贪心法（推荐）

```java
/**
 * 贪心法：时间复杂度 O(n)，空间复杂度 O(1)
 *
 * 核心思路：如果当前子数组和 thisMaxSub 小于 0，
 * 则负数加上任何数都会变小，直接舍弃当前子数组（thisMaxSub 置为 0）。
 * 遍历过程中不断更新全局最大和 result。
 *
 * @param nums 整数数组
 * @return 最大子数组和
 */
public int maxSubArray(int[] nums) {
    // result: 全局最大子数组和，初始化为最小值
    // thisMaxSub: 以当前元素结尾的最大子数组和
    int result = Integer.MIN_VALUE, thisMaxSub = 0;
    for (int num : nums) {
        thisMaxSub += num;                          // 将当前元素加入
        result = Math.max(thisMaxSub, result);       // 更新全局最大值
        thisMaxSub = Math.max(thisMaxSub, 0);        // 若和为负数，则舍弃（置0）
    }
    return result;
}
```

### 动态规划

```java
/**
 * 动态规划：dp[i] = max(nums[i], dp[i-1] + nums[i])
 * 可压缩为一个变量替代数组，空间 O(1)
 */
public int maxSubArrayDP(int[] nums) {
    int dp = nums[0], max = nums[0];
    for (int i = 1; i < nums.length; i++) {
        dp = Math.max(nums[i], dp + nums[i]);  // 状态转移
        max = Math.max(max, dp);               // 更新全局最大
    }
    return max;
}
```

### 分治法

```java
/**
 * 分治法：最大子数组要么在左半、要么在右半、要么跨越中点
 */
public int maxSubArrayDC(int[] nums) {
    return divide(nums, 0, nums.length - 1);
}

private int divide(int[] nums, int left, int right) {
    if (left == right) return nums[left];
    int mid = left + (right - left) / 2;
    int leftMax = divide(nums, left, mid);
    int rightMax = divide(nums, mid + 1, right);
    // 跨越中点的最大子数组和
    // 左半部分：从 mid 向左累加的最大后缀和
    int leftCross = Integer.MIN_VALUE, sum = 0;
    for (int i = mid; i >= left; i--) {
        sum += nums[i];
        leftCross = Math.max(leftCross, sum);
    }
    // 右半部分：从 mid+1 向右累加的最大前缀和
    int rightCross = Integer.MIN_VALUE;
    sum = 0;
    for (int i = mid + 1; i <= right; i++) {
        sum += nums[i];
        rightCross = Math.max(rightCross, sum);
    }
    int crossMax = leftCross + rightCross;
    return Math.max(Math.max(leftMax, rightMax), crossMax);
}
```

## 3. 踩坑记录

- **全负数数组**：贪心法中 `result` 初始化为 `Integer.MIN_VALUE`，否则全负数会返回 0（错误）
- **贪心法的 thisMaxSub 置 0 时机**：必须在 `result = max(result, thisMaxSub)` 之后，否则如果当前元素是第一个正数，它的和尚未被记录就被清零

## 4. 技巧总结

- 这道题是**贪心法**的经典应用，体现"当前子数组和为负即舍弃"的贪心选择性质
- 同时也展示了**动态规划**的最优子结构
- **分治法**的"跨越中点"模式在其他问题中也很常见（如最大子数组积）
- 涉及三种算法思想，是典型的多解法对比题目
