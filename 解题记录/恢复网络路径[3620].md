# 恢复网络路径 [3620]

## 1. 解题思路

### 问题本质

给定一个 DAG（有向无环图），每条边有恢复成本。节点有在线/离线状态。求从 0 到 n-1 的所有有效路径中，**路径上最小边权**的最大值。

有效路径的条件：
1. 中间节点均在线
2. 总恢复成本 ≤ k

### 核心转换：最大化最小值 → 二分答案

"路径分数 = 路径上的最小边权"，要最大化这个值。

典型的**最大化最小值**问题，可以用**二分答案**：

```
假设答案为 X，问：是否存在一条路径，每条边权 ≥ X，且总成本 ≤ k？
```

如果能回答这个问题，就可以用二分法不断缩小区间，找到最大的可行 X。

### 判定方法一：Dijkstra（通用方法）

思路：
1. 只保留边权 ≥ X 的边
2. 只允许经过在线节点
3. 在这个子图上运行 Dijkstra 求 0→n-1 的最短路径
4. 若最短路径 ≤ k，则 X 可行

### 判定方法二：拓扑排序 + DP（利用 DAG 特性）

由于图是 DAG，不需要 Dijkstra 的优先队列：

1. **先计算拓扑序**（只需一次，与 X 无关）
2. **按拓扑序递推 DP**：
   - `dist[v] = min(dist[v], dist[u] + w)`，仅当 `w ≥ X` 且 `online[v]` 为 true
3. 若 `dist[n-1] ≤ k`，则 X 可行

为什么拓扑序可行？因为 DAG 上，处理到节点 u 时，**所有能到达 u 的节点都已经处理完毕**，`dist[u]` 已经是最优值，不需要再次更新。

---

### 整体流程

```
对边权去重排序
二分枚举 X：
  在子图（边权 ≥ X，节点在线）上运行最短路径算法
  若最短路径 ≤ k → X 可行，尝试更大的 X
  否则 → X 太大，尝试更小的 X
```

## 2. 代码实现

### Solution1：二分 + Dijkstra

```java
class Solution1 {
    public int findMaxPathScore(int[][] edges, boolean[] online, long k) {
        int n = online.length;
        List<List<int[]>> nodes = new ArrayList<>();
        for (int i = 0; i < n; i++) nodes.add(new ArrayList<>());

        Set<Integer> costSet = new HashSet<>();
        for (int[] e : edges) {
            int u = e[0], v = e[1], w = e[2];
            nodes.get(u).add(new int[]{v, w});
            costSet.add(w);
        }

        List<Integer> costList = new ArrayList<>(costSet);
        Collections.sort(costList);

        int left = 0, right = costList.size() - 1, ans = -1;
        while (left <= right) {
            int mid = (left + right) >>> 1;
            if (check(nodes, costList.get(mid), k, online)) {
                ans = costList.get(mid);
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ans;
    }

    private boolean check(List<List<int[]>> nodes, int minCost, long k, boolean[] online) {
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[1]));
        pq.offer(new long[]{0, 0});
        long[] dist = new long[nodes.size()];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;

        while (!pq.isEmpty()) {
            long[] curr = pq.poll();
            int node = (int) curr[0];
            long cost = curr[1];
            if (cost != dist[node]) continue;       // 过期数据剪枝
            if (cost > k) continue;                  // 成本已超上限
            if (!online[node]) continue;             // 节点不在线
            if (node == nodes.size() - 1) return true;

            for (int[] edge : nodes.get(node)) {
                int v = edge[0], w = edge[1];
                if (w < minCost || !online[v]) continue;
                long nd = cost + w;
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.offer(new long[]{v, nd});
                }
            }
        }
        return false;
    }
}
```

### Solution2：二分 + 拓扑排序 + DP

```java
class Solution2 {
    List<Integer> topo;

    public int findMaxPathScore(int[][] edges, boolean[] online, long k) {
        int n = online.length;
        List<List<int[]>> nodes = new ArrayList<>();
        int[] indegree = new int[n];
        for (int i = 0; i < n; i++) nodes.add(new ArrayList<>());

        Set<Integer> costSet = new HashSet<>();
        for (int[] e : edges) {
            int u = e[0], v = e[1], w = e[2];
            nodes.get(u).add(new int[]{v, w});
            indegree[v]++;
            costSet.add(w);
        }

        // Kahn 算法求拓扑序（只需一次）
        topo = new ArrayList<>();
        Queue<Integer> q = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (indegree[i] == 0) q.offer(i);
        }
        while (!q.isEmpty()) {
            int u = q.poll();
            topo.add(u);
            for (int[] edge : nodes.get(u)) {
                int v = edge[0];
                if (--indegree[v] == 0) q.offer(v);
            }
        }

        List<Integer> costList = new ArrayList<>(costSet);
        Collections.sort(costList);
        int left = 0, right = costList.size() - 1, ans = -1;
        while (left <= right) {
            int mid = (left + right) >>> 1;
            if (check(nodes, costList.get(mid), k, online)) {
                ans = costList.get(mid);
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return ans;
    }

    private boolean check(List<List<int[]>> nodes, int minCost, long k, boolean[] online) {
        int n = nodes.size();
        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;

        for (int u : topo) {
            if (dist[u] == Long.MAX_VALUE) continue;   // 不可达
            if (u == n - 1) break;                      // 终点已确定
            for (int[] edge : nodes.get(u)) {
                int v = edge[0], w = edge[1];
                if (w < minCost || !online[v]) continue;
                long nd = dist[u] + w;
                if (nd < dist[v]) {
                    dist[v] = nd;
                }
            }
        }
        return dist[n - 1] <= k;
    }
}
```

## 3. 踩坑记录

### 3.1 读数据时复制粘贴错误

```java
// ❌ 错误
int tar = edges[i][0];   // 全部读成了起点下标
int cost = edges[i][0];

// ✅ 正确
int tar = edges[i][1];
int cost = edges[i][2];
```

### 3.2 PriorityQueue 中距离和节点编号颠倒

```java
// ❌ 错误：{nextNode, dist[nextNode]}，导致 PQ 按节点编号排序而非距离
pq.offer(new int[]{nextNode, dist[nextNode]});

// ✅ 正确：{node, distance}，比较器按 a[1] 排序
pq.offer(new long[]{nextNode, dist[nextNode]});
// 比较器：Comparator.comparingLong(a -> a[1])
```

### 3.3 邻接表初始化用边数而非节点数

```java
// ❌ 错误：当 n > edges.length 时 nodes.get(cur) 越界
for (int i = 0; i < edges.length; i++) nodes.add(new ArrayList<>());

// ✅ 正确：用 online.length（= n）
for (int i = 0; i < online.length; i++) nodes.add(new ArrayList<>());
```

### 3.4 距离数组用 int 溢出

`k` 最大 5×10^13，任意两条 10^9 的边相加就溢出 int，必须用 `long[]`。

### 3.5 过期数据导致超时

Dijkstra 中同一个节点可能被多次入队，不加 `if (cost != dist[node]) continue` 剪枝会导致每个节点的出边被反复遍历，复杂度退化为 O(m²)，m=10^5 时 TLE。

### 3.6 无解时返回最小值而非 -1

二分结束后若所有检查均失败，应返回 -1 而非 `costList.get(0)`。

## 4. 技巧总结

### 4.1 答案二分（二分答案）

**模式**：求"最大值中的最小值"或"最小值中的最大值"时，将最优解问题转化为判定性问题。

本题：
- 外层：二分"最小边权 X"
- 内层：判定"是否存在一条路径满足边权 ≥ X 且总成本 ≤ k"

关键：判定函数单调——X 越大，边越少，可行性越低。

### 4.2 DAG 上的 DP

DAG 天然适合 DP，因为**拓扑序保证了无后效性**：处理到节点 u 时，所有入边来源都已处理完，`dist[u]` 已经确定，不需要 Dijkstra 的优先队列。

**与 Dijkstra 的对比**：

| | Dijkstra | 拓扑 DP |
|--|----------|---------|
| 适用图 | 非负权图（可有环） | DAG（必须无环） |
| 核心结构 | 优先队列 | 普通队列 + for 循环 |
| 处理次数 | 每个节点可能多次入队 | 每个节点恰好一次 |
| 复杂度 | O((n+m)logn) | O(n+m) |

### 4.3 二分 + 判定模式

和本仓库中 [2071. 最多任务数目](../解题记录/最多任务数目[2071].md) 相同的套路：
- 最优解 → 能否解
- 在线决策 → 离线判定

## 5. 思考过程

### 最初的直觉

拿到题目后，第一反应是 DFS 暴力搜索，对每个节点缓存 `(总成本, 最小边)` 对，用 Pareto 支配剪枝。

### 卡点分析

DFS 的 Pareto 前沿在最坏情况下会膨胀到 O(m)，导致退化到 O(m²)，不可控。

### 二分答案的发现

意识到"最大化最小边权"是典型的二分答案模式：
- 猜一个答案 X
- 检查 X 是否可行
- 可行则试试更大的 X，否则试试更小的 X

### Dijkstra 实现踩坑

第一次实现 Dijkstra 时出了不少低级错误：
- 读数据全读成 `edges[i][0]`（复制粘贴忘了改）
- PQ 里距离和节点编号放反了
- dist 数组用 int 溢出
- 忘了加过期数据剪枝导致超时
- 无解时忘了返回 -1

每个 bug 都靠实际跑测试或推理发现。

### 拓扑 DP 的进化

意识到题目说了图是 DAG，而 DAG 的最短路可以用更简单的拓扑 DP：
- 先一次 Kahn 算出拓扑序
- check 里直接按序递推，不需要任何优先队列

和 Dijkstra 相比，**代码更简洁，性能更好（O(n+m) vs O((n+m)logn)），且没有过期数据的问题**。

学到的核心：**利用题目的额外条件（这里是 DAG）可以大幅简化算法**。
