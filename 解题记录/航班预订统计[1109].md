# 航班预订统计[1109]

## 1. 解题思路

### 问题分析
给定 `n` 个航班（编号 1~n）和一组预订记录 `bookings`，每条记录 `[first, last, seats]` 表示在 `first` 到 `last`（含）的每个航班上预订了 `seats` 个座位。需要返回每个航班的预订总数。

### 解法一：差分数组（O(n + m)）

**核心思想**：将区间操作转化为端点操作。

对于每条预订 `[start, end]` 加 `seats`：
- `diff[start-1] += seats`（从 `start` 开始增加）
- `diff[end] -= seats`（在 `end+1` 处减回来，即 `end` 下标处减）

最后对 `diff` 求前缀和即得每个航班的最终值。

**为什么这样做？** 差分数组的前缀和就是原数组。`diff[l] += x` 会让 l 之后的所有位置 +x，再在 `r+1` 处 -x 抵消掉 r 之后的影响。本题航班编号从 1 开始而数组从 0 开始，需要注意坐标变换。

### 解法二：线段树（O(n + m log n)）

用线段树维护区间加操作，最后逐个查询每个位置的累加值。相比差分，线段树代码更重，但支持更灵活的区间更新和查询（如区间和、区间最值）。

### 复杂度对比

| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|:----------:|:----------:|----------|
| 差分 | O(n + m) | O(n) | 仅需最终结果，区间修改+单点查询 |
| 线段树 | O(n + m log n) | O(4n) | 需要中间结果、动态查询，或更复杂的区间操作 |

## 2. 代码实现

### 差分解法

```java
public int[] corpFlightBookings(int[][] bookings, int n) {
    int[] res = new int[n];
    for (int[] booking : bookings) {
        int start = booking[0], end = booking[1], seats = booking[2];
        res[start - 1] += seats;   // 从 start 开始增加
        if (end < n) {
            res[end] -= seats;      // 在 end+1 处减回来
        }
    }
    for (int i = 1; i < n; i++) {
        res[i] += res[i - 1];      // 前缀和还原
    }
    return res;
}
```

**关键细节**：
- `start - 1`：航班编号从 1 开始，数组下标从 0 开始，需减 1
- `if (end < n)`：只在 `end < n` 时才在 `res[end]` 处减，因为 `end == n` 时末尾没有航班需要抵消
- `res[end]` 处减：因为差分中 `diff[r+1] -= x`，这里 `r = end - 1`（0-indexed），所以 `r+1 = end`

### 线段树解法（数组实现 + 懒标记）

```java
class SegmentTree {
    int[] tree, lazy;
    int n;

    public SegmentTree(int n) {
        this.n = n;
        tree = new int[n * 4];
        lazy = new int[n * 4];
    }

    public void update(int l, int r, int val) {
        update(1, 0, n - 1, l, r, val);
    }

    private void update(int node, int start, int end, int l, int r, int val) {
        if (start > r || end < l) return;          // 不相交
        if (start >= l && end <= r) {               // 完全覆盖
            tree[node] += val;
            lazy[node] += val;
            return;
        }
        pushDown(node);
        int mid = (start + end) / 2;
        update(node * 2, start, mid, l, r, val);
        update(node * 2 + 1, mid + 1, end, l, r, val);
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    public int query(int l, int r) {
        return query(1, 0, n - 1, l, r);
    }

    private int query(int node, int start, int end, int l, int r) {
        if (start > r || end < l) return 0;
        if (start >= l && end <= r) return tree[node];
        pushDown(node);
        int mid = (start + end) / 2;
        return query(node * 2, start, mid, l, r) +
               query(node * 2 + 1, mid + 1, end, l, r);
    }

    private void pushDown(int node) {
        if (lazy[node] != 0) {
            tree[node * 2] += lazy[node];
            tree[node * 2 + 1] += lazy[node];
            lazy[node * 2] += lazy[node];
            lazy[node * 2 + 1] += lazy[node];
            lazy[node] = 0;
        }
    }
}
```

## 3. 踩坑记录

- **边界偏移**：航班编号是 1-indexed，数组下标是 0-indexed，差分操作中 `start - 1` 加、`end` 减（而非 `end - 1`），因为差分公式中 `diff[r+1] -= x` 中的 `r+1` 在 0-indexed 下恰好等于 `end`。
- **`end == n` 的特殊情况**：当 `end == n` 时，`res[end]` 已越界，减操作无需执行。

| 技巧 | 说明 | 相关笔记 |
|------|------|----------|
| **差分数组** | 区间多次加+最终结果，O(1) 区间修改 | [经典解法/差分.md](../经典解法/差分.md) |
| **线段树·懒标记** | 区间加+区间查询，O(log n) 操作 | [经典解法/线段树.md](../经典解法/线段树.md) |
| **数组表示完全二叉树** | 线段树用 `4n` 数组存，下标 `2*i` / `2*i+1` | [小技巧/数组表示完全二叉树.md](../小技巧/数组表示完全二叉树.md) |

**从差分到线段树的思考**：
- 差分适合"多次区间修改 + 最终一次性查询"的离线场景
- 线段树适合"边修改边查询、区间灵活操作"的动态场景
- 本题只需要最终结果，差分解法更优；线段树代码更通用但有一定常数开销

## 5. 思考过程

这道题是差分数组的入门经典题，也是理解"区间操作→端点操作"思维的好例子。最初看到"区间加"想到的是暴力 O(m·n)，但数据规模不允许。讨论后意识到：

1. **差分数组**：端点操作的数学本质——修改前缀和的"导数"，再通过前缀和还原。
2. **线段树**：更通用的区间数据结构，虽然本题用差分更优，但线段树解法展示了区间加+懒标记的标准模板。
3. **二者对比**：差分是"从前往后"的累积逻辑，线段树是"分治+合并"的树形逻辑，理解两者的关系有助于在不同场景下选择合适的数据结构。
