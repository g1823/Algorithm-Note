## 一、416. 分割等和子集

### 1. 解题思路

**题目**：给定一个只包含正整数的非空数组 `nums`，判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**核心难点**：将问题转化为"能否从集合中选出若干元素，使其和等于总和的一半"。

**转化**：设总和为 sum，问题等价于能否选出和为 `sum/2` 的子集 → **0-1 背包问题**。

dp\[i][j] 表示：前 i 个元素能否组合出数值 j（用 1 表示可以）：
- 若 `nums[i] > j`：放不下 → `dp[i][j] = dp[i-1][j]`
- 若 `nums[i] <= j`：放得下 → `dp[i][j] = dp[i-1][j] || dp[i-1][j-nums[i]]`

### 2. 代码实现

```java
/**
 * 动态规划背包思想可以解决：求解一组数据是否可以组合出指定解，或组合出指定解的组合数量
 */
public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int num : nums) sum += num;
    if (sum % 2 != 0) return false;    // 奇数不可能平分
    int target = sum >> 1;
    int[] dp = new int[target + 1];
    dp[0] = 1;                          // 0个元素，总和为0的解法有一个
    for (int i = 1; i < nums.length + 1; i++) {
        int num = nums[i - 1];
        for (int j = target; j >= 1; j--) {
            dp[j] = j >= num ? (num == j ? 1 : Math.max(dp[j], dp[j - num])) : dp[j];
        }
    }
    return dp[target] == 1;
}
```

## 二、494. 目标和

### 1. 解题思路

**题目**：给定非负整数数组 `nums` 和整数 `target`，向每个整数前添加 `'+'` 或 `'-'`，返回运算结果等于 `target` 的不同表达式的数目。

**核心难点**：将 ± 符号问题转化为"选取部分数作为正数集合"的子集和问题。

**转化推导**：
- 设正值集合和为 `add`，负值集合和为 `reduce`
- `add + reduce = sum(nums)`
- `add - reduce = target`
- 联立得：`add = (sum(nums) + target) / 2`

问题转化为：从 nums 中选出若干元素，使其和等于 `(sum + target) / 2`，求方案数 → **0-1 背包计数**。

dp\[i][j] 表示：前 i 个元素组合出数值 j 的方案数：
- 不放第 i 个：`dp[i-1][j]`
- 放第 i 个：`dp[i-1][j-nums[i]]`
- 转移方程：`dp[i][j] = dp[i-1][j] + dp[i-1][j-nums[i]]`

### 2. 代码实现

```java
public int findTargetSumWays(int[] nums, int target) {
    int sumNums = 0;
    for (int num : nums) sumNums += num;
    // 无法整除或目标超出范围则无解
    if ((target + sumNums) < 0 || (target + sumNums) % 2 != 0) return 0;
    int packCapacity = (target + sumNums) / 2;
    int[] dp = new int[packCapacity + 1];
    dp[0] = 1;
    for (int num : nums) {
        // 滚动数组，倒序更新避免重复使用
        for (int j = dp.length - 1; j >= num; j--) {
            dp[j] += dp[j - num];
        }
    }
    return dp[packCapacity];
}
```

> 相关代码：`leetCode/moderately/FindTargetSumWays.java`

### 3. 踩坑记录

- 边界条件：`(target + sumNums) < 0` 时直接返回 0，否则 `packCapacity` 可能为负数
- `(target + sumNums) % 2 != 0` 说明无法整数平分，无解

### 4. 技巧总结

- **问题转化**：很多看似与背包无关的题目（如分割子集、± 符号），通过代数变形可转化为子集和问题
- **滚动数组优化**：0-1 背包中，内层循环必须**倒序遍历**，防止同一物品被重复选取
