### 分析：

堆排序是一种基于堆数据结构的排序算法，其基本思想：

1. **构建最大堆**：将数组调整为一个最大堆（父节点大于等于子节点）
2. **排序**：将堆顶最大元素与堆末尾元素交换，然后对剩余元素重新调整为最大堆
3. **重复**：重复步骤2，直到堆中只剩一个元素

堆排序的核心概念：
- **最大堆**：根节点的值大于等于所有子节点的值
- **完全二叉树**：除了最后一层，所有节点都满，最后一层从左到右排列
- **数组表示**：利用数组下标关系表示二叉树
  - 父节点 i 的左子节点：2*i + 1
  - 父节点 i 的右子节点：2*i + 2
  - 子节点 i 的父节点：(i - 1) / 2

### 过程图解：

**待排序数据：** 8、4、5、7、1、3、6、2

1. **构建最大堆**：
   - 从最后一个非叶子节点开始（n/2 - 1 = 3）
   - 调整节点 7：无子节点大于 7，保持不变
   - 调整节点 5：子节点 8、2，8 > 5，交换 → [8、4、6、7、1、3、5、2]
   - 调整节点 4：子节点 4、7，7 > 4，交换 → [8、7、6、4、1、3、5、2]
   - 调整节点 8：子节点 7、6，8 > 7，保持不变
   - 结果：[8、7、6、4、1、3、5、2]

2. **排序过程**：
   - 交换堆顶 8 和末尾 2：[2、7、6、4、1、3、5]、8
   - 调整剩余元素为最大堆：[7、2、6、4、1、3、5] → [7、5、6、4、1、3、2]、8
   - 交换堆顶 7 和末尾 2：[2、5、6、4、1、3]、7、8
   - 调整：[6、5、2、4、1、3] → [6、5、3、4、1、2]、7、8
   - ...重复直到排序完成

**完全二叉树与数组对应关系：**

数组索引从 0 开始：
```
数组: [8, 4, 5, 7, 1, 3, 6, 2]
      0  1  2  3  4  5  6  7

对应二叉树:
           8 (0)
         /   \
        4(1)  5(2)
       / \   / \
     7(3) 1(4) 3(5) 6(6)
     /
    2(7)
```

### 时间复杂度分析：

- **构建最大堆**：$O(n)$
- **排序过程**：进行 n-1 次调整，每次调整的时间为 $O(\log n)$
- **总时间复杂度**：$O(n \log n)$

堆排序的特点：
- **不稳定排序**：相等的元素可能被交换位置
- **原地排序**：只需要常数级别的额外空间
- **适合大数据量排序**：不需要递归，内存占用小

### 代码实现：

~~~ java
public static void execute(int[] data) {
    int length = data.length;
    buildMaxHeap(data);
    for (int i = length - 1; i > 0; ) {
        swap(data, 0, i);
        adjustHeap(data, --i, 0);
    }
}

// 构建最大堆
public static void buildMaxHeap(int data[]) {
    int n = data.length;
    // 数组初始为一个无序的完全二叉树，从最后一个非叶子节点开始调整
    for (int i = n / 2 - 1; i >= 0; i--) {
        adjustHeap(data, n - 1, i);
    }
}

// 调整堆，使其满足最大堆性质
public static void adjustHeap(int[] data, int length, int i) {
    int leftChildIndex = 2 * i + 1;
    int rightChildIndex = 2 * i + 2;
    int maxIndex = i;
    if (leftChildIndex <= length && data[leftChildIndex] > data[maxIndex]) {
        maxIndex = leftChildIndex;
    }
    if (rightChildIndex <= length && data[rightChildIndex] > data[maxIndex]) {
        maxIndex = rightChildIndex;
    }
    if (maxIndex != i) {
        swap(data, i, maxIndex);
        adjustHeap(data, length, maxIndex);
    }
}

public static void swap(int[] data, int i, int j) {
    int temp = data[i];
    data[i] = data[j];
    data[j] = temp;
}
~~~
