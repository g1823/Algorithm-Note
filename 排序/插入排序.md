### 分析：

插入排序是一种简单直观的排序算法，其基本思想：

- 将数组分为"已排序区间"和"未排序区间"
- 初始时，已排序区间只有一个元素（数组第一个元素）
- 每次从未排序区间取出一个元素，插入到已排序区间的正确位置
- 重复上述过程，直到未排序区间为空

插入排序的特点：
- **稳定排序**：相等的元素不会被交换位置
- **原地排序**：不需要额外的存储空间
- **对于基本有序的数组效率较高**：最好情况时间复杂度为 $O(n)$

### 过程图解：

**待排序数据：** 8、4、5、7、1、3、6、5、2

1. **初始状态**：已排序区间 [8]，未排序区间 [4、5、7、1、3、6、5、2]

2. **插入元素 4**：
   - 4 < 8，将 8 后移一位：8、8、5、7、1、3、6、5、2
   - 4 插入到位置 0：4、8、5、7、1、3、6、5、2

3. **插入元素 5**：
   - 5 < 8，将 8 后移一位：4、8、8、7、1、3、6、5、2
   - 5 < 8，将第二个 8 后移一位：4、5、8、7、1、3、6、5、2
   - 5 插入到位置 1：4、5、8、7、1、3、6、5、2

4. **重复上述过程**...

**详细步骤表：**

| 步骤 | 待插入元素 | 已排序区间变化 | 结果数组 |
| :--: | :--------: | :------------ | :------- |
| 初始 | - | [8] | 8、4、5、7、1、3、6、5、2 |
| 1 | 4 | [4、8] | 4、8、5、7、1、3、6、5、2 |
| 2 | 5 | [4、5、8] | 4、5、8、7、1、3、6、5、2 |
| 3 | 7 | [4、5、7、8] | 4、5、7、8、1、3、6、5、2 |
| 4 | 1 | [1、4、5、7、8] | 1、4、5、7、8、3、6、5、2 |
| 5 | 3 | [1、3、4、5、7、8] | 1、3、4、5、7、8、6、5、2 |
| 6 | 6 | [1、3、4、5、6、7、8] | 1、3、4、5、6、7、8、5、2 |
| 7 | 5 | [1、3、4、5、5、6、7、8] | 1、3、4、5、5、6、7、8、2 |
| 8 | 2 | [1、2、3、4、5、5、6、7、8] | 1、2、3、4、5、5、6、7、8 |

### 时间复杂度分析：

- **最好情况**：数组已经有序，每趟只需比较一次，总时间复杂度为 $O(n)$
- **最坏情况**：数组逆序，每趟需要比较 $i$ 次，总时间复杂度为 $O(n^2)$
  $$
  1+2+3+...+(n-1)=\frac{n(n-1)}{2}=O(n^2)
  $$
- **平均情况**：时间复杂度为 $O(n^2)$

### 代码实现：

~~~ java
public static int[] execute(int[] data) {
    for (int thisIndex = 1; thisIndex < data.length; thisIndex++) {
        int temp = data[thisIndex], i = thisIndex;
        while (i >= 0) {
            if (i != 0 && temp < data[i - 1]) {
                data[i] = data[i-- - 1];
            } else {
                data[i] = temp;
                break;
            }
        }
    }
    return data;
}
~~~
