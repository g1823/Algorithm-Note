# 版本三：双指针优化法

## 分析

双指针优化法是对单边循环法的进一步优化，主要解决了重复元素导致的效率问题。

其基本思想：
1. **选择基准**：通常选择第一个元素作为基准
2. **双指针交换**：
   - 从两端向中间遍历
   - 左边找到大于基准的元素，右边找到小于基准的元素
   - 交换这两个元素
   - 当左右指针相遇时，将基准放入正确位置
3. **重复元素优化**：当左右指针指向的元素都等于基准时，右指针左移一位，避免大量重复元素导致的低效

## 过程图解

**待排序数据：** 8、4、5、7、1、3、6、5、2

选择基准 key = 8，l = 0，r = 8

| 步骤 | l | r | 操作 | 数据变化 |
| :--: |:-:|:-:|:--- | :------- |
| 1 | 0 | 8 | l++(8==8，继续), r--(5<8) | |
| 2 | 0 | 7 | 交换 [8,2] | [2、4、5、7、1、3、6、5、8] |
| 3 | 1 | 7 | l++(4<8), r--(6<8) | |
| 4 | 2 | 6 | l++(5<8), r--([]) | |
| 5 | 3 | 5 | 交换 [7,3] | [2、4、5、3、1、7、6、5、8] |
| 6 | 4 | 5 | l++(1<8), r--([]) | |
| 7 | 5 | 4 | l >= r，退出循环 | 返回基准位置 5 |

## 代码实现

~~~ java
public static int[] execute(int[] data, int left, int right) {
    if (left >= right) {
        return null;
    }
    int result = quickSort(data, left, right);
    execute(data, left, result - 1);
    execute(data, result + 1, right);
    return data;
}

public static int quickSort(int[] data, int left, int right) {
    if (left >= right) {
        return -1;
    }
    int key = data[left], l = left, r = right;
    while (true) {
        while (l < r && data[l] < key) {
            l++;
        }
        while (l < r && data[r] > key) {
            r--;
        }
        if (l >= r) {
            return l;
        }
        if (data[l] == key && data[r] == key) {
            r--;
            while (l < r && data[r] > key) {
                r--;
            }
        }
        swap(data, l, r);
    }
}
~~~

## 复杂度分析

- **时间复杂度**：$O(n \log n)$
- **空间复杂度**：$O(\log n)$（递归栈空间）

## 特点

- **优化重复元素处理**：当左右指针指向的元素都等于基准时，右指针左移一位，减少不必要的交换
- **适用于重复元素较多的情况**：比前两个版本更高效
- **实现稍微复杂**：代码逻辑比单边循环法稍复杂
