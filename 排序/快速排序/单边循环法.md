# 版本二：单边循环法

## 分析

单边循环法是最简洁高效的快速排序实现方式，也是实际应用中最常用的版本。

其基本思想：
1. **选择基准**：通常选择最后一个元素作为基准
2. **单边循环**：
   - 从左向右遍历，找到第一个大于等于基准的元素
   - 将该元素放到右侧的"坑位"（用 r 标记）
   - 继续遍历，直到左右指针相遇
   - 将基准放入正确的位置

## 过程图解

**待排序数据：** 8、4、5、7、1、3、6、5、2

选择基准 key = 2，l = 0，r = 8

| 步骤 | l | r | 操作 | 数据变化 |
| :--: |:-:|:-:|:--- | :------- |
| 1 | 0 | 8 | 8 > 2，将 8 放到 r 位置，r-- | [2、4、5、7、1、3、6、5、8] |
| 2 | 0 | 7 | 4 > 2，将 4 放到 r 位置，r-- | [2、4、5、7、1、3、6、5、4] |
| 3 | 0 | 6 | 5 > 2，将 5 放到 r 位置，r-- | [2、4、5、7、1、3、6、5、5] |
| 4 | 0 | 5 | 7 > 2，将 7 放到 r 位置，r-- | [2、4、5、7、1、3、6、7、5] |
| 5 | 0 | 4 | 1 < 2，不交换，l++ | - |
| 6 | 1 | 4 | 4 > 2，将 4 放到 r 位置，r-- | [2、4、5、7、1、3、4、7、5] |
| 7 | 1 | 3 | 1 < 2，不交换，l++ | - |
| 8 | 2 | 3 | 5 > 2，将 5 放到 r 位置，r-- | [2、4、5、7、1、3、5、7、5] |
| 9 | 2 | 2 | l >= r，退出循环 | 将 key 放到 l 位置 |
| 最终 | - | - | 基准归位 | [2、4、5、7、1、3、4、5、8] |

## 代码实现

~~~ java
public static int[] execute(int[] data, int left, int right) {
    if (left >= right) {
        return null;
    }
    int result = quickSort(data, left, right);
    execute(data, left, result - 1);
    execute(data, result + 1, right);
    return data;
}

public static int quickSort(int[] data, int left, int right) {
    if (left >= right) {
        return -1;
    }
    int key = data[right], l = left, r = right;
    while (l < r) {
        while (l < r && data[l] < key) {
            l++;
        }
        if (l < r) {
            data[r--] = data[l];
        }
        while (l < r && data[r] > key) {
            r--;
        }
        if (l < r) {
            data[l++] = data[r];
        }
    }
    data[l] = key;
    return l;
}
~~~

## 复杂度分析

- **时间复杂度**：$O(n \log n)$
- **空间复杂度**：$O(\log n)$（递归栈空间）

## 特点

- **代码简洁**：相比双边循环，代码更简洁
- **实际应用广泛**：很多标准库中的快速排序实现都采用这种方式
- **处理重复元素**：当有大量重复元素时，效率会有所下降
