### 分析：

基数排序是一种非比较排序算法，其基本思想：

- 按位数进行排序，从低位到高位（或从高位到低位）
- 每一位使用计数排序进行排序
- 依次处理完所有位数后，数据就有序了

基数排序的核心步骤：
1. **确定位数**：找出数组中最大值的位数
2. **按位排序**：从最低位到最高位，依次对每一位使用稳定的排序算法（通常用计数排序）
3. **重复**：重复步骤2，直到处理完所有位

基数排序的关键：
- **稳定性**：必须使用稳定的排序算法（如计数排序）进行每一位的排序
- **按位处理**：每次只处理一位数字（0-9）

### 过程图解：

**待排序数据：** 5、0、3、20、6、2、1、4、7、8

1. **确定最大位数**：
   - 最大值 20，位数为 2
   - 需要进行 2 轮排序

2. **第一轮（按个位排序）**：
   - exp = 1（表示个位）
   - 提取各位数字：[5, 0, 3, 0, 6, 2, 1, 4, 7, 8]
   - 使用计数排序排序

3. **第二轮（按十位排序）**：
   - exp = 10（表示十位）
   - 提取各位数字：[0, 0, 0, 2, 0, 0, 0, 0, 0, 1]
   - 使用计数排序排序

**排序过程示例：**

| 原数组 | 5 | 0 | 3 | 20 | 6 | 2 | 1 | 4 | 7 | 8 |
|:-----:|:-:|:-:|:-:|:--:|:-:|:-:|:-:|:-:|:-:|:-:|
| 个位 | 5 | 0 | 3 | 0 | 6 | 2 | 1 | 4 | 7 | 8 |
| 十位 | 0 | 0 | 0 | 2 | 0 | 0 | 0 | 0 | 0 | 0 |

**计数排序辅助过程：**

1. 统计每个桶中的元素个数（counter 数组）
2. 累加 counter，得到每个桶的结束位置
3. 从后向前遍历原数组，根据位数将元素放到正确位置

### 时间复杂度分析：

- **时间复杂度**：$O(d \times (n + k))$，其中 d 是最大位数，k 是桶的数量（固定为 10）
- **最好情况**：$O(d \times (n + k))$
- **最坏情况**：$O(d \times (n + k))$
- **平均情况**：$O(d \times (n + k))$

空间复杂度：$O(n + k)$

**基数排序的特点**：
- **稳定排序**：相同元素的相对顺序保持不变
- **非比较排序**：不通过元素之间的比较完成排序
- **适用于整数排序**：特别是位数较少的情况

**基数排序 vs 计数排序**：
- 计数排序适用于数据范围较小的情况
- 基数排序通过按位排序，可以处理更大的数据范围

### 代码实现：

~~~ java
public static int[] execute(int[] data) {
    int maxRadix = getMaxRadix(data);
    for (int i = 1; i <= maxRadix; i++) {
        int[] counter = new int[10];
        int exp = 1;
        for (int t = i; t > 1; t--) {
            exp *= 10;
        }
        // 统计每个桶中的元素个数
        for (int j = 0; j < data.length; j++) {
            int index = getDigit(data[j], exp);
            counter[index] += 1;
        }
        // 累加 counter，得到每个桶的结束位置
        for (int k = 1; k < counter.length; k++) {
            counter[k] += counter[k - 1];
        }
        // 从后向前遍历，将元素放到正确位置
        int[] temp = new int[data.length];
        for (int l = data.length - 1; l >= 0; l--) {
            int index = getDigit(data[l], exp);
            counter[index] -= 1;
            temp[counter[index]] = data[l];
        }
        swapArray(temp, data);
    }
    return data;
}

// 获取数字指定位的值
public static int getDigit(int data, int exp) {
    return (data / exp) % 10;
}

// 获取最大值的位数
public static int getMaxRadix(int[] data) {
    int maxRadix = 1;
    int base = 10;
    for (int i = 0; i < data.length; i++) {
        if (data[i] > base) {
            base *= 10;
            maxRadix++;
        }
    }
    return maxRadix;
}

public static void swapArray(int[] sourceArray, int[] targetArray) {
    for (int i = 0; i < sourceArray.length; i++) {
        targetArray[i] = sourceArray[i];
    }
}
~~~
