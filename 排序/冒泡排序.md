### 分析：

冒泡排序是一种简单的排序算法，其基本思想是：
- 重复遍历待排序的数组，每次比较相邻的两个元素
- 如果它们的顺序错误就交换它们的位置
- 遍历完成后，最大的元素会"冒泡"到数组的末端

冒泡排序的特点：
- **稳定排序**：相等的元素不会被交换位置
- **原地排序**：不需要额外的存储空间

### 过程图解：

​	待排序数据：5、0、3、20、6、2、1、4、7、8

1. **第一趟（i=10）**：从 j=1 开始比较到 j=9
   - 比较 data[0] 和 data[1]：5 > 0，交换 → [0、5、3、20、6、2、1、4、7、8]
   - 比较 data[1] 和 data[2]：5 > 3，交换 → [0、3、5、20、6、2、1、4、7、8]
   - 比较 data[2] 和 data[3]：5 < 20，不交换
   - 比较 data[3] 和 data[4]：20 > 6，交换 → [0、3、5、6、20、2、1、4、7、8]
   - 比较 data[4] 和 data[5]：20 > 2，交换 → [0、3、5、6、2、20、1、4、7、8]
   - 比较 data[5] 和 data[6]：20 > 1，交换 → [0、3、5、6、2、1、20、4、7、8]
   - 比较 data[6] 和 data[7]：20 > 4，交换 → [0、3、5、6、2、1、4、20、7、8]
   - 比较 data[7] 和 data[8]：20 > 7，交换 → [0、3、5、6、2、1、4、7、20、8]
   - 比较 data[8] 和 data[9]：20 > 8，交换 → [0、3、5、6、2、1、4、7、8、20]

2. **第二趟（i=9）**：从 j=1 开始比较到 j=8
   - 重复上述过程，最大值 20 已在末尾，不再参与比较

3. **优化**：使用 flag 标记
   - 如果某一趟没有任何交换，说明数组已经有序，可以提前结束排序

**待排序数据：** 5、0、3、20、6、2、1、4、7、8

| 趟数 | 比较次数 | 本趟是否发生交换 | 本趟结果（最后一位是本趟最大值） |
| :--: | :------: | :--------------: | :-----------------------------: |
| 1 | 9 | 是 | 0、3、5、6、2、1、4、7、8、**20** |
| 2 | 8 | 是 | 0、3、5、2、1、4、6、7、**8**、20 |
| 3 | 7 | 是 | 0、3、2、1、4、5、**6**、8、20 |
| ... | ... | ... | ... |
| n-1 | 1 | - | 0、1、2、3、4、5、6、7、8、20 |

### 时间复杂度分析：

- **最好情况**：数组已经有序，只需遍历一次，时间复杂度为 $O(n)$
- **最坏情况**：数组逆序，需要进行 $n-1$ 趟，每趟比较次数从 $n-1$ 到 $1$
  $$
  (n-1)+(n-2)+(n-3)+...+1=\frac{n(n-1)}{2}=O(n^2)
  $$
- **平均情况**：时间复杂度为 $O(n^2)$

### 代码实现：

~~~ java
public static int[] execute(int[] data) {
    int n = data.length;
    if (n == 0 || n == 1) return data;
    for (int i = n; i > 0; i--) {
        boolean flag = true;
        for (int j = 1; j < i; j++) {
            if (data[j - 1] > data[j]) {
                swap(data, j, j - 1);
                flag = false;
            }
        }
        // 如果没有发生交换，说明已经有序，直接退出
        if (flag) break;
    }
    return data;
}

public static void swap(int[] data, int i, int j) {
    int temp = data[i];
    data[i] = data[j];
    data[j] = temp;
}
~~~
