### 分析：

选择排序是一种简单直观的排序算法，其基本思想：

- 每一趟从待排序的数据中选出最小（或最大）的元素
- 将其放在已排序序列的末尾（或开头）
- 重复上述过程，直到所有元素排序完成

选择排序的特点：
- **不稳定排序**：相等的元素可能被交换到其他位置
- **原地排序**：不需要额外的存储空间

### 过程图解：

选择排序将数组分为**有序区域**和**无序区域**：
- 初始时，所有元素都在无序区域
- 每趟从无序区域找出最大（最小）元素，放入有序区域
- 无序区域不断缩小，直到只剩一个元素

**待排序数据：** 49、27、65、76、38、13

| 序号 | 步骤描述 | 数据变化 |
| :--: | :------- | :------- |
| 1 | 划分有序区域和无序区域（方括号内为无序区域） | [49、27、65、76、38、13] |
| 2 | 第一趟：找出无序区域中最大的数 76，与无序区域最后一个元素 13 交换 | [49、27、65、**13**、38]、**76** |
| 3 | 第二趟：找出无序区域中最大的数 65，与无序区域最后一个元素 38 交换 | [49、27、**38**、13]、**65**、76 |
| 4 | 第三趟：找出无序区域中最大的数 49，与无序区域最后一个元素 13 交换 | [**13**、27、38]、**49**、65、76 |
| 5 | 第四趟：找出无序区域中最大的数 38，与无序区域最后一个元素 38 交换（位置不变） | [13、27]、38、49、65、76 |
| 6 | 第五趟：找出无序区域中最大的数 27，与无序区域最后一个元素 27 交换（位置不变） | [13]、27、38、49、65、76 |
| 7 | 无序区域剩余最后一个元素，排序完成 | 13、27、38、49、65、76 |

### 时间复杂度分析：

总共需要进行 $n-1$ 轮迭代，每一轮都需要在剩下的未排序元素中找到最小（或最大）元素。具体分析如下：

- 第1轮：需要比较 $n-1$ 次
- 第2轮：需要比较 $n-2$ 次
- 第3轮：需要比较 $n-3$ 次
- ...
- 第 $n-1$ 轮：需要比较 1 次

总的比较次数为：
$$
(n-1)+(n-2)+(n-3)+...+1=\frac{n(n-1)}{2}
$$

这是一个二次方程，因此时间复杂度为 $O(n^2)$

**注意**：无论数组初始状态如何，比较次数是固定的，但交换次数最多为 $n-1$ 次。

### 代码实现：

~~~ java
public static int[] execute(int[] data) {
    for (int i = 0; i < data.length; i++) {
        int maxIndex = 0;
        // 从无序区域内找到最大值的下标
        for (int j = 1; j < data.length - i; j++) {
            maxIndex = data[maxIndex] > data[j] ? maxIndex : j;
        }
        // 将最大值与无序区域最后一个元素替换，然后无序区域范围缩小（通过i++实现）
        int temp = data[maxIndex];
        data[maxIndex] = data[data.length - i - 1];
        data[data.length - i - 1] = temp;
    }
    return data;
}
~~~
