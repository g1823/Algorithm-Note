### 分析：

快速排序是一种基于分治思想的高效排序算法，其基本思想：

1. **选择基准元素**：从数组中选择一个元素作为"基准"（pivot）
2. **分区**：将数组分成两部分，左边所有元素小于基准，右边所有元素大于基准
3. **递归**：对左右两部分分别进行快速排序

快速排序的核心在于**分区算法**，不同的分区方式导致不同的实现版本：
- **版本一**：双边循环法，处理重复元素效率较低
- **版本二**：单边循环法，简洁高效
- **版本三**：双指针法，处理重复元素效率较高

### 过程图解（版本二：单边循环法）：

**待排序数据：** 8、4、5、7、1、3、6、5、2

以最后一个元素 2 为基准（key）：

1. **初始化**：l = 0，r = 8，key = 2

2. **第一趟**：
   - 从 l=0 开始向右遍历，找到第一个 >= key 的元素
   - l=0：8 > 2，找到 → data[r--] = data[l] → [2、4、5、7、1、3、6、5、8]
   - 继续从 l=0 开始向右遍历，找到第一个 > key 的元素
   - l=0：2 == 2，不变
   - l=1：4 > 2，找到 → data[r--] = data[l] → [2、4、5、7、1、3、6、5、4]
   - l=1：2 == 2，不变
   - l=2：5 > 2，找到 → data[r--] = data[l] → [2、4、5、7、1、3、6、5、5]
   - l=2：2 == 2，不变
   - l=3：7 > 2，找到 → data[r--] = data[l] → [2、4、5、7、1、3、6、5、7]
   - ...
   - 直到 l >= r，将 key 放入位置 l → [2、4、5、7、1、3、6、5、8]
   - 返回基准位置 l = 0

3. **递归处理左右两部分**

### 时间复杂度分析：

- **最好情况**：每次分区都均匀划分，时间复杂度为 $O(n\log_2n)$
- **最坏情况**：每次分区都极度不均匀（如已经有序的数组），时间复杂度为 $O(n^2)$
- **平均情况**：时间复杂度为 $O(n\log_2n)$

**优化策略**：
- 随机选择基准元素，避免最坏情况
- 当数组较小时，使用插入排序
- 三数取中法选择基准

### 代码实现（版本二：单边循环法）：

~~~ java
public static int[] execute(int[] data, int left, int right) {
    if (left >= right) {
        return null;
    }
    int result = quickSort(data, left, right);
    execute(data, left, result - 1);
    execute(data, result + 1, right);
    return data;
}

public static int quickSort(int[] data, int left, int right) {
    if (left >= right) {
        return -1;
    }
    int key = data[right], l = left, r = right;
    while (l < r) {
        while (l < r && data[l] < key) {
            l++;
        }
        if (l < r) {
            data[r--] = data[l];
        }
        while (l < r && data[r] > key) {
            r--;
        }
        if (l < r) {
            data[l++] = data[r];
        }
    }
    data[l] = key;
    return l;
}
~~~
