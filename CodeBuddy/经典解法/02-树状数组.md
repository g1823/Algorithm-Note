# 树状数组 (Fenwick Tree / Binary Indexed Tree)

## 一、作用与适用场景

### 核心作用
树状数组是一种**基于二进制**的数据结构，用于高效地支持**单点更新**和**前缀和查询**操作。

### 与线段树的对比
| 操作 | 树状数组 | 线段树 |
|------|---------|--------|
| 单点更新 | O(log n) | O(log n) |
| 前缀查询 | O(log n) | O(log n) |
| 区间查询 | O(log n) | O(log n) |
| 空间复杂度 | O(n) | O(n) |
| 代码复杂度 | 简洁 | 较复杂 |

### 何时使用树状数组
- ✅ 需要频繁更新和查询的场景
- ✅ 只需要前缀和/前缀最大值（满足结合律）
- ✅ 空间敏感，希望代码更简洁
- ❌ 需要区间更新 + 区间查询（用线段树更好）

## 二、核心概念：lowbit

### 定义
```java
lowbit(x) = x & -x
```

### 数学含义
返回 x 的二进制表示中**最低位的 1 所对应的值**（即 2^k，其中 k 是最低位1的位置）

### 示例
| x | 二进制 | lowbit(x) | 含义 |
|---|--------|----------|------|
| 6 | 110 | 2 (010) | 最低位1在第2位 |
| 12 | 1100 | 4 (0100) | 最低位1在第3位 |
| 8 | 1000 | 8 (1000) | 最低位1在第4位 |
| 7 | 111 | 1 (001) | 最低位1在第1位 |

### lowbit 的推导证明

**定理**：`lowbit(x) = x & (-x)` 返回 x 二进制表示中最低位的 1

**证明**：
设 x 的二进制表示为：`...b₂b₁`（b₀ 为最低位）

情况1：x 为奇数（最低位为1）
- x = ...001
- -x 在计算机中表示为补码：取反 + 1
- ~x = ...110
- -x = ~x + 1 = ...111
- x & -x = 1

情况2：x 最低位1在第 k 位
- x = ...1000（k个0）
- ~x = ...0111
- -x = ~x + 1 = ...1000 = 2^k
- x & -x = 2^k ✓

**本质**：负数的补码表示使得 `-x` 只有最低位的1被保留，其余位取反。

## 三、tree[x] 的真正含义

### 关键定义（极其重要）
```java
tree[x] = sum(nums[x - lowbit(x) + 1 ... x])
```

**tree[x] 存储的不是单点值，而是以 x 为右端点的区间和！**

### 图示理解
```
数组下标:  1   2   3   4   5   6   7   8
          ├───┤
tree[1] = nums[1..1]          (lowbit=1, 长度1)
          ├─────┤
tree[2] = nums[1..2]          (lowbit=2, 长度2)
              ├───┤
tree[3] = nums[3..3]          (lowbit=1, 长度1)
              ├─────────┤
tree[4] = nums[1..4]          (lowbit=4, 长度4)
                  ├───┤
tree[5] = nums[5..5]          (lowbit=1, 长度1)
                  ├─────┤
tree[6] = nums[5..6]          (lowbit=2, 长度2)
                      ├───┤
tree[7] = nums[7..7]          (lowbit=1, 长度1)
                  ├─────────────┤
tree[8] = nums[1..8]          (lowbit=8, 长度8)
```

### 为什么这样设计？
每个 tree[i] 管理的区间长度都是 2 的幂，便于利用二进制拆分。

## 四、query(x) 的严格数学证明

### 查询过程
```java
int query(int x) {
    int sum = 0;
    while (x > 0) {
        sum += tree[x];
        x -= lowbit(x);
    }
    return sum;
}
```

### 目标
计算 `sum(nums[1..x])`

### 区间拆分形式

**定义**：
```
x₀ = x
x₁ = x₀ - lowbit(x₀)
x₂ = x₁ - lowbit(x₁)
...
xₘ = 0
```

**第 i 步对应的区间**：
```
Iᵢ = [xᵢ - lowbit(xᵢ) + 1, xᵢ]
```

### 不重叠证明

**定理**：所有区间 I₀, I₁, ..., Iₘ₋₁ 互不相交

**证明**：
```
Iᵢ.left = xᵢ - lowbit(xᵢ) + 1
Iᵢ₊₁.right = xᵢ₊₁ = xᵢ - lowbit(xᵢ)

⇒ Iᵢ₊₁.right = Iᵢ.left - 1

所以 Iᵢ 的左边界比 Iᵢ₊₁ 的右边界大1，区间严格相邻，不可能重叠 ✓
```

### 覆盖性证明（不遗漏）

**定理**：所有区间 Iᵢ 的并集恰好是 [1, x]

**证明**：
```
每个区间长度 |Iᵢ| = lowbit(xᵢ)

总长度 = Σ lowbit(xᵢ)

根据二进制分解：
x = Σ (2^k) for each set bit k

而每个 lowbit(xᵢ) 恰好对应 x 二进制表示中的一个 2^k

所以 Σ lowbit(xᵢ) = x ✓
```

### 举例验证
```
x = 13 = 1101 (二进制)
拆分：
- x₀ = 13, lowbit = 1, I₀ = [13, 13]
- x₁ = 12, lowbit = 4, I₁ = [9, 12]
- x₂ = 8,  lowbit = 8, I₂ = [1, 8]

验证：
[1,8] ∪ [9,12] ∪ [13,13] = [1,13] ✓
长度：8 + 4 + 1 = 13 ✓
```

### query 本质
```
query(x) = x 的二进制分解 = Σ (2^k for each set bit k)

即把 [1, x] 按"二进制块"拆分
```

## 五、add(x, delta) 的正确性证明

### 更新过程
```java
void add(int x, int delta) {
    while (x <= n) {
        tree[x] += delta;
        x += lowbit(x);
    }
}
```

### 目标
将"位置 x 的变化 delta"传播到所有"包含位置 x"的 tree 节点

### 分析

**tree[i] 覆盖的区间**：
```
[i - lowbit(i) + 1, i]
```

**需要更新的条件**：该区间包含位置 x
```
i - lowbit(i) + 1 ≤ x ≤ i
```

### 为什么 x += lowbit(x) 能找到所有需要的区间？

**关键观察**：
- lowbit(x) 每次变化，会跳到"覆盖范围更大"的区间
- 这相当于在一棵隐式树中，从叶子不断向上更新祖先节点

```
更新 x = 3 时：
- x₀ = 3,  tree[3] 需要更新（包含位置3）
- x₁ = 4,  tree[4] 需要更新（[1,4]包含位置3）
- x₂ = 8,  tree[8] 需要更新（[1,8]包含位置3）
- x₃ = 16, 超出范围，停止
```

**本质**：树状数组是一棵用**二进制隐式表示的完全二叉树**

## 六、为什么必须用 1-based 索引？

### 问题
为什么树状数组必须从下标 1 开始？数组大小是 n + 1？

### 原因分析

```java
lowbit(0) = 0  // x & -x，当 x=0 时结果为 0

// 在 add 中：
x += lowbit(x)  // 如果 x=0，则 x 一直是 0，死循环！

// 在 query 中：
x -= lowbit(x)  // 如果 x=0，则 x 一直是 0，无法结束！

// 且区间定义 [x - lowbit(x) + 1, x] 在 x=0 时无意义
```

### 解决方案
- ✅ 从 1 开始索引（1-based）
- ✅ 数组大小设为 n + 1
- ✅ query(0) 相当于 sum = 0，正常返回

## 七、完整代码实现

```java
class BIT {
    int[] tree;
    int n;

    public BIT(int n) {
        this.n = n;
        this.tree = new int[n + 1];  // 1-based
    }

    // 单点更新：将 index 位置的值增加 delta
    public void add(int index, int delta) {
        while (index <= n) {
            tree[index] += delta;
            index += index & -index;
        }
    }

    // 前缀查询：计算 sum(nums[1..index])
    public int query(int index) {
        int sum = 0;
        while (index > 0) {
            sum += tree[index];
            index -= index & -index;
        }
        return sum;
    }

    // 区间查询：计算 sum(nums[l..r])
    public int rangeQuery(int l, int r) {
        if (l > r) return 0;
        return query(r) - query(l - 1);
    }
}
```

## 八、应用实例

### LeetCode 315. 计算右侧小于当前元素的个数

```java
public List<Integer> countSmaller(int[] nums) {
    // 1. 离散化
    Set<Integer> set = new HashSet<>();
    for (int num : nums) set.add(num);
    int[] sortedNums = set.stream().sorted().mapToInt(Integer::intValue).toArray();
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < sortedNums.length; i++) {
        map.put(sortedNums[i], i + 1);
    }
    
    // 2. 初始化树状数组
    int[] tree = new int[sortedNums.length + 1];
    List<Integer> result = new ArrayList<>();
    
    // 3. 从右往左遍历
    for (int i = nums.length - 1; i >= 0; i--) {
        int index = map.get(nums[i]);
        // 查询比当前值小的个数（小于 index-1 的前缀和）
        result.add(query(tree, index - 1));
        // 更新当前值的频率
        add(tree, index);
    }
    
    Collections.reverse(result);
    return result;
}

private void add(int[] tree, int index) {
    while (index < tree.length) {
        tree[index]++;
        index += index & -index;
    }
}

private int query(int[] tree, int index) {
    int sum = 0;
    while (index > 0) {
        sum += tree[index];
        index -= index & -index;
    }
    return sum;
}
```

## 九、终极总结

### 核心三点（必须记住）

1. **tree[x] 存的是区间和**：
   ```
   tree[x] = sum(nums[x - lowbit(x) + 1 .. x])
   ```

2. **query(x)**：
   - 利用 lowbit 将 [1, x] 拆成若干"二进制区间块"
   - 证明：不重叠 + 不遗漏 + 总长度 = x

3. **add(x, delta)**：
   - 更新所有"覆盖该点"的区间
   - x += lowbit(x) 相当于向父节点传播

### 树状数组本质
```
用二进制结构实现的"前缀和分块 + 隐式线段树"

等价于：
线段树的简化版（只支持前缀运算）
```
