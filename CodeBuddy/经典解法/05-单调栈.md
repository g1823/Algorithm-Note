# 单调栈 (Monotonic Stack)

## 一、作用与适用场景

### 核心作用
单调栈是一种**特殊栈结构**，在遍历过程中维护一个**单调递增或单调递减**的序列，用于在 **O(n)** 时间复杂度内解决以下问题：
- 查找每个元素**下一个更大/更小**的元素
- 查找每个元素**前一个更大/更小**的元素
- 计算柱状图中最大矩形面积
- 接雨水问题

### 与单调队列的区别
| 特点 | 单调栈 | 单调队列 |
|------|--------|---------|
| 应用场景 | 寻找最近更大/更小元素 | 滑动窗口最值 |
| 窗口 | 无固定窗口 | 有固定窗口 |
| 移除策略 | 只在栈顶操作 | 从队首移除过期元素 |

## 二、单调栈的基本思想

### 核心思路
```
从左到右遍历数组，维护一个单调递增栈（存下标）：
- 当遇到一个新元素 nums[i] 时
- 如果 nums[i] > nums[stack.top()]：
  → 说明 stack.top() 的"下一个更大元素"找到了
  → 弹出 stack.top()，记录答案
- 重复直到 nums[i] <= nums[stack.top()]
- 将 i 压入栈
```

### 为什么 O(n)？
每个元素最多入栈一次、出栈一次，总操作数为 2n，故时间复杂度 O(n)。

## 三、代码实现

### 寻找下一个更大元素

```java
/**
 * LeetCode 739. 每日温度
 * 返回：对于每个温度，需要等待多少天才能等到更高的温度
 */
public int[] dailyTemperatures(int[] temperatures) {
    int[] result = new int[temperatures.length];
    // 存储下标（通过下标可以获取温度值）
    Stack<Integer> stack = new Stack<>();
    
    for (int i = 0; i < temperatures.length; i++) {
        // 栈不为空，且当前温度 > 栈顶温度
        while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
            int index = stack.pop();
            result[index] = i - index;  // 计算天数差
        }
        stack.push(i);  // 入栈
    }
    
    // 栈中剩余元素的答案为 0（没有更高温度）
    while (!stack.isEmpty()) {
        result[stack.pop()] = 0;
    }
    
    return result;
}

/**
 * 优化版本：使用 Deque 替代 Stack
 * Deque 更灵活，性能更好
 */
public int[] dailyTemperatures2(int[] temperatures) {
    int[] result = new int[temperatures.length];
    Deque<Integer> stack = new LinkedList<>();
    
    for (int i = 0; i < temperatures.length; i++) {
        while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
            int index = stack.pop();
            result[index] = i - index;
        }
        stack.push(i);
    }
    
    return result;
}
```

### 寻找前一个更小元素

```java
/**
 * 维护单调递增栈，找前一个更小元素
 */
public int[] findPreviousSmaller(int[] nums) {
    int[] result = new int[nums.length];
    Stack<Integer> stack = new Stack<>();
    
    for (int i = 0; i < nums.length; i++) {
        // 栈不为空，且当前元素 <= 栈顶元素时，弹出
        // 注意：这里是 <=，用于找前一个更小元素
        while (!stack.isEmpty() && nums[i] <= nums[stack.peek()]) {
            stack.pop();
        }
        
        if (stack.isEmpty()) {
            result[i] = -1;  // 没有更小元素
        } else {
            result[i] = stack.peek();  // 栈顶是前一个更小元素的下标
        }
        stack.push(i);
    }
    
    return result;
}
```

## 四、应用实例

### 1. LeetCode 42. 接雨水（单调栈解法）

```java
/**
 * 思路：
 * 维护一个递减栈。当遇到一个更高的柱子时，说明形成了"凹槽"
 * 弹出底部，计算凹槽的雨水量
 */
public int trap(int[] height) {
    int n = height.length;
    if (n <= 2) return 0;
    
    int result = 0;
    Stack<Integer> stack = new Stack<>();
    stack.push(0);
    
    for (int i = 1; i < n; i++) {
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = stack.pop();
            if (stack.isEmpty()) break;
            
            int left = stack.peek();
            int width = i - left - 1;
            int h = Math.min(height[left], height[i]) - height[bottom];
            result += width * h;
        }
        stack.push(i);
    }
    
    return result;
}
```

### 2. LeetCode 84. 柱状图中最大的矩形

```java
/**
 * 核心思路：
 * 遍历每个柱子，以它的高度作为矩形高度，向左右扩展
 * 使用单调递增栈找到"左边第一个更矮"和"右边第一个更矮"
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    int result = 0;
    Stack<Integer> stack = new Stack<>();
    
    // 扩展数组，首尾添加 0（最小的柱子）
    int[] extended = new int[n + 2];
    System.arraycopy(heights, 0, extended, 1, n);
    
    for (int i = 0; i < extended.length; i++) {
        while (!stack.isEmpty() && extended[i] < extended[stack.peek()]) {
            int height = extended[stack.pop()];
            int width = i - stack.peek() - 1;
            result = Math.max(result, height * width);
        }
        stack.push(i);
    }
    
    return result;
}
```

### 3. LeetCode 85. 最大矩形

```java
/**
 * 将二维矩阵按行压缩为一维数组
 * 对每一行，应用"柱状图中最大矩形"的算法
 */
public int maximalRectangle(char[][] matrix) {
    if (matrix.length == 0) return 0;
    
    int n = matrix[0].length;
    int[] heights = new int[n];
    int result = 0;
    
    for (int i = 0; i < matrix.length; i++) {
        for (int j = 0; j < n; j++) {
            // 累加连续 1 的高度
            if (matrix[i][j] == '1') {
                heights[j] += 1;
            } else {
                heights[j] = 0;
            }
        }
        // 应用单调栈算法
        result = Math.max(result, largestRectangleAreaHelper(heights));
    }
    
    return result;
}
```

## 五、单调栈的变体

### 1. 单调递减栈（找更大元素）

```java
// 找下一个更大元素
Stack<Integer> stack = new Stack<>();  // 存下标，维护递减序列
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
        int idx = stack.pop();
        ans[idx] = i;  // i 是 idx 的下一个更大元素
    }
    stack.push(i);
}
```

## 六、模板总结

### 模板一：下一个更大元素
```java
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] ans = new int[n];
    Stack<Integer> stack = new Stack<>();
    
    for (int i = 0; i < n; i++) {
        // 维护单调递减栈
        while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
            ans[stack.pop()] = nums[i];
        }
        stack.push(i);
    }
    
    // 栈中剩余元素的答案为 -1
    while (!stack.isEmpty()) {
        ans[stack.pop()] = -1;
    }
    
    return ans;
}
```

### 模板二：前一个更小元素
```java
public int[] prevSmallerElement(int[] nums) {
    int n = nums.length;
    int[] ans = new int[n];
    Stack<Integer> stack = new Stack<>();
    
    for (int i = 0; i < n; i++) {
        // 维护单调递增栈
        while (!stack.isEmpty() && nums[i] <= nums[stack.peek()]) {
            stack.pop();
        }
        ans[stack.isEmpty() ? -1 : stack.peek()] = nums[i];
        stack.push(i);
    }
    
    return ans;
}
```

## 七、注意事项

1. **栈中存什么**：通常存**下标**而非值，这样可以通过下标访问原数组
2. **边界处理**：首尾添加虚拟元素可以简化代码
3. **比较符号**：
   - `<` 用于找更大元素
   - `>` 用于找更小元素
   - `>=` 或 `<=` 用于包含相等的情况
4. **性能优化**：使用 `Deque`/`LinkedList` 替代 `Stack`（Stack 是同步的，性能较差）
