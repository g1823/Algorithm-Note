# 归并排序求逆序对

## 一、作用与适用场景

### 核心作用
归并排序不仅是一种高效的排序算法（O(n log n)），其**分治思想**还可以用于高效地统计**逆序对**的数量。

### 什么是逆序对？
对于数组中的两个元素 `nums[i]` 和 `nums[j]`：
- 如果 `i < j` 且 `nums[i] > nums[j]`
- 则称 `(i, j)` 为一个**逆序对**

### 应用场景
- 计算数组的"乱序程度"
- 计算"右侧小于当前元素的个数"（LeetCode 315）
- 计算"翻转对"（LeetCode 493）
- 计算"区间和的个数"（LeetCode 327）

## 二、基本思想

### 关键洞察
```
在归并排序的 merge 过程中：
- 左半部分：[left...mid]（原始位置靠左）
- 右半部分：[mid+1...right]（原始位置靠右）

如果：右侧元素 < 左侧元素
则：这个右侧元素是"左侧元素的一个逆序元素"

因为：
- 右侧元素在原始数组中位置更靠右
- 但值却更小
- → 构成逆序对
```

### 统计原理
```
在 merge 时维护变量 rightCount：
表示"已经放入结果数组的右侧元素个数"

规则：
1. 若 nums[left] <= nums[right]
   → 左元素先进结果数组
   → result[leftIndex] += rightCount
   （因为 rightCount 个右侧更小元素已经被确定）

2. 若 nums[right] < nums[left]
   → 右元素先进结果数组
   → rightCount++
   （新增一个"对左侧元素而言更小的右侧元素"）
```

## 三、代码实现

### 标准实现（基于 CountSmaller.java）

```java
public List<Integer> countSmaller(int[] nums) {
    if (nums == null || nums.length == 0) {
        return new ArrayList<>();
    }

    int n = nums.length;
    int[] temp = new int[n];      // 临时数组用于归并
    int[] result = new int[n];    // 存储每个位置的答案
    
    // 初始化下标数组
    int[] indices = new int[n];
    for (int i = 0; i < n; i++) {
        indices[i] = i;
    }
    
    // 执行归并排序
    mergeSort(nums, indices, 0, n - 1, result, temp);
    
    // 转换为 List
    List<Integer> ans = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        ans.add(result[i]);
    }
    return ans;
}

/**
 * 归并排序 + 统计逆序对
 */
private void mergeSort(int[] nums, int[] indices, int left, int right, 
                       int[] result, int[] temp) {
    if (left >= right) {
        return;  // 只有一个元素，自然有序
    }
    
    int mid = left + (right - left) / 2;
    
    // 递归排序左右两部分
    mergeSort(nums, indices, left, mid, result, temp);
    mergeSort(nums, indices, mid + 1, right, result, temp);
    
    // 合并两个有序子数组
    merge(nums, indices, left, mid, right, result, temp);
}

private void merge(int[] nums, int[] indices, int left, int mid, int right,
                   int[] result, int[] temp) {
    int i = left;      // 左半部分指针
    int j = mid + 1;   // 右半部分指针
    int k = left;      // 临时数组指针
    int rightCount = 0; // 右侧更小元素的个数
    
    while (i <= mid && j <= right) {
        if (nums[indices[i]] <= nums[indices[j]]) {
            // 左元素先进结果
            int idx = indices[i];
            temp[k++] = idx;
            result[idx] += rightCount;  // 累加逆序对数
            i++;
        } else {
            // 右元素先进结果，右半部分多了一个更小元素
            temp[k++] = indices[j];
            rightCount++;
            j++;
        }
    }
    
    // 处理剩余的左半部分
    while (i <= mid) {
        int idx = indices[i];
        temp[k++] = idx;
        result[idx] += rightCount;  // 剩余右半部分都比这些左元素小
        i++;
    }
    
    // 处理剩余的右半部分
    while (j <= right) {
        temp[k++] = indices[j++];
    }
    
    // 复制回原数组
    for (int p = left; p <= right; p++) {
        indices[p] = temp[p];
    }
}
```

## 四、数学推导

### 为什么这样统计是正确的？

**定理**：在归并排序的 merge 过程中，当左半部分的某个元素 `nums[left]` 被放入结果数组时，`rightCount` 恰好等于「右侧数组中比 `nums[left]` 小的元素个数」。

**证明**（归纳法）：

**基础情况**：merge 开始时，`rightCount = 0`。左数组的第一个元素尚未处理，显然没有右侧元素比它小。✓

**归纳假设**：假设当处理到左数组的某个元素时，`rightCount` 正确计数。

**归纳步骤**：
- 当比较 `nums[left]` 和 `nums[right]` 时：
  - 若 `nums[left] <= nums[right]`：
    - 左元素先进结果
    - 此时右数组中已有 `rightCount` 个元素被放入（都比 `nums[left]` 小）
    - `result[left] += rightCount` 正确
  - 若 `nums[right] < nums[left]`：
    - 右元素先进结果
    - `nums[right]` 是左元素的逆序元素
    - `rightCount++` 更新计数

**结论**：通过数学归纳法，每一步的 `rightCount` 都是正确的，最终的逆序对统计也是正确的。✓

### LeetCode 493. 翻转对

```java
/**
 * 问题：统计 (i, j) 对的数量，其中 i < j 且 nums[i] > 2 * nums[j]
 * 
 * 思路：
 * 在归并排序过程中，对左右两部分分别排序后
 * 在合并前统计翻转对
 */
public int reversePairs(int[] nums) {
    if (nums.length < 2) return 0;
    return reversePairsRecursive(nums, 0, nums.length - 1);
}

private int reversePairsRecursive(int[] nums, int left, int right) {
    if (left >= right) return 0;
    
    int mid = left + (right - left) / 2;
    int count = reversePairsRecursive(nums, left, mid)
              + reversePairsRecursive(nums, mid + 1, right);
    
    // 统计翻转对
    int j = mid + 1;
    for (int i = left; i <= mid; i++) {
        while (j <= right && (long) nums[i] > 2L * nums[j]) {
            j++;
        }
        count += j - (mid + 1);
    }
    
    // 合并
    merge(nums, left, mid, right);
    return count;
}
```

## 六、与其他方法的对比

| 方法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|

| 树状数组 | O(n log n) | O(n) | - |
| 线段树 | O(n log n) | O(n) | - |

**归并排序的优势**：
- ✅ 不需要离散化（适用于值域不大的情况）
- ✅ 稳定
- ✅ 代码相对简单
- ✅ 可以同时解决多个相关问题

## 七、注意事项

1. **必须使用 `<=` 而非 `<`**：
   - 如果 `nums[left] == nums[right]`，应该让左元素先进
   - 否则会错误统计相等的元素

2. **下标数组**：
   - 排序的是下标数组，而不是原数组
   - 这样才能通过 `result[index[i]]` 正确记录答案

3. **数据类型溢出**：
   - 逆序对数量可能超过 `int` 范围（如 315 题答案可能达到 n²/2）
   - 使用 `long` 存储计数

4. **递归深度**：
   - 归并排序递归深度为 O(log n)
   - Java 默认栈深度足够
