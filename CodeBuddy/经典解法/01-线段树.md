# 线段树 (Segment Tree)

## 一、作用与适用场景

### 核心作用
线段树是一种**二叉树形数据结构**，用于高效地支持**区间查询**和**区间更新**操作。

### 解决的问题
- 区间求和 (Range Sum Query)
- 区间最大值/最小值查询 (Range Max/Min Query)
- 区间更新（点更新或区间批量更新）
- 满足**结合律**的其他区间运算

### 复杂度
| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 构建 | O(n) | O(n) |
| 单点更新 | O(log n) | - |
| 区间查询 | O(log n) | - |
| 区间更新 | O(log n) | - |

---

## 二、基本原理

### 数据结构
```
线段树是一棵完全二叉树，每个节点代表一个区间：
- 根节点：代表整个数组区间 [0, n-1]
- 叶节点：代表单个元素
- 内部节点：合并左右子区间的信息
```

### 数组表示法
利用完全二叉树的性质，用数组存储（假设根节点从1开始）：
- 左子节点：index * 2
- 右子节点：index * 2 + 1
- 父节点：index / 2

### 数组大小选择
```java
// 分配 4 * n 大小的数组
tree = new int[4 * n];

// 原因分析：
// 1. 线段树叶子节点对应原数组的 n 个元素
// 2. 树的高度 h = ⌈log₂(n)⌉ + 1
// 3. 完全二叉树最多有 2^h - 1 个节点
// 4. 2^⌈log₂(n)⌉ ≤ 2n（当 n>0 时）
// 5. 所以节点数 < 2 * (2n) - 1 = 4n - 1
```

## 三、数学推导与严格证明

### 完全二叉树与数组的对应关系

**定理**：对于 n 个叶节点的完全二叉线段树，节点编号从 1 开始，可以用大小为 4n 的数组安全存储。

**证明**：
1. 设原数组大小为 n
2. 树的高度 h = ⌈log₂(n)⌉ + 1
3. 节点数最多为：2^h - 1 = 2^(⌈log₂(n)⌉+1) - 1
4. 令 m = 2^⌈log₂(n)⌉，则 m 是"不小于 n 的最小 2 的幂"
5. 因为 m ≤ 2n，所以 m + m/2 + m/4 + ... + 1 < 2m ≤ 4n
6. 得证：节点数 < 4n

### 区间查询的递归推导

**目标**：查询区间 [l, r] 的和

**递归公式**：
```
query(node, start, end, l, r):
    if [start, end] 完全在 [l, r] 外: return 0
    if [start, end] 完全在 [l, r] 内: return tree[node]
    else: return query(left_child) + query(right_child)
```

**正确性**：由于树是区间划分，每个节点的区间互不相交，递归保证了：
- 不遗漏：所有子区间都被覆盖
- 不重复：每个子区间只被访问一次

## 四、代码实现

### 实现一：真实二叉树节点（基于CountSmaller.java）

```java
class SegmentTree {
    class Node {
        int l, r;           // 区间左右边界
        int count;          // 该区间内元素出现次数
        Node left, right;  // 左右子节点
        public Node(int l, int r, int count) {
            this.l = l;
            this.r = r;
            this.count = count;
        }
    }

    Node root;

    public SegmentTree(int n) {
        root = build(1, n);
    }

    // 递归构建线段树
    private Node build(int l, int r) {
        if (l == r) {
            return new Node(l, l, 0);
        }
        int mid = l + (r - l) / 2;
        Node node = new Node(l, r, 0);
        node.left = build(l, mid);
        node.right = build(mid + 1, r);
        return node;
    }

    // 单点更新：index 位置出现次数 +1
    public void update(int index) {
        update(root, index);
    }

    private void update(Node node, int index) {
        if (node.l > index || node.r < index) return;
        if (node.l == node.r) {
            node.count++;
            return;
        }
        int mid = node.l + (node.l + node.r) / 2;
        if (index <= mid) {
            update(node.left, index);
        } else {
            update(node.right, index);
        }
        node.count = node.left.count + node.right.count;
    }

    // 区间查询：统计 [l, r] 区间内的元素个数
    public int query(int l, int r) {
        return query(root, l, r);
    }

    private int query(Node node, int l, int r) {
        if (node.l > r || node.r < l) return 0;
        if (l <= node.l && node.r <= r) return node.count;
        return query(node.left, l, r) + query(node.right, l, r);
    }
}
```

### 实现二：数组隐式表示（更常用）

```java
class SegmentTree {
    int[] tree;
    int n;

    public SegmentTree(int n) {
        this.n = n;
        tree = new int[4 * n];
    }

    public void update(int index) {
        update(1, 1, n, index);
    }

    private void update(int node, int start, int end, int key) {
        if (start == end) {
            tree[node]++;
            return;
        }
        int mid = (start + end) / 2;
        if (key <= mid) {
            update(node * 2, start, mid, key);
        } else {
            update(node * 2 + 1, mid + 1, end, key);
        }
        tree[node] = tree[node * 2] + tree[node * 2 + 1];
    }

    public int query(int l, int r) {
        return query(1, 1, n, l, r);
    }

    private int query(int node, int start, int end, int l, int r) {
        if (start > r || end < l) return 0;
        if (l <= start && end <= r) return tree[node];
        int mid = (start + end) / 2;
        return query(node * 2, start, mid, l, r) 
             + query(node * 2 + 1, mid + 1, end, l, r);
    }
}
```

## 五、应用实例

### LeetCode 315. 计算右侧小于当前元素的个数

**问题**：对于数组中每个元素，计算右侧有多少个元素比它小

**解法思路**：
1. 从右往左遍历数组
2. 使用线段树统计"已经遍历过的元素"的频率分布
3. 查询 [1, rank-1] 区间得到比当前元素小的个数
4. 更新当前元素的频率

```java
public List<Integer> countSmaller(int[] nums) {
    // 1. 离散化：将值映射为 1~n 的排名
    Set<Integer> set = new HashSet<>();
    for (int num : nums) set.add(num);
    int[] sortedNums = set.stream().sorted().mapToInt(Integer::intValue).toArray();
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < sortedNums.length; i++) {
        map.put(sortedNums[i], i + 1);
    }
    
    // 2. 构建线段树
    SegmentTree segmentTree = new SegmentTree(sortedNums.length);
    List<Integer> result = new ArrayList<>();
    
    // 3. 从右往左遍历
    for (int i = nums.length - 1; i >= 0; i--) {
        int index = map.get(nums[i]);
        // 查询比当前值小的个数
        result.add(segmentTree.query(1, index - 1));
        // 更新当前值出现次数
        segmentTree.update(index);
    }
    
    Collections.reverse(result);
    return result;
}
```

## 六、变体与扩展

### 1. 区间更新线段树（支持区间加减）
```java
// 懒标记线段树：增加 lazy 数组记录未向下传递的更新
class LazySegmentTree {
    int[] tree, lazy;
    
    public void rangeUpdate(int node, int start, int end, int l, int r, int val) {
        if (lazy[node] != 0) {
            // 先下推懒标记
            tree[node] += lazy[node] * (end - start + 1);
            if (start != end) {
                lazy[node*2] += lazy[node];
                lazy[node*2+1] += lazy[node];
            }
            lazy[node] = 0;
        }
        // 递归更新...
    }
}
```

## 七、注意事项

1. **数组大小**：使用 4n 而非 2n，保证不会越界
2. **离散化**：当原数组值域很大时，必须先离散化
3. **递归深度**：最坏情况深度为 O(log n)，Java 默认栈深度足够
4. **初始化**：需要明确 tree 数组的初始化值（通常为0）
5. **边界处理**：注意使用 `int mid = start + (end - start) / 2` 防止整数溢出
