# 堆与优先队列 (Heap / Priority Queue)

## 一、堆的基本概念

### 定义
堆是一棵**完全二叉树**，满足**堆序性质**：
- **大顶堆（Max Heap）**：父节点 ≥ 子节点，堆顶是最大值
- **小顶堆（Min Heap）**：父节点 ≤ 子节点，堆顶是最小值

### 性质
- **完全二叉树**：除了最后一层，其他层都是满的，最后一层从左到右填充
- **可以用数组存储**：利用下标关系，无需指针

### 数组表示法
```
下标关系（假设根从 1 开始）：
- 父节点：i / 2
- 左子节点：i * 2
- 右子节点：i * 2 + 1

（如果根从 0 开始）：
- 父节点：(i - 1) / 2
- 左子节点：i * 2 + 1
- 右子节点：i * 2 + 2
```

## 二、堆的核心操作

### 1. 上浮 (sift up)
当插入新元素或修改堆中某个元素时，可能破坏堆序性质，需要将其向上移动到正确位置。

```java
private void siftUp(int k) {
    while (k > 1 && heap[k] > heap[k/2]) {
        swap(heap, k, k/2);
        k = k/2;
    }
}
```

### 2. 下沉 (sift down)
当删除堆顶或修改某个元素时，可能需要向下调整。

```java
private void siftDown(int k) {
    while (k * 2 <= size) {
        int j = k * 2;  // 默认和左子节点比较
        if (j + 1 <= size && heap[j + 1] > heap[j]) {
            j = j + 1;  // 右子节点更大
        }
        if (heap[k] >= heap[j]) {
            break;  // 已满足堆序
        }
        swap(heap, k, j);
        k = j;
    }
}
```

### 3. 建堆
将任意数组调整为堆结构，时间复杂度 O(n)。

```java
// 自下而上下沉建堆
public void buildHeap(int[] arr) {
    this.heap = arr;
    this.size = arr.length;
    // 从最后一个非叶子节点开始下沉
    for (int i = size / 2; i >= 1; i--) {
        siftDown(i);
    }
}
```

## 三、优先队列

### 定义
优先队列是基于堆实现的数据结构，每次取出的是**优先级最高（或最低）**的元素。

### Java 实现
```java
// 默认是小顶堆（最小元素先出队）
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// 大顶堆（最大元素先出队）
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);

// 或者使用 Lambda
PriorityQueue<Integer> maxHeap2 = new PriorityQueue<>(Comparator.reverseOrder());
```

### 基本操作
| 操作 | 方法 | 时间复杂度 |
|------|------|-----------|
| 入队 | `offer(e)` / `add(e)` | O(log n) |
| 出队（最大值） | `poll()` | O(log n) |
| 查看堆顶 | `peek()` | O(1) |

## 四、堆排序 (Heap Sort)

### 算法步骤
1. 将数组建成大顶堆
2. 循环进行：
   - 交换堆顶和堆尾（最大值放到正确位置）
   - 将堆大小减 1
   - 对堆顶进行下沉操作

### 代码实现

```java
public void heapSort(int[] nums) {
    int n = nums.length;
    
    // 1. 建大顶堆
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(nums, n, i);
    }
    
    // 2. 排序
    for (int i = n - 1; i > 0; i--) {
        // 交换堆顶和当前堆尾
        swap(nums, 0, i);
        // 调整剩余元素为大顶堆
        heapify(nums, i, 0);
    }
}

private void heapify(int[] nums, int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    
    if (left < n && nums[left] > nums[largest]) {
        largest = left;
    }
    if (right < n && nums[right] > nums[largest]) {
        largest = right;
    }
    if (largest != i) {
        swap(nums, i, largest);
        heapify(nums, n, largest);
    }
}
```

### 复杂度分析
| 指标 | 复杂度 |
|------|--------|
| 时间复杂度 | O(n log n) |
| 空间复杂度 | O(1) |
| 稳定性 | 不稳定 |

## 五、双堆技巧：数据流中位数

### 核心思想
维护两个堆：
- **大顶堆**：存放较小的一半元素，堆顶是较小元素中的最大值
- **小顶堆**：存放较大的一半元素，堆顶是较大元素中的最小值

### 不变量
1. `maxHeap.size() >= minHeap.size()`（两堆大小差 ≤ 1）
2. `maxHeap` 中的所有元素 ≤ `minHeap` 中的所有元素

### 算法流程

```java
class MedianFinder {
    // 大顶堆：存放较小的一半
    private PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
    // 小顶堆：存放较大的一半
    private PriorityQueue<Integer> minHeap = new PriorityQueue<>();

    public void addNum(int num) {
        // 1. 先加入大顶堆
        maxHeap.offer(num);
        
        // 2. 移动最大堆的堆顶到小顶堆，保证顺序
        minHeap.offer(maxHeap.poll());
        
        // 3. 如果小顶堆元素更多，移回一个
        if (minHeap.size() > maxHeap.size()) {
            maxHeap.offer(minHeap.poll());
        }
    }

    public double findMedian() {
        // 大顶堆元素多时，返回大顶堆堆顶
        if (maxHeap.size() > minHeap.size()) {
            return maxHeap.peek();
        }
        // 两堆元素相等时，返回两堆顶平均值
        return (maxHeap.peek() + minHeap.peek()) / 2.0;
    }
}
```

### 图解
```
添加 1, 3, 2, 5, 4 的过程：

添加1:  maxHeap=[1],      minHeap=[]      → 中位数=1
添加3:  maxHeap=[3],      minHeap=[1]     → 中位数=(3+1)/2=2
添加2:  maxHeap=[2,1],    minHeap=[3]     → 中位数=2
添加5:  maxHeap=[3,1],    minHeap=[5,2]   → 中位数=(3+2)/2=2.5
添加4:  maxHeap=[4,1,3],  minHeap=[5,2]   → 中位数=3
```

### 复杂度分析
| 操作 | 时间复杂度 |
|------|-----------|
| addNum | O(log n) |
| findMedian | O(1) |

## 六、应用场景

### 1. Top K 问题
求第 k 大的元素或最小的 k 个元素

```java
// 方法1：全部排序 O(n log n)
Arrays.sort(arr);
// 方法2：小顶堆 O(n log k)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
for (int num : arr) {
    minHeap.offer(num);
    if (minHeap.size() > k) {
        minHeap.poll();
    }
}
// 方法3：大顶堆 O(n log k) - 找第k大
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
```

### 2. 合并 K 个有序链表
```java
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> minHeap = new PriorityQueue<>(
        Comparator.comparingInt(n -> n.val)
    );
    
    for (ListNode node : lists) {
        if (node != null) {
            minHeap.offer(node);
        }
    }
    
    ListNode dummy = new ListNode(0);
    ListNode cur = dummy;
    
    while (!minHeap.isEmpty()) {
        ListNode node = minHeap.poll();
        cur.next = node;
        cur = cur.next;
        if (node.next != null) {
            minHeap.offer(node.next);
        }
    }
    
    return dummy.next;
}
```

### 3. 滑动窗口最大值（堆 + 延迟删除）

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int[] result = new int[nums.length - k + 1];
    // 大顶堆：(值, 下标)
    PriorityQueue<int[]> maxHeap = new PriorityQueue<>(
        (a, b) -> b[0] - a[0]
    );
    
    for (int i = 0; i < nums.length; i++) {
        maxHeap.offer(new int[]{nums[i], i});
        // 移除不在窗口内的元素
        while (maxHeap.peek()[1] <= i - k) {
            maxHeap.poll();
        }
        // 记录答案
        if (i >= k - 1) {
            result[i - k + 1] = maxHeap.peek()[0];
        }
    }
    
    return result;
}
```

## 八、注意事项

1. **Java PriorityQueue 默认是小顶堆**
2. **PriorityQueue 不是线程安全的**，多线程使用 `PriorityBlockingQueue`
3. **无法直接修改堆中某个元素**（需要先删除再插入，或使用索引堆）
4. **堆排序是不稳定的排序算法**
