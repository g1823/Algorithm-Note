# 单调队列 (Monotonic Queue)

## 一、作用与适用场景

### 核心作用
单调队列是一种**特殊队列结构**，在滑动窗口遍历过程中维护一个**单调递增或递减**的序列，用于在 **O(n)** 时间复杂度内解决滑动窗口的最值问题。

### 解决的问题
- 滑动窗口最大值 / 最小值
- 滑动窗口第 K 大 / 第 K 小
- 任何需要"带过期机制的滑动窗口极值"的问题

### 与单调栈的区别
| 特点 | 单调栈 | 单调队列 |
|------|--------|---------|
| 应用场景 | 寻找最近更大/更小元素 | 滑动窗口最值 |
| 窗口 | 无固定窗口 | 有固定窗口 |
| 移除策略 | 只从栈顶移除 | 从队首移除过期元素，从队尾移除违反单调性 |

## 二、单调队列的基本思想

### 核心思想
```
维护一个单调递减队列（存下标）：
- 队首始终是当前窗口的最大值
- 新元素从队尾入队，移除所有比它小的元素
- 窗口滑动时，从队首移除过期元素

为什么正确？
→ 比当前元素小的，永远不会成为未来窗口的最大值
→ 可以安全移除
```

### 图解示例
```
数组: [1, 3, -1, -3, 5, 3, 6, 7], 窗口大小 k=3

窗口 [1,3,-1] 的最大值：
- 入队 1: deque = [0]
- 入队 3: 移除 1，入队 3: deque = [1]  → max=3
- 入队 -1: deque = [1,2]             → max=3

窗口 [3,-1,-3] 的最大值：
- 滑动：队首 0 已过期（i-k=0），移除
- 入队 -3: deque = [1,2,3]           → max=3

窗口 [-1,-3,5] 的最大值：
- 移除过期下标 1,2
- 入队 5: 移除 -1,-3，入队 5: deque = [4] → max=5

...以此类推
```

## 三、代码实现

### 基于数组的手写单调队列

```java
/**
 * LeetCode 239. 滑动窗口最大值
 * 使用自定义双端队列实现
 */
class MaxSlidingWindow {
    
    class Node {
        int index;
        Node next;
        Node prev;
        public Node(int index) {
            this.index = index;
        }
    }

    class Deque {
        Node head;  // 队首（最大值所在位置）
        Node tail;  // 队尾
        int[] nums; // 引用原数组，用于比较值

        public Deque(int[] nums) {
            this.nums = nums;
        }

        /**
         * 从队尾入队：移除所有比当前元素小的节点
         * 保证队列单调递减
         */
        public void addLast(int index) {
            // 从后往前找，移除所有比 nums[index] 小的
            while (tail != null && nums[tail.index] < nums[index]) {
                tail = tail.prev;
            }

            Node newNode = new Node(index);

            if (head == null) {
                head = tail = newNode;
            } else if (tail == null) {
                // 所有元素都被移除了
                head = tail = newNode;
            } else {
                // 连接到 tail 后面
                tail.next = newNode;
                newNode.prev = tail;
                tail = newNode;
            }
        }

        public int getMax() {
            return nums[head.index];
        }

        /**
         * 从队首出队：移除过期元素
         */
        public void removeFirst(int expireIndex) {
            if (head != null && head.index == expireIndex) {
                head = head.next;
                if (head != null) {
                    head.prev = null;
                } else {
                    tail = null;
                }
            }
        }
    }

    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0) return new int[0];

        int[] result = new int[nums.length - k + 1];
        Deque deque = new Deque(nums);

        for (int i = 0; i < nums.length; i++) {
            // 1. 新元素入队（移除比它小的）
            deque.addLast(i);

            // 2. 移除过期元素（不在窗口内）
            if (i >= k) {
                deque.removeFirst(i - k);
            }

            // 3. 记录答案
            if (i >= k - 1) {
                result[i - k + 1] = deque.getMax();
            }
        }

        return result;
    }
}
```

### 使用 Java Deque 的简洁实现

```java
public int[] maxSlidingWindow2(int[] nums, int k) {
    if (nums == null || nums.length == 0) return new int[0];

    int[] result = new int[nums.length - k + 1];
    // 双端队列，存放下标
    Deque<Integer> deque = new LinkedList<>();

    for (int i = 0; i < nums.length; i++) {
        // 1. 移除队首过期元素
        if (!deque.isEmpty() && deque.peek() <= i - k) {
            deque.poll();
        }

        // 2. 移除队尾比当前元素小的元素
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // 3. 入队
        deque.offer(i);

        // 4. 记录答案
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peek()];
        }
    }

    return result;
}
```

## 四、单调队列的变体

### 1. 单调递增队列（求滑动窗口最小值）

```java
public int[] minSlidingWindow(int[] nums, int k) {
    int[] result = new int[nums.length - k + 1];
    Deque<Integer> deque = new LinkedList<>();

    for (int i = 0; i < nums.length; i++) {
        // 移除过期元素
        if (!deque.isEmpty() && deque.peek() <= i - k) {
            deque.poll();
        }

        // 移除队尾比当前元素大的元素（改为 >= 求最小值时）
        while (!deque.isEmpty() && nums[deque.peekLast()] >= nums[i]) {
            deque.pollLast();
        }

        deque.offer(i);

        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peek()];
        }
    }

    return result;
}
```

### 2. 同时维护最大和最小值

```java
class MinMaxQueue {
    Deque<Integer> maxDeque = new LinkedList<>();  // 递减
    Deque<Integer> minDeque = new LinkedList<>();  // 递增

    public void offer(int val) {
        // 维护 maxDeque
        while (!maxDeque.isEmpty() && val > maxDeque.peekLast()) {
            maxDeque.pollLast();
        }
        maxDeque.offer(val);

        // 维护 minDeque
        while (!minDeque.isEmpty() && val < minDeque.peekLast()) {
            minDeque.pollLast();
        }
        minDeque.offer(val);
    }

    public void poll(int val) {
        if (!maxDeque.isEmpty() && maxDeque.peekFirst() == val) {
            maxDeque.pollFirst();
        }
        if (!minDeque.isEmpty() && minDeque.peekFirst() == val) {
            minDeque.pollFirst();
        }
    }

    public int getMax() {
        return maxDeque.isEmpty() ? Integer.MIN_VALUE : maxDeque.peekFirst();
    }

    public int getMin() {
        return minDeque.isEmpty() ? Integer.MAX_VALUE : minDeque.peekFirst();
    }
}
```

/**
 * 思路：维护最大值和最小值的差值
 */
public boolean hasArray(int[] nums, int k) {
    Deque<Integer> maxDeque = new LinkedList<>();  // 存可能的最大值下标
    Deque<Integer> minDeque = new LinkedList<>();  // 存可能的最小值下标
    
    int left = 0;
    for (int right = 0; right < nums.length; right++) {
        // 维护 maxDeque 和 minDeque
        
        while (nums[maxDeque.peekLast()] - nums[minDeque.peekLast()] > k) {
            // 收缩窗口
            left = Math.min(left + 1, Math.min(maxDeque.peek(), minDeque.peek()) + 1);
            // 移除过期元素
        }
    }
}

## 六、模板总结

### 滑动窗口最大值模板
```java
public int[] slidingWindowMax(int[] nums, int k) {
    int[] result = new int[nums.length - k + 1];
    Deque<Integer> deque = new LinkedList<>();  // 存下标

    for (int i = 0; i < nums.length; i++) {
        // 1. 移除队首过期元素
        if (!deque.isEmpty() && deque.peek() <= i - k) {
            deque.poll();
        }

        // 2. 移除队尾违反单调性的元素（最大值：<=, 最小值：>=）
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // 3. 入队
        deque.offer(i);

        // 4. 记录答案（从第 k 个元素开始）
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peek()];
        }
    }

    return result;
}
```

## 七、注意事项

1. **存放下标而非值**：
   - 优点：通过下标可以访问原数组
   - 优点：便于判断元素是否过期
   - 优点：可以区分相等的元素

2. **队首过期 vs 队尾单调**：
   - 先移除过期元素（队首）
   - 再移除违反单调性的元素（队尾）

3. **时间复杂度**：
   - 每个元素最多入队、出队各一次
   - 总操作数 2n，故 O(n)

4. **Java 中的选择**：
   - `LinkedList` 实现 `Deque` 是最优选择
   - 避免使用 `Stack`（同步且继承自 Vector）
