# 离散化

## 一、作用与适用场景

### 核心作用
离散化是将**值域跨度大**的数据映射到**连续的整数索引**的过程，用于解决「值域太大无法直接作为数组下标」的问题。

### 何时需要离散化
- 值域为 `[-10^9, 10^9]` 甚至更大
- 数组下标无法直接使用这些值
- 需要使用线段树、树状数组等数据结构

### 常见场景
- LeetCode 315：计算右侧小于当前元素的个数
- LeetCode 327：区间和的个数
- 使用树状数组/线段树时

## 二、基本方法

### 方法一：排序 + 去重

```java
/**
 * 离散化：将值映射为 1~n 的排名
 */
public int[] discretize(int[] nums) {
    // 1. 复制并排序
    int[] sorted = nums.clone();
    Arrays.sort(sorted);
    
    // 2. 去重
    int uniqueCount = 0;
    for (int i = 0; i < sorted.length; i++) {
        if (i == 0 || sorted[i] != sorted[i - 1]) {
            sorted[uniqueCount++] = sorted[i];
        }
    }
    
    // 3. 二分查找映射
    int[] result = new int[nums.length];
    for (int i = 0; i < nums.length; i++) {
        result[i] = Arrays.binarySearch(sorted, 0, uniqueCount, nums[i]) + 1;
    }
    
    return result;
}
```

### 方法二：使用 TreeMap

```java
/**
 * 使用 TreeMap 自动排名
 */
public Map<Integer, Integer> discretizeWithTreeMap(int[] nums) {
    Map<Integer, Integer> map = new TreeMap<>();
    for (int num : nums) {
        map.put(num, map.size() + 1);  // TreeMap 自动排序
    }
    return map;
}
```

## 三、应用实例

### LeetCode 315. 计算右侧小于当前元素的个数

```java
public List<Integer> countSmaller(int[] nums) {
    // 1. 离散化
    Set<Integer> set = new HashSet<>();
    for (int num : nums) {
        set.add(num);
    }
    int[] sortedNums = set.stream().sorted().mapToInt(Integer::intValue).toArray();
    
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < sortedNums.length; i++) {
        map.put(sortedNums[i], i + 1);  // 1-indexed
    }
    
    // 2. 使用树状数组统计
    int n = sortedNums.length;
    int[] tree = new int[n + 1];
    List<Integer> result = new ArrayList<>();
    
    for (int i = nums.length - 1; i >= 0; i--) {
        int rank = map.get(nums[i]);
        result.add(query(tree, rank - 1));  // 查询比它小的个数
        update(tree, rank);                  // 更新当前值的频率
    }
    
    Collections.reverse(result);
    return result;
}

private void update(int[] tree, int index) {
    while (index < tree.length) {
        tree[index]++;
        index += index & -index;
    }
}

private int query(int[] tree, int index) {
    int sum = 0;
    while (index > 0) {
        sum += tree[index];
        index -= index & -index;
    }
    return sum;
}
```

### 带区间操作的离散化

```java
/**
 * 离散化 + 区间更新
 * 用于需要同时处理点更新和区间查询的场景
 */
public class DiscretizeWithIntervals {
    
    /**
     * 将所有用到的坐标进行离散化
     * 注意：如果需要区间操作，需要在端点处加 1
     */
    public List<Integer> discretizeWithIntervals(int[][] intervals) {
        Set<Integer> coords = new TreeSet<>();
        
        for (int[] interval : intervals) {
            coords.add(interval[0]);
            coords.add(interval[1] + 1);  // 区间右端点 +1
        }
        
        // 坐标压缩
        Map<Integer, Integer> map = new HashMap<>();
        int idx = 1;
        for (int coord : coords) {
            map.put(coord, idx++);
        }
        
        return null;  // 返回压缩后的坐标
    }
}
```

## 四、注意事项

1. **去重**：
   - 如果相同值需要相同排名，先去重
   - 使用 `HashSet` 或 `TreeSet`

2. **边界处理**：
   - 区间操作时，右端点 +1
   - 树状数组必须用 1-indexed

3. **稳定性**：
   - 相同值的元素必须映射到相同排名
   - 这是归并排序求逆序对不需要显式离散化的原因
