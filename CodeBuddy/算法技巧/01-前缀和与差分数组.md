# 前缀和与差分数组

## 一、作用与适用场景

### 前缀和（Prefix Sum）
**核心作用**：在 **O(1)** 时间复杂度内计算任意区间的元素和。

**适用场景**：
- 频繁查询区间和的场景
- 降低时间复杂度（从 O(n) 到 O(1)）

### 差分数组（Difference Array）
**核心作用**：在 **O(1)** 时间复杂度内对区间进行批量加减操作。

**适用场景**：
- 频繁对区间进行增减操作的场景
- 减少更新操作的时间复杂度

## 二、前缀和

### 基本思想
```
原数组:  [a0, a1, a2, a3, a4, a5]
前缀和:  [a0, a0+a1, a0+a1+a2, ...]

前缀和数组 preSum：
preSum[i] = a0 + a1 + ... + ai
preSum[-1] = 0（方便计算）

区间和 [l, r] = preSum[r] - preSum[l-1]
```

### 代码实现

```java
/**
 * LeetCode 303. 区域和检索 - 数组不可变
 */
class NumArray {
    private int[] prefixSum;

    public NumArray(int[] nums) {
        prefixSum = new int[nums.length];
        if (nums.length == 0) return;
        
        prefixSum[0] = nums[0];
        for (int i = 1; i < nums.length; i++) {
            prefixSum[i] = prefixSum[i - 1] + nums[i];
        }
    }

    /**
     * 查询区间 [left, right] 的和
     * 时间复杂度：O(1)
     */
    public int sumRange(int left, int right) {
        if (left == 0) {
            return prefixSum[right];
        }
        return prefixSum[right] - prefixSum[left - 1];
    }
}
```

### 二维前缀和

```java
/**
 * 二维矩阵的区域和检索
 */
class NumMatrix {
    private int[][] prefixSum;

    public NumMatrix(int[][] matrix) {
        if (matrix == null || matrix.length == 0) return;
        
        int m = matrix.length;
        int n = matrix[0].length;
        prefixSum = new int[m + 1][n + 1];  // 多一行一列，方便计算
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                prefixSum[i][j] = prefixSum[i-1][j] + prefixSum[i][j-1] 
                                 - prefixSum[i-1][j-1] + matrix[i-1][j-1];
            }
        }
    }

    /**
     * 查询左上角 (row1, col1) 到右下角 (row2, col2) 的矩形区域和
     */
    public int sumRegion(int row1, int col1, int row2, int col2) {
        return prefixSum[row2+1][col2+1] - prefixSum[row1][col2+1]
             - prefixSum[row2+1][col1] + prefixSum[row1][col1];
    }
}
```

## 三、差分数组

### 基本思想
```
原数组:    [a0, a1, a2, a3, a4]
差分数组:   [a0, a1-a0, a2-a1, a3-a2, a4-a3]

性质：
1. diff[i] = nums[i] - nums[i-1]（i > 0）
2. diff[0] = nums[0]
3. 对区间 [l, r] 加 val：
   → diff[l] += val
   → diff[r+1] -= val
4. 差分数组的前缀和 = 原数组
```

### 代码实现

```java
/**
 * LeetCode 1109. 航班预订统计
 * 问题：有 n 个航班，m 条预订记录，第 i 条预订了 from 到 to 的航班，共 seats 个
 * 求每个航班的最终预订数
 */
public int[] corpFlightBookings(int[][] bookings, int n) {
    // 差分数组
    int[] diff = new int[n];
    
    // 处理每个预订
    for (int[] booking : bookings) {
        int first = booking[0] - 1;  // 转为 0-indexed
        int last = booking[1] - 1;
        int seats = booking[2];
        
        diff[first] += seats;
        if (last + 1 < n) {
            diff[last + 1] -= seats;
        }
    }
    
    // 还原原数组
    int[] result = new int[n];
    result[0] = diff[0];
    for (int i = 1; i < n; i++) {
        result[i] = result[i - 1] + diff[i];
    }
    
    return result;
}
```

### 一维差分模板

```java
/**
 * 区间批量操作模板
 */
class Difference {
    private int[] diff;

    // 构造差分数组
    public Difference(int[] nums) {
        diff = new int[nums.length];
        if (nums.length > 0) {
            diff[0] = nums[0];
            for (int i = 1; i < nums.length; i++) {
                diff[i] = nums[i] - nums[i - 1];
            }
        }
    }

    /**
     * 对区间 [left, right] 加 val
     */
    public void increment(int left, int right, int val) {
        diff[left] += val;
        if (right + 1 < diff.length) {
            diff[right + 1] -= val;
        }
    }

    /**
     * 获取结果数组
     */
    public int[] getResult() {
        int[] result = new int[diff.length];
        result[0] = diff[0];
        for (int i = 1; i < diff.length; i++) {
            result[i] = result[i - 1] + diff[i];
        }
        return result;
    }
}
```

## 四、应用实例

### LeetCode 560. 和为 K 的子数组

```java
/**
 * 思路：前缀和 + 哈希表
 * 
 * 原问题：统计和为 k 的连续子数组个数
 * 优化：使用前缀和，将问题转化为：
 *   统计以当前位置结尾的子数组中，有多少个的前缀和差值为 k
 *   即：preSum[i] - preSum[j] = k → preSum[j] = preSum[i] - k
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);  // 前缀和为0的出现1次
    
    int sum = 0;
    int result = 0;
    
    for (int num : nums) {
        sum += num;
        // 查找有多少个前缀和等于 sum - k
        result += prefixCount.getOrDefault(sum - k, 0);
        // 更新当前前缀和的数量
        prefixCount.put(sum, prefixCount.getOrDefault(sum, 0) + 1);
    }
    
    return result;
}
```

### LeetCode 238. 除自身以外数组的乘积

```java
/**
 * 思路：前缀积 + 后缀积
 */
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    
    // 前缀积
    result[0] = 1;
    for (int i = 1; i < n; i++) {
        result[i] = result[i - 1] * nums[i - 1];
    }
    
    // 后缀积
    int suffix = 1;
    for (int i = n - 1; i >= 0; i--) {
        result[i] *= suffix;
        suffix *= nums[i];
    }
    
    return result;
}
```

### LeetCode 1248. 统计「优美子数组」

```java
/**
 * 思路：前缀和 + 哈希表
 * 将奇数视为1，偶数视为0，求连续子数组和为k的个数
 */
public int numberOfSubarrays(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    count.put(0, 1);  // 前缀和为0出现1次
    
    int sum = 0;
    int result = 0;
    
    for (int num : nums) {
        sum += num % 2;  // 累加奇数计数
        result += count.getOrDefault(sum - k, 0);
        count.put(sum, count.getOrDefault(sum, 0) + 1);
    }
    
    return result;
}
```

## 五、二维差分数组

```java
/**
 * 二维差分数组：用于批量对矩阵的子矩形区域加减操作
 */
class Difference2D {
    private int[][] diff;

    public Difference2D(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;
        diff = new int[m + 1][n + 1];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                insert(i, j, i, j, matrix[i][j]);
            }
        }
    }

    /**
     * 对子矩形区域 (r1,c1) 到 (r2,c2) 加 val
     */
    public void insert(int r1, int c1, int r2, int c2, int val) {
        diff[r1][c1] += val;
        diff[r1][c2 + 1] -= val;
        diff[r2 + 1][c1] -= val;
        diff[r2 + 1][c2 + 1] += val;
    }

    /**
     * 获取结果矩阵
     */
    public int[][] getResult() {
        int m = diff.length - 1;
        int n = diff[0].length - 1;
        int[][] result = new int[m][n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result[i][j] = (i > 0 ? result[i - 1][j] : 0) 
                             + (j > 0 ? result[i][j - 1] : 0) 
                             - (i > 0 && j > 0 ? result[i - 1][j - 1] : 0) 
                             + diff[i][j];
            }
        }
        return result;
    }
}
```

## 六、注意事项

1. **前缀和数组大小**：
   - 一维：`preSum.length = nums.length`（或 `nums.length + 1`）
   - 二维：通常 `preSum[m+1][n+1]` 便于计算

2. **数据类型选择**：
   - 如果数组元素可能为负数，使用 `long`
   - 累计和可能超出 `int` 范围

3. **差分数组边界**：
   - `diff[r+1]` 和 `diff[c+1]` 需要检查越界

4. **初始化**：
   - 哈希表法前缀和：`count.put(0, 1)` 表示前缀和为0的情况
