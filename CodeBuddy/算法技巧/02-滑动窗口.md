# 滑动窗口

## 一、作用与适用场景

### 核心作用
滑动窗口是一种**双指针技巧**，通过维护一个"窗口"在数组/字符串上滑动，高效地处理**连续子数组/子串**问题。

### 解决的问题
- 长度最小的子数组（和 >= target）
- 无重复字符的最长子串
- 字符串的字母异位词
- 滑动窗口最大值/最小值

### 时间复杂度
- **暴力**：O(n²) 或 O(n³)
- **滑动窗口**：O(n)（每个元素最多入、出窗口各一次）

---

## 二、基本思想

### 核心框架
```java
int left = 0, right = 0;
while (right < nums.length) {
    // 1. 将 right 元素加入窗口
    window.add(nums[right]);
    right++;
    
    // 2. 收缩窗口（根据题目条件）
    while (valid == false) {  // 或 window.size() > k
        // 移除 left 元素
        window.remove(nums[left]);
        left++;
    }
    
    // 3. 更新答案
    result = Math.max(result, right - left);
}
```

### 两种类型
1. **固定窗口大小**：窗口大小始终为 k
2. **可变窗口大小**：窗口大小根据条件变化

## 三、代码实现

### 1. 固定窗口：长度最小的子数组

```java
/**
 * LeetCode 209. 长度最小的子数组
 * 问题：找和 >= target 的最短连续子数组长度
 */
public int minSubArrayLen(int target, int[] nums) {
    int n = nums.length;
    int left = 0;
    int sum = 0;
    int result = Integer.MAX_VALUE;
    
    for (int right = 0; right < n; right++) {
        sum += nums[right];
        
        // 收缩窗口
        while (sum >= target) {
            result = Math.min(result, right - left + 1);
            sum -= nums[left];
            left++;
        }
    }
    
    return result == Integer.MAX_VALUE ? 0 : result;
}
```

### 2. 可变窗口：无重复字符的最长子串

```java
/**
 * LeetCode 3. 无重复字符的最长子串
 */
public int lengthOfLongestSubstring(String s) {
    Set<Character> window = new HashSet<>();
    int left = 0;
    int result = 0;
    
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        
        // 收缩窗口直到没有重复
        while (window.contains(c)) {
            window.remove(s.charAt(left));
            left++;
        }
        
        window.add(c);
        result = Math.max(result, right - left + 1);
    }
    
    return result;
}

/**
 * 优化版本：使用 HashMap 记录字符位置
 */
public int lengthOfLongestSubstring2(String s) {
    Map<Character, Integer> window = new HashMap<>();
    int left = 0;
    int result = 0;
    
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        
        if (window.containsKey(c)) {
            // 跳过重复字符，但注意取 max（防止 left 回退）
            left = Math.max(left, window.get(c) + 1);
        }
        
        window.put(c, right);
        result = Math.max(result, right - left + 1);
    }
    
    return result;
}
```

### 3. 字符串排列（字母异位词）

```java
/**
 * LeetCode 567. 字符串的排列
 * 问题：判断 s2 是否包含 s1 的某种排列
 */
public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;
    
    int[] need = new int[26];
    int[] window = new int[26];
    
    // 统计 s1 需要的字符
    for (char c : s1.toCharArray()) {
        need[c - 'a']++;
    }
    
    int left = 0;
    int valid = 0;
    int required = (int) Arrays.stream(need).filter(x -> x > 0).count();
    
    for (int right = 0; right < s2.length(); right++) {
        char c = s2.charAt(right);
        
        if (need[c - 'a'] > 0) {
            window[c - 'a']++;
            if (window[c - 'a'] == need[c - 'a']) {
                valid++;
            }
        }
        
        // 收缩窗口
        while (right - left + 1 > s1.length()) {
            char d = s2.charAt(left);
            if (need[d - 'a'] > 0) {
                if (window[d - 'a'] == need[d - 'a']) {
                    valid--;
                }
                window[d - 'a']--;
            }
            left++;
        }
        
        // 检查是否匹配
        if (valid == required) {
            return true;
        }
    }
    
    return false;
}
```

### 4. 最小覆盖子串

```java
/**
 * LeetCode 76. 最小覆盖子串
 */
public String minWindow(String s, String t) {
    if (s.length() < t.length()) return "";
    
    Map<Character, Integer> need = new HashMap<>();
    Map<Character, Integer> window = new HashMap<>();
    
    for (char c : t.toCharArray()) {
        need.put(c, need.getOrDefault(c, 0) + 1);
    }
    
    int left = 0, right = 0;
    int valid = 0;
    int required = need.size();
    int start = 0, len = Integer.MAX_VALUE;
    
    while (right < s.length()) {
        char c = s.charAt(right);
        right++;
        
        if (need.containsKey(c)) {
            window.put(c, window.getOrDefault(c, 0) + 1);
            if (window.get(c).equals(need.get(c))) {
                valid++;
            }
        }
        
        // 收缩窗口
        while (valid == required) {
            if (right - left < len) {
                start = left;
                len = right - left;
            }
            
            char d = s.charAt(left);
            left++;
            
            if (need.containsKey(d)) {
                if (window.get(d).equals(need.get(d))) {
                    valid--;
                }
                window.put(d, window.get(d) - 1);
            }
        }
    }
    
    return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
}
```

## 四、应用场景分类

### 1. 子数组/子串问题
| 问题 | 窗口类型 | 核心技巧 |
|------|---------|---------|
| 长度最小的子数组 | 可变 | 收缩条件：sum >= target |
| 无重复字符的最长子串 | 可变 | 使用 Set/Map 记录字符 |
| 串联所有单词的子串 | 固定 | 窗口大小 = sum(wordLengths) |

### 2. 固定窗口问题
| 问题 | 窗口类型 | 核心技巧 |
|------|---------|---------|
| 滑动窗口最大值 | 固定 + 单调队列 | 维护递减队列 |
| 滑动窗口中位数 | 固定 + 双堆 | 延迟删除 |
| 最多 K 个不同字符 | 固定 | 计数 + 收缩 |

### 3. 排列问题
| 问题 | 窗口类型 | 核心技巧 |
|------|---------|---------|
| 字符串的排列 | 固定 | 字符计数相等 |
| 找到字符串中所有字母异位词 | 固定 | 同上 |

## 五、模板总结

### 模板一：可变窗口（收缩条件明确）
```java
public int slidingWindow(int[] nums) {
    int left = 0;
    int result = 0;
    // 初始化窗口相关变量
    
    for (int right = 0; right < nums.length; right++) {
        // 1. 加入 right 元素
        window.add(nums[right]);
        
        // 2. 收缩窗口
        while (needToShrink()) {
            window.remove(nums[left]);
            left++;
        }
        
        // 3. 更新答案
        result = max(result, window.size());
    }
    
    return result;
}
```

### 模板二：固定窗口
```java
public int slidingWindowFixed(int[] nums, int k) {
    int left = 0;
    int result = 0;
    // 初始化窗口
    
    for (int right = 0; right < nums.length; right++) {
        // 1. 加入 right 元素
        window.add(nums[right]);
        
        // 2. 窗口达到大小 k
        if (right - left + 1 == k) {
            // 更新答案
            result = max(result, window.getMax());  // 或其他操作
            
            // 移除 left 元素，滑动窗口
            window.remove(nums[left]);
            left++;
        }
    }
    
    return result;
}
```

## 六、注意事项

1. **什么时候收缩？**
   - 窗口大小超过限制
   - 满足某种条件
   - 需要找最优解

2. **使用什么数据结构？**
   - Set：判断是否存在重复
   - HashMap：记录频率/位置
   - 数组（字符问题）：`int[26]` 或 `int[128]`
   - 单调队列：需要最大值/最小值

3. **边界情况**：
   - 空字符串
   - 窗口大小为 0
   - 数组长度小于窗口大小

4. **时间复杂度分析**：
   - 每个元素最多入窗口一次、出窗口一次
   - 总操作数 2n，故 O(n)
