# 位运算技巧

## 一、常用位运算操作

### 基础操作

| 操作 | 符号 | 示例 | 说明 |
|------|------|------|------|
| 与 | `&` | `1010 & 1100 = 1000` | 全1为1 |
| 或 | `\|` | `1010 \| 1100 = 1110` | 有1为1 |
| 异或 | `^` | `1010 ^ 1100 = 0110` | 不同为1 |
| 取反 | `~` | `~1010 = 0101` | 按位取反 |
| 左移 | `<<` | `1010 << 1 = 10100` | 乘2 |
| 右移 | `>>` | `1010 >> 1 = 0101` | 除2（向下取整）|
| 无符号右移 | `>>>` | 负数高位补0 | |

## 二、Brian Kernighan 算法

### 核心操作：清除最低位的 1

```java
/**
 * n & (n-1) 的本质：
 * 将 n 二进制表示中最右边的 1 变为 0
 */
public int countBits(int n) {
    int count = 0;
    while (n != 0) {
        n = n & (n - 1);  // 清除最低位的1
        count++;
    }
    return count;
}
```

### 数学推导

**定理**：`n & (n-1)` 将 n 二进制表示中最右边的 1 变为 0

**证明**：
设 n 的二进制为 `...1000`（最低位的1后面全是0）

```
n     = ...1000
n-1   = ...0111
n&(n-1) = ...0000
```

结论：`n & (n-1)` 消除了最低位的 1。

## 三、应用实例

### 1. LeetCode 338. 比特位计数

```java
/**
 * 方法一：Brian Kernighan 算法
 */
public int[] countBits(int n) {
    int[] result = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        result[i] = result[i & (i - 1)] + 1;
    }
    return result;
}

/**
 * 方法二：最低有效位
 * i & 1 得到最低位
 * i >> 1 得到除最低位外的部分
 */
public int[] countBits2(int n) {
    int[] result = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        result[i] = result[i >> 1] + (i & 1);
    }
    return result;
}

/**
 * 方法三：最低设置位
 * i & (-i) 得到最低位的1
 */
public int[] countBits3(int n) {
    int[] result = new int[n + 1];
    for (int i = 1; i <= n; i++) {
        result[i] = result[i - (i & -i)] + 1;
    }
    return result;
}
```

### 2. 判断是否为 2 的幂

```java
/**
 * n > 0 && (n & (n-1)) == 0
 * 
 * 2的幂：1000, 10000, 100000...
 * 只有1个1
 */
public boolean isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

### 3. 判断是否为 4 的幂

```java
/**
 * 4的幂的特点：
 * 1. 只有1个1（在奇数位：1, 3, 5, 7...）
 * 2. & 0x55555555（01010101...）不为0
 */
public boolean isPowerOfFour(int n) {
    return n > 0 && (n & (n - 1)) == 0 && (n & 0x55555555) != 0;
}
```

### 4. 找出唯一出现一次的数

```java
/**
 * LeetCode 136. 只出现一次的数字
 * 其他数字都出现两次
 */
public int singleNumber(int[] nums) {
    int result = 0;
    for (int num : nums) {
        result ^= num;  // 异或
    }
    return result;
}
```

### 5. 交换两个数（不使用临时变量）

```java
public void swap(int[] arr, int i, int j) {
    arr[i] = arr[i] ^ arr[j];
    arr[j] = arr[i] ^ arr[j];  // arr[i] ^ arr[j] ^ arr[j] = arr[i]
    arr[i] = arr[i] ^ arr[j];  // arr[i] ^ arr[j] ^ arr[i] = arr[j]
}
```

### 6. 找出缺失的数字

```java
/**
 * LeetCode 268. 丢失的数字
 * 0到n中缺失一个数字
 */
public int missingNumber(int[] nums) {
    int result = nums.length;
    for (int i = 0; i < nums.length; i++) {
        result ^= i ^ nums[i];
    }
    return result;
}
```

## 四、掩码技巧

### 常用掩码

```java
// 全部为1
int ALL_ONE = ~0;

// 最低位的1
int LOWEST_ONE = n & -n;

// 清除最低位的1
int CLEAR_LOWEST = n & (n - 1);

// 获取第i位（从0开始）
int getBit = (n >> i) & 1;

// 设置第i位为1
int setOne = n | (1 << i);

// 设置第i位为0
int setZero = n & ~(1 << i);

// 切换第i位
int toggle = n ^ (1 << i);
```

### 统计二进制中1的个数（库函数）

```java
// Java
Integer.bitCount(n);

// C/C++
__builtin_popcount(n);
```

## 五、注意事项

1. **优先级问题**：
   - 位运算优先级较低
   - 建议加括号：`a & (b | c)`

2. **负数右移**：
   - `>>` 保持符号位（算术右移）
   - `>>>` 不保持符号位（逻辑右移）

3. **溢出问题**：
   - 左移可能溢出
   - 使用 `long` 类型更安全
