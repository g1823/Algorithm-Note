# 哈希表应用

## 一、作用与适用场景

### 核心作用
哈希表（Hash Table）提供 **O(1)** 平均时间复杂度的查找、插入和删除操作。

### 解决的问题
- 快速判断元素是否存在
- 统计元素出现频率
- 去重
- 映射关系（键值对）
- 前缀和 + 哈希表（如 "和为 K 的子数组"）

## 二、基础应用

### 1. 两数之和（最经典）

```java
/**
 * LeetCode 1. 两数之和
 */
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    
    throw new IllegalArgumentException("No two sum solution");
}
```

### 2. 字符出现的频率

```java
/**
 * 统计字符出现频率
 */
public Map<Character, Integer> countFrequency(String s) {
    Map<Character, Integer> freq = new HashMap<>();
    for (char c : s.toCharArray()) {
        freq.put(c, freq.getOrDefault(c, 0) + 1);
    }
    return freq;
}
```

### 3. 字母异位词分组

```java
/**
 * LeetCode 49. 字母异位词分组
 */
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    
    for (String str : strs) {
        // 排序作为 key
        char[] chars = str.toCharArray();
        Arrays.sort(chars);
        String key = new String(chars);
        
        groups.computeIfAbsent(key, k -> new ArrayList<>()).add(str);
    }
    
    return new ArrayList<>(groups.values());
}

/**
 * 使用字符计数作为 key（更高效）
 */
public List<List<String>> groupAnagrams2(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    int[] count = new int[26];
    
    for (String str : strs) {
        Arrays.fill(count, 0);
        for (char c : str.toCharArray()) {
            count[c - 'a']++;
        }
        
        StringBuilder key = new StringBuilder();
        for (int i = 0; i < 26; i++) {
            key.append('#').append(count[i]);
        }
        
        groups.computeIfAbsent(key.toString(), k -> new ArrayList<>()).add(str);
    }
    
    return new ArrayList<>(groups.values());
}
```

## 三、高级应用

### 1. 前缀和 + 哈希表

```java
/**
 * LeetCode 560. 和为 K 的子数组
 */
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);  // 前缀和为0出现1次
    
    int sum = 0;
    int result = 0;
    
    for (int num : nums) {
        sum += num;
        // 找有多少个前缀和等于 sum - k
        result += prefixCount.getOrDefault(sum - k, 0);
        // 更新当前前缀和的数量
        prefixCount.put(sum, prefixCount.getOrDefault(sum, 0) + 1);
    }
    
    return result;
}
```

### 2. 同余定理 + 哈希表

```java
/**
 * LeetCode 523. 连续的子数组和
 * 问题：判断是否存在长度至少为2的连续子数组，其和是k的倍数
 */
public boolean checkSubarraySum(int[] nums, int k) {
    Map<Integer, Integer> remainderIndex = new HashMap<>();
    remainderIndex.put(0, -1);  // 前缀和0在-1位置
    
    int sum = 0;
    for (int i = 0; i < nums.length; i++) {
        sum += nums[i];
        int remainder = k == 0 ? sum : sum % k;
        
        if (remainderIndex.containsKey(remainder)) {
            if (i - remainderIndex.get(remainder) > 1) {
                return true;
            }
        } else {
            remainderIndex.put(remainder, i);
        }
    }
    
    return false;
}
```

### 3. 链表随机访问 + 哈希表

```java
/**
 * LeetCode 146. LRU 缓存
 */
class LRUCache {
    private int capacity;
    private Map<Integer, Node> cache;
    private DoubleList doublyList;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.cache = new HashMap<>();
        this.doublyList = new DoubleList();
    }

    public int get(int key) {
        if (!cache.containsKey(key)) return -1;
        Node node = cache.get(key);
        doublyList.remove(node);
        doublyList.addFirst(node);
        return node.value;
    }

    public void put(int key, int value) {
        if (cache.containsKey(key)) {
            Node node = cache.get(key);
            node.value = value;
            doublyList.remove(node);
            doublyList.addFirst(node);
        } else {
            if (cache.size() == capacity) {
                Node last = doublyList.removeLast();
                cache.remove(last.key);
            }
            Node newNode = new Node(key, value);
            cache.put(key, newNode);
            doublyList.addFirst(newNode);
        }
    }
}
```

### 4. 图的邻接表表示

```java
/**
 * 使用哈希表表示图的邻接表
 */
class Graph {
    private Map<Integer, Set<Integer>> adj = new HashMap<>();
    
    public void addEdge(int u, int v) {
        adj.computeIfAbsent(u, k -> new HashSet<>()).add(v);
        adj.computeIfAbsent(v, k -> new HashSet<>()).add(u);
    }
    
    public Set<Integer> getNeighbors(int u) {
        return adj.getOrDefault(u, Collections.emptySet());
    }
}
```

## 四、注意事项

1. **容量和负载因子**：
   - 默认初始容量 16，负载因子 0.75
   - 可根据数据量调整：`new HashMap<>(expectedSize * 2)`

2. **自定义对象作为 key**：
   - 必须重写 `hashCode()` 和 `equals()`

3. **并发问题**：
   - HashMap 不是线程安全的
   - 多线程使用 `ConcurrentHashMap`

4. **遍历顺序**：
   - HashMap 不保证顺序
   - 需要顺序使用 `LinkedHashMap`
   - 需要排序使用 `TreeMap`
