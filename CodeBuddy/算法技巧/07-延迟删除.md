# 延迟删除

## 一、作用与适用场景

### 核心作用
延迟删除（Lazy Deletion）是一种**不立即删除**数据，而是记录待删除状态，在后续操作中**惰性处理**的技巧。

### 解决的问题
- 堆中删除任意元素（传统堆不支持 O(1) 删除任意元素）
- 滑动窗口中移除不在窗口内的元素
- 缓存淘汰策略（如 LFU）

---

## 二、基本思想

### 传统堆的问题
```java
PriorityQueue<Integer> heap = new PriorityQueue<>();
heap.add(1);
heap.add(2);
heap.add(3);
// 想删除元素 2？PriorityQueue 没有 remove(Object) 的高效实现！
```

### 延迟删除的解决方案
```
不使用立即删除，而是：
1. 用 HashMap 记录每个元素的"待删除计数"
2. 当弹出元素时，先检查是否应该被删除
3. 如果是，就跳过（惰性）
```

## 三、代码实现

### LeetCode 480. 滑动窗口中位数

```java
/**
 * 滑动窗口中位数
 * 使用双堆 + 延迟删除
 */
class MedianSlidingWindow {
    private PriorityQueue<Long> maxHeap;  // 大顶堆（较小的一半）
    private PriorityQueue<Long> minHeap;  // 小顶堆（较大的一半）
    private Map<Long, Integer> delayed;  // 延迟删除计数
    private int maxSize;  // 最大堆元素数量
    private int minSize;  // 最小堆元素数量

    public MedianSlidingWindow() {
        maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
        minHeap = new PriorityQueue<>();
        delayed = new HashMap<>();
    }

    public double[] medianSlidingWindow(int[] nums, int k) {
        double[] result = new double[nums.length - k + 1];
        
        for (int i = 0; i < nums.length; i++) {
            // 1. 添加新元素
            addNum((long) nums[i]);
            
            // 2. 移除窗口外的元素（延迟删除）
            if (i >= k) {
                remove(nums[i - k]);
            }
            
            // 3. 记录答案
            if (i >= k - 1) {
                result[i - k + 1] = findMedian();
            }
        }
        
        return result;
    }

    private void addNum(long num) {
        if (maxHeap.isEmpty() || num <= maxHeap.peek()) {
            maxHeap.offer(num);
            maxSize++;
        } else {
            minHeap.offer(num);
            minSize++;
        }
        balance();
    }

    private void remove(long num) {
        delayed.put(num, delayed.getOrDefault(num, 0) + 1);
        
        if (num <= maxHeap.peek()) {
            maxSize--;
            if (num == maxHeap.peek()) {
                prune(maxHeap);
            }
        } else {
            minSize--;
            if (num == minHeap.peek()) {
                prune(minHeap);
            }
        }
        
        balance();
    }

    private void prune(PriorityQueue<Long> heap) {
        while (!heap.isEmpty()) {
            Long num = heap.peek();
            if (delayed.containsKey(num) && delayed.get(num) > 0) {
                heap.poll();
                delayed.put(num, delayed.get(num) - 1);
            } else {
                break;
            }
        }
    }

    private void balance() {
        if (maxSize > minSize + 1) {
            minHeap.offer(maxHeap.poll());
            maxSize--;
            minSize++;
            prune(maxHeap);
        } else if (maxSize < minSize) {
            maxHeap.offer(minHeap.poll());
            maxSize++;
            minSize--;
            prune(minHeap);
        }
    }

    private double findMedian() {
        if (maxSize > minSize) {
            return maxHeap.peek().doubleValue();
        } else {
            return (maxHeap.peek() + minHeap.peek()) / 2.0;
        }
    }
}
```

### 简化版：堆中的延迟删除

```java
/**
 * 延迟删除的基本模式
 */
class LazyDeleteHeap {
    private PriorityQueue<Integer> heap;
    private Map<Integer, Integer> delayed;

    public LazyDeleteHeap() {
        heap = new PriorityQueue<>();
        delayed = new HashMap<>();
    }

    public void add(int num) {
        heap.offer(num);
    }

    public void lazyRemove(int num) {
        delayed.put(num, delayed.getOrDefault(num, 0) + 1);
    }

    public Integer poll() {
        prune();
        return heap.poll();
    }

    public Integer peek() {
        prune();
        return heap.peek();
    }

    private void prune() {
        while (!heap.isEmpty()) {
            Integer top = heap.peek();
            Integer count = delayed.get(top);
            if (count != null && count > 0) {
                heap.poll();
                delayed.put(top, count - 1);
            } else {
                break;
            }
        }
    }
}
```

## 五、注意事项

1. **删除计数**：
   - 相同元素可能被删除多次
   - 使用 `HashMap<Integer, Integer>` 记录次数

2. **清理时机**：
   - 每次访问堆顶时检查并清理
   - 或者在平衡操作时清理

3. **内存泄漏**：
   - 如果某元素长期不出现在堆顶，其延迟删除计数不会清理
   - 需要在适当时机（如平衡操作时）清理
