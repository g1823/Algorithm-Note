# 双指针技巧

## 一、作用与适用场景

### 核心作用
双指针是一种通过**两个指针协同移动**来遍历数组/链表的技巧，可以将 O(n²) 的暴力搜索优化到 O(n)。

### 解决的问题
- 两数之和（有序数组）
- 链表中倒数第 k 个节点
- 链表中环的入口
- 回文链表判断
- 合并两个有序数组/链表
- 接雨水问题

---

## 二、基本类型

### 1. 对撞指针（左右指针）
两个指针从两端向中间移动：
```
[left]                    [right]
  ↓                        ↓
  a[l] ... ... ... ... a[r]
  
常用于：
- 有序数组的两数之和
- 回文判断
- 接雨水
```

### 2. 快慢指针
两个指针以不同速度移动：
```
[slow]  →  [fast]
  ↓
  步长 1    步长 2
  
常用于：
- 链表环检测
- 链表中间节点
- 链表倒数第 k 个节点
```

### 3. 滑动窗口
两个指针维护一个区间：
```
[left]────────────[right]
  ↓              ↓
  [  窗口区域  ]
  
常用于：
- 子数组问题
- 子串问题
```

## 三、代码实现

### 1. 对撞指针：两数之和 II

```java
/**
 * LeetCode 167. 两数之和 II - 输入有序数组
 * 问题：找到两个数使它们相加等于目标值
 */
public int[] twoSum(int[] numbers, int target) {
    int left = 0;
    int right = numbers.length - 1;
    
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        
        if (sum == target) {
            return new int[]{left + 1, right + 1};  // 1-indexed
        } else if (sum < target) {
            left++;  // 需要更大的和
        } else {
            right--;  // 需要更小的和
        }
    }
    
    return new int[]{-1, -1};  // 无解
}
```

### 2. 快慢指针：链表中间节点

/**
 * LeetCode 876. 链表的中间结点

public ListNode middleNode(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;      // 慢指针走一步
        fast = fast.next.next;  // 快指针走两步
    }
    
    return slow;  // 中间节点
}

### 3. 快慢指针：环形链表检测

```java
/**
 * LeetCode 141. 环形链表
 */
public boolean hasCycle(ListNode head) {
    if (head == null || head.next == null) {
        return false;
    }
    
    ListNode slow = head;
    ListNode fast = head;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        
        if (slow == fast) {
            return true;  // 相遇，说明有环
        }
    }
    
    return false;  // 无环
}

/**
 * LeetCode 142. 环形链表 II
 * 返回环形链表的入口节点
 */
public ListNode detectCycle(ListNode head) {
    if (head == null || head.next == null) {
        return null;
    }
    
    // 1. 检测是否有环
    ListNode slow = head;
    ListNode fast = head;
    boolean hasCycle = false;
    
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            hasCycle = true;
            break;
        }
    }
    
    if (!hasCycle) return null;
    
    // 2. 找环入口
    // 数学证明：从 head 到环入口的距离 = 从相遇点到环入口的距离
    slow = head;
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    
    return slow;
}
```

### 4. 快慢指针：删除链表的倒数第 N 个节点

```java
/**
 * LeetCode 19. 删除链表的倒数第 N 个结点
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    
    ListNode slow = dummy;
    ListNode fast = dummy;
    
    // 先让 fast 走 n+1 步
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }
    
    // 同时移动，直到 fast 到达末尾
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }
    
    // slow.next 就是要删除的节点
    slow.next = slow.next.next;
    
    return dummy.next;
}
```

### 5. 对撞指针：三数之和

```java
/**
 * LeetCode 15. 三数之和
 */
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    Arrays.sort(nums);
    
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
        
        int target = -nums[i];
        int left = i + 1;
        int right = nums.length - 1;
        
        while (left < right) {
            int sum = nums[left] + nums[right];
            
            if (sum == target) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                
                // 去重
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                
                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    
    return result;
}
```

### 6. 对撞指针：接雨水（双指针优化）

```java
/**
 * LeetCode 42. 接雨水 - 双指针法
 */
public int trap(int[] height) {
    int left = 0, right = height.length - 1;
    int leftMax = 0, rightMax = 0;
    int result = 0;
    
    while (left < right) {
        if (height[left] < height[right]) {
            if (height[left] < leftMax) {
                result += leftMax - height[left];
            } else {
                leftMax = height[left];
            }
            left++;
        } else {
            if (height[right] < rightMax) {
                result += rightMax - height[right];
            } else {
                rightMax = height[right];
            }
            right--;
        }
    }
    
    return result;
}
```

## 六、数学证明：环形链表入口

**定理**：从 head 到环入口的距离 = 从相遇点到环入口的距离

**证明**：
1. 设 head 到环入口的距离为 F
2. 环入口到相遇点的距离为 a
3. 环的长度为 C
4. 相遇时：
   - 慢指针走了 F + a
   - 快指针走了 F + a + kC（k >= 1，因为可能多走几圈）
   - 快指针速度是慢指针的 2 倍：
     ```
     2(F + a) = F + a + kC
     F + a = kC
     F = kC - a = (k-1)C + (C - a)
     ```
   - C - a 是相遇点沿环反向到环入口的距离
   - 因此：从 head 走 F 步 = 从相遇点走 (C-a) 步 = 从相遇点继续走到环入口

**结论**：当快慢指针相遇后，将 slow 放回 head，然后同速前进，再次相遇点即为环入口。

## 七、注意事项

1. **边界条件**：
   - 空链表
   - 单节点链表
   - 无环链表
   - 特殊情况（k > 链表长度）

2. **去重**：
   - 排序后相邻元素去重
   - 对于重复结果要谨慎处理

3. **指针移动**：
   - 先移动还是后移动
   - 移动步长（1 步还是 2 步）

4. **空间复杂度**：
   - O(1) 空间通常是双指针的优势
