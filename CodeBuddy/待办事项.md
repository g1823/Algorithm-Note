### 4. 在线推导 → 离线判定转换

**问题描述**：
固定 k 的情况下，将「在线推导」（根据当前状态动态决策）转换为「离线判定」（预先判断）的方法。

**相关题目**：
- LeetCode 1818. 绝对差值和
- LeetCode 1898. 可移除的最大数目
- LeetCode 鸡舍问题

**核心思想**：
```
在线推导（动态选择）：
for each step:
    根据当前状态做最优选择

离线判定（固定选择）：
二分答案，判定是否可行
```

### 1. 使用 Deque 替代 Stack

**问题**：
Stack 类是同步的，基于 Vector，性能较差。

**建议**：
```java
// 不推荐
Stack<Integer> stack = new Stack<>();

// 推荐
Deque<Integer> deque = new LinkedList<>();
// 作为栈使用
deque.push(x);
deque.pop();
deque.peek();
```
