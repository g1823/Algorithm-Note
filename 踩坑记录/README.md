# 踩坑记录

> 记录具体踩过的坑：错误现象、定位过程、最终方案、可复用教训。
>
> 与三维度的区别：`算法思想` / `经典解法` / `小技巧` 是可复用的方法论，这里只写「具体问题 + 具体解决」。

## 命名

`YYYY-MM-DD-简短描述.md`，例如 `2026-11-08-线段树下标从0开始.md`

## 模板

```markdown
# 现象

出了什么问题，报错信息或错误结果。

# 排查

怎么定位的：缩小范围、打的日志、对比的样例。

# 解决

最终改了什么，为什么这样改。

# 教训

下次怎么避免，属于哪类通用陷阱（边界 / 溢出 / 下标 / 类型 / 复杂度）。
```

## 索引

新建后不必立刻登记，等条目多了再在 `汇总/算法分类总览.md` 增加入口。
