# 位运算表示集合

## 原理

当元素范围较小时（如 1~n，n ≤ 50），可以用一个 **整数的二进制位**表示集合：第 i 位为 1 表示元素 i 存在。

| 集合操作 | 位运算等价 | Java 示例 |
|----------|-----------|-----------|
| 添加元素 x | `bitset \|= (1L << x)` | `p \|= 1L << A[i]` |
| 交集 | `bitset1 & bitset2` | `p & q` |
| 并集 | `bitset1 \| bitset2` | `p \| q` |
| 差集 | `bitset1 & ~bitset2` | `p & ~q` |
| 集合大小 | `Long.bitCount(bitset)` | `Long.bitCount(p & q)` |
| 判断元素是否存在 | `(bitset >> x) & 1` | `(p >> x) & 1` |

**前提条件**：元素范围不能超过整数位数（int 可表示 0~31，long 可表示 0~63）。

## 应用：2657. 找到两个数组的前缀公共数组

**题目**：给定两个 1~n 的排列 A 和 B，求每个前缀 `A[0..i]` 和 `B[0..i]` 的公共元素个数。

**位运算解法**：用两个 `long` 分别表示 A 和 B 已出现元素的集合，交集 `p & q` 的 bitCount 即为公共元素个数。

```java
public int[] findThePrefixCommonArray2(int[] A, int[] B) {
    long p = 0, q = 0;
    for (int i = 0; i < A.length; i++) {
        p |= 1L << A[i];           // A 前缀集合加入 A[i]
        q |= 1L << B[i];           // B 前缀集合加入 B[i]
        A[i] = Long.bitCount(p & q); // 交集大小 = 公共元素个数
    }
    return A;
}
```

时间复杂度 O(n)，空间复杂度 O(1)。4 行代码替代哈希表的几十行。

## 适用场景

- 元素范围 ≤ 63（long）或 ≤ 31（int）
- 只需记录元素"是否存在"（不需要频次）
- 需要频繁做集合交/并/差运算
