# 数组表示完全二叉树（堆式存储）

## 问题

线段树、堆排序等需要一棵**完全二叉树**，但用指针或内部类 Node 表示时：
- 每个节点额外存储 left/right 引用，内存开销大
- 频繁 new 对象，GC 压力大
- 代码冗余

## 技巧

利用**完全二叉树父子节点的下标关系**，用一维数组隐式表示树结构：

| 关系 | 公式 |
|------|------|
| 根节点下标 | 1（数组索引从 1 开始） |
| 节点 i 的左子节点 | `2 * i` |
| 节点 i 的右子节点 | `2 * i + 1` |
| 节点 i 的父节点 | `i / 2` |

### 证明

完全二叉树按层序编号：
- 第 k 层有 2^(k-1) 个节点（从第 1 层开始）
- 前 k 层共有 2^k - 1 个节点
- 节点 i 在第 ceil(log2(i+1)) 层
- 左子节点编号 = 2*i：因为节点 i 之前的节点数 = i-1，其子节点之前的节点数 = 2*(i-1)，所以左子节点编号 = 2*(i-1) + 1 = 2*i - 1（0-indexed）或 2*i（1-indexed）

### 数组大小

对于 n 个叶子的线段树：
- 树的高度 h = ceil(log2(n)) + 1
- 完全二叉树最多有 2^h - 1 个节点
- 代入得 < 4n，因此数组大小取 **4n** 足够安全

## 应用

| 场景 | 说明 |
|------|------|
| **线段树** | `tree[4*n]` 存储区间聚合值，`update/query` 时通过 `node*2` / `node*2+1` 访问子节点 |
| **堆排序** | `heap[n+1]` 存储堆元素，父子关系通过下标计算，无需真实树结构 |
| **二叉堆（优先队列）** | 完全二叉树 + 数组表示，`siftUp` / `siftDown` 操作通过下标移动 |
