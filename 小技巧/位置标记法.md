# 位置标记法（首/末次出现位置）

## 原理

当约束条件是"某类元素的**所有**出现都必须满足某种顺序关系"时，可以将该约束**压缩为极值位置的比较**。

| 原约束 | 等价转换 |
|--------|----------|
| 所有小写字母在其大写字母之前 | 最后一个小写的位置 < 第一个大写的位置 |
| 所有 X 在 Y 之前 | X 的最后出现 < Y 的第一次出现 |
| 所有 X 在 Y 之后 | X 的第一次出现 > Y 的最后出现 |

**关键**：不需要验证每一个个体，只需要比较两个极值位置即可。

## 应用：3121. 统计特殊字母的数量 II

**题目**：统计 word 中同时满足以下条件的字母个数：
1. 大小写都在 word 中出现
2. 该字母的**所有小写**都在其**大写**之前出现

**转换**：
- 小写字母 → 记录 `low[i]` = 字母 i 的**最后出现位置**
- 大写字母 → 记录 `up[i]` = 字母 i 的**第一次出现位置**
- 条件等价于：`up[i] > low[i]`

```java
public int numberOfSpecialChars(String word) {
    int[] up = new int[26], low = new int[26];
    Arrays.fill(up, -1);
    Arrays.fill(low, -1);
    for (int i = 0; i < word.length(); i++) {
        char c = word.charAt(i);
        if (c >= 'a' && c <= 'z') {
            low[c - 'a'] = i;           // 持续更新 = 保留最后位置
        } else {
            if (up[c - 'A'] == -1) {
                up[c - 'A'] = i;        // 只设一次 = 保留首次位置
            }
        }
    }
    int count = 0;
    for (int i = 0; i < 26; i++) {
        if (up[i] != -1 && low[i] != -1 && up[i] > low[i]) {
            count++;
        }
    }
    return count;
}
```
