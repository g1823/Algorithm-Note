# 归并排序求逆序对（及同类统计问题）

## 概述

在归并排序的 merge 过程中，自然可以统计**逆序对**或**右侧更小元素个数**等信息，而不增加额外的时间复杂度（O(n log n)）。

## 核心思想

归并排序将数组不断二分，在 merge 阶段合并两个有序子数组。当**右侧元素先于左侧元素进入结果数组**时，意味着这个右侧元素比左侧**所有未处理**的元素都小 —— 每发生一次，就产生一批逆序对。

## 通用模板

```java
// 逆序对计数
private long count = 0;

private void merge(int[] nums, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = 0, l = left, r = mid + 1;
    while (l <= mid && r <= right) {
        if (nums[l] <= nums[r]) {
            temp[i++] = nums[l++];
        } else {
            // 右侧元素先进入 → 与左侧所有剩余元素构成逆序对
            count += (mid - l + 1);
            temp[i++] = nums[r++];
        }
    }
    while (l <= mid) temp[i++] = nums[l++];
    while (r <= right) temp[i++] = nums[r++];
    System.arraycopy(temp, 0, nums, left, temp.length);
}
```

## 关键变量详解

| 变量 | 含义 | 技术细节 |
|------|------|----------|
| `count` | 逆序对总数 | 在右侧先入时累加 `mid - l + 1`（左侧剩余元素数） |
| `rightCount` | 已进入的右侧元素数 | 在左侧入时累加，用于统计"每个元素右侧更小值个数" |
| `index[]` | 下标数组 | 需要保留原始位置时使用（排序下标而非值） |

## 三种常见变体

### 变体一：统计逆序对总数（最基础）

右侧元素 `nums[r]` 小于左侧元素 `nums[l]` 时，左侧从 l 到 mid 的所有元素都与 `nums[r]` 构成逆序对。

```java
// 右侧先入，说明 nums[r] < nums[l]
// 那么 nums[l..mid] 都比 nums[r] 大
count += mid - l + 1;
temp[i++] = nums[r++];
```

### 变体二：统计每个元素右侧比它小的个数（LeetCode 315）

需要排序**下标数组**（而非原数组），因为排序后元素位置改变，需要通过下标找回原始位置更新答案。

```java
int[] result = new int[n];
int[] index = new int[n];  // index[i] = i

// merge 时比较 nums[index[l]] 和 nums[index[r]]
if (nums[index[l]] <= nums[index[r]]) {
    result[index[l]] += rightCount;  // 当前左侧元素遇到 rightCount 个更小右侧元素
    temp[i++] = index[l++];
} else {
    rightCount++;
    temp[i++] = index[r++];
}
```

### 变体三：统计翻转对（LeetCode 493）

不是比较两个元素，而是比较 `nums[l] > 2 * nums[r]`，统计满足条件的对数。

```java
// 在 merge 前先统计（因为 merge 过程中会破坏大小关系）
int r = mid + 1;
for (int l = left; l <= mid; l++) {
    while (r <= right && nums[l] > 2L * nums[r]) r++;
    count += r - (mid + 1);
}
// 然后正常 merge
merge(nums, left, mid, right);
```

### 变体四：统计区间和的个数（LeetCode 327）

对**前缀和数组**进行归并排序，统计跨半数对中满足 `lower ≤ P[j] - P[i] ≤ upper` 的个数。

与前三者的区别：
- 不是"右侧比左侧小"的逆序关系，而是"值落在某个区间内"的范围统计
- 在 merge 前用**双指针**在左半滑动，而非在 merge 过程中计数
- 不需要记录每个元素的结果，只需累加总数

```java
// 双指针计数跨半数对
int i1 = left, i2 = left;
for (int j = mid + 1; j <= right; j++) {
    while (i1 <= mid && P[i1] < P[j] - upper) i1++;
    while (i2 <= mid && P[i2] <= P[j] - lower) i2++;
    count += i2 - i1;
}
// 然后正常 merge
merge(P, left, mid, right);
```

**关键技巧**：
- 排序的是前缀和数组（不是原数组），因为前缀和的差值代表子数组和
- 双指针在左半单调移动，总的计数耗时 O(n)
- 排序后左右半的大小关系和原始下标的区间绑定不变

## 同类问题

| 题目 | 类型 | 区别 |
|------|------|------|
| 剑指 51. 数组中的逆序对 | 逆序对总数 | 基础模板，直接统计 |
| 315. 计算右侧小于当前元素的个数 | 每个元素的统计 | 需下标数组 + result |
| 493. 翻转对 | 条件逆序对（2倍关系） | 先统计再 merge |
| 327. 区间和的个数 | 前缀和 + 归并 | 对前缀和数组归并，统计落在范围内的对数 |

## 注意事项

- **稳定性**：必须用 `<=` 而非 `<`，相等时让左元素先入，避免错误统计
- **下标排序**：当需要统计每个元素而非总数时，必须排序下标数组
- **数据类型**：逆序对数量可能超出 int 范围，用 long 存储
