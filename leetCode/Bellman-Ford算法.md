## 算法能做什么

Bellman-Ford 算法用于解决**单源最短路径问题**，特点包括：

-  ✅ 可处理带负权边的图 
-  ✅ 可检测负权环 
-  ❌ 不可处理存在负权环的最短路径（路径长度可能无穷小） 
-  适合应用场景： 
  -  普通单源最短路径求解 
  -  限制最多 k 条边的路径问题（如 K 站中转航班最便宜问题） 

------

## 核心思想

Bellman-Ford 的核心思想可以概括为：

> **通过多轮“边松弛（Relaxation）”，逐步逼近最短路径，直至收敛**

每条边 `(u → v)` 的松弛操作： 

```
dist[v] = min(dist[v], dist[u] + w(u,v))
```

意义：尝试用“经过 u 再到 v”的路径更新 v 的最短距离 

核心策略：每轮遍历**所有边**，保证所有可能路径都能被传播 

------

## 算法流程

```
1. 初始化：
    dist[src] = 0
    dist[其他节点] = ∞

2. 重复 n-1 轮：
    for 每一条边 (u → v)：
        if dist[u] + w(u,v) < dist[v]:
            dist[v] = dist[u] + w(u,v)

3. （可选）检测负权环：
    if 第 n 轮还能松弛：
        存在负权环
```

说明：

-  n = 节点数 
-  每轮遍历所有边，逐步更新 dist 
-  每轮保证到达当前节点的最短路径最多使用 k 条边（对应当前轮数 k） 

------

## 证明与分析

### 每一轮的实际含义

> 第 k 轮结束后，`dist[x]` 表示**从 src 出发，最多使用 k 条边到达 x 的最短路径**

证明（归纳法）：

1.  **初始化**：0 轮时，`dist[src]=0`，表示用 0 条边到达源点，其他节点为 ∞ 
2.  **归纳假设**：第 k-1 轮结束后，`dist[x]` 表示从 src 出发，至多使用 k-1 条边到达 x 的最短路径 
3. 第 k 轮操作：
   - 遍历每条边 (u → v)
   -  更新：`dist[v] = min(dist[v], dist[u] + w(u,v))` 
   -  含义：用“至多 k-1 条边到达 u”的路径，再接一条边到 v → 至多 k 条边 
4.  **归纳结论**：第 k 轮结束后成立 

------

### 顺序问题与松弛操作

-  疑问：如果边 c→b 本轮才更新 b，会不会影响顺序？ 
-  答案： 
  -  ❌ 当前轮不保证绝对正确 
  -  ✅ 下一轮会修正 
-  原因：Bellman-Ford 是**允许滞后修正**的算法 
-  每轮遍历所有边，无需保证顺序 

------

### n-1轮的原因

-  最短路径是**简单路径**，最多经过 n-1 条边 
-  因此 n-1 轮松弛足够覆盖所有最短路径 
-  第 n 轮用于检测负权环 

------

### 负环检测原理

-  再做第 n 轮松弛： 
  -  如果还能更新 dist[v] → 存在负权环 
-  理由： 
  -  简单路径最多 n-1 条边 
  -  第 n 条边只能来自环 
  -  松弛还能降低距离 → 说明环权为负 

------

## 限制 k 条边数类比动态规划

Bellman-Ford 可以类比为按**边数维度的动态规划**：

1.  定义状态： 

```
dp[k][v] = 从 src 出发，最多使用 k 条边到达 v 的最短路径
```

1.  状态转移方程： 

```
dp[k][v] = min(
    dp[k-1][v],           // 不使用第 k 条边
    dp[k-1][u] + w(u,v)   // 遍历所有边 u→v
)
```

1.  对应 Bellman-Ford： 

| 动态规划概念 | Bellman-Ford 对应                              |
| ------------ | ---------------------------------------------- |
| dp\[k][v]    | 第 k 轮结束的 dist[v]                          |
| 遍历所有边   | 每轮遍历所有边做松弛                           |
| 状态转移     | 松弛操作 `dist[v] = min(dist[v], dist[u] + w)` |

滚动优化： 

-  可以只用一个数组 dist[] 代替 dp[][] 
-  本质是允许当前轮使用上一轮或本轮更新的值 
-  优化后仍然正确 

 应用： 

-  可以严格限制最多 k 条边的最短路径问题（K站中转问题、航班问题） 



## 总结

-  Bellman-Ford 是**按边数维度逼近最短路径的算法** 
-  每轮松弛 = 更新所有节点最多使用 k 条边的最短路径 
-  核心优势： 
  -  可处理负权边 
  -  可检测负环 
  -  可扩展到限制 k 条边的问题（DP类比） 
-  算法理解层次： 
  1.  松弛操作 
  2.  每轮对应 k 条边 
  3.  n-1轮覆盖所有简单路径 
  4.  DP 类比理解，更容易拓展应用
