# 回溯法

## 基本思想

回溯法是一种系统地搜索问题解空间的算法，常用于解决组合优化和约束满足问题。核心是**利用深度优先搜索**逐步构建可能的解，同时进行**剪枝**操作排除无法满足约束或不产生最优解的分支，减少不必要计算。

## 与蛮力法的区别

- 蛮力法：穷举所有可能解，逐一验证
- 回溯法：DFS 逐步构建 + 提前剪枝，避免无效搜索；同时保存/恢复状态避免重复计算

## 一般步骤

1. **定义问题并构造状态空间树**：确定解空间结构（通常是树），树的每个节点表示一个状态
2. **编写递归函数**，包含以下部分：
   - **递归边界**：何时到达叶节点（找到解或无法继续）
   - **选择和判断（剪枝）**：在当前状态下尝试每种选择，判断是否满足约束
   - **递归调用**：满足条件时递归进入下一个状态
   - **回溯**：不满足条件或递归返回后，撤销当前选择，回溯到上一步

## 经典实例一：01 背包问题（回溯法）

01 背包问题同样可以用回溯法解决：每个物品只有放入/不放入两种状态，构成一棵二叉树。

**剪枝**：放入当前物品后总体积超出容量 → 直接剪枝
**回溯**：计算完一种情况后，回到上一步时保留之前的状态（当前体积和价值），避免蛮力法的重复计算

```java
public class ZeroOneBackpackBacktrack {
    private static int maxValue = 0;

    public static void execute(Item[] items, int maxVolume) {
        zeroOneBackpackBacktrack(items, maxVolume, 0, 0, 0);
    }

    public static void zeroOneBackpackBacktrack(Item[] items, int maxVolume,
            int index, int currentVolume, int currentValue) {
        if (currentVolume > maxVolume) return;              // 剪枝：超出容量
        maxValue = Math.max(currentValue, maxValue);        // 更新最优解
        if (index < items.length) {
            // 放入当前物品
            zeroOneBackpackBacktrack(items, maxVolume, index + 1,
                currentVolume + items[index].getVolume(), currentValue + items[index].getValue());
            // 不放入当前物品（回溯：状态自动恢复，因为参数传递是值传递）
            zeroOneBackpackBacktrack(items, maxVolume, index + 1, currentVolume, currentValue);
        }
    }
}
```

## 经典实例二：N 皇后问题

**问题**：根据国际象棋规则，皇后可以攻击同行、同列或同斜线上的棋子。给定 n 个皇后和 n×n 棋盘，寻找所有皇后无法相互攻击的摆放方案。

### 蛮力法

每行有 n 列，共 n 行，遍历所有情况需 n^n 次，加上验证皇后位置需额外遍历。复杂度极高。

### 回溯法

每一行仅允许放置一个皇后。逐行放入，放入前判断是否冲突，冲突则剪枝。

```java
public static void dfs(int[][] data, int row) {
    if (row == data.length) {           // 所有皇后放置完毕
        printResult(data, ++resultNum);
        return;
    }
    for (int col = 0; col < data.length; col++) {
        if (canPlace(data, row, col)) { // 剪枝：判断位置是否合法
            data[row][col] = 1;          // 放入皇后
            dfs(data, row + 1);         // 放入下一个皇后
            data[row][col] = 0;          // 回溯：取出当前皇后
        }
    }
}
```

### 优化：对角线快速判断

- 同一列：用长度为 n 的布尔数组 `existCol` 记录
- 主对角线（\\）：`row - col` 为恒定值，数组长度 2n-1
- 次对角线（/）：`row + col` 为恒定值，数组长度 2n-1

```java
public static boolean canPlace(int row, int col, int n,
        boolean[] existCol, boolean[] existLeftDiagonal, boolean[] existRightDiagonal) {
    return !(existCol[col] || existLeftDiagonal[row - col + n - 1] || existRightDiagonal[row + col]);
}
```
