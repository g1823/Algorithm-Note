# 分治法

## 基本思想

分治法，就是将一个大问题分成多个规模较小的子问题，分别解决各个子问题，最后合并子问题的解得到原问题的解。

## 求解过程

**1、划分（分）**：把规模为 n 的原问题划分为 k（通常 k=2）个规模较小的子问题，继续递归划分直到到达最小子问题（如元素只剩 1 个），一般使用递归。

**2、合并（治）**：从已知解的最小子问题开始，自底向上将子问题的解合并，构建原问题的解。**分治算法的效率很大程度上依赖合并的实现**。

## 判断是否为分治问题

1. **问题可以分解**：原问题可以分解成规模更小、类似的子问题，能以相同方式递归进行划分
2. **子问题是独立的**：子问题之间没有重叠，互不依赖，可以独立解决
3. **子问题的解可以合并**：原问题的解通过合并子问题的解得来

## 经典实例：归并排序

对于一个无序数组进行排序，满足分治三个要求：
1. 问题可以分解：递归地将数组划分为两个子数组
2. 子问题独立：每个子数组都可以独立排序
3. 子问题解可合并：两个有序子数组可以合并为一个有序数组

### 合并操作

两个子数组从下标 0 开始，依次比较，拿出较小的放入合并后数组。最后将剩余子数组的数据依次放入结果数组。

```java
public static int[] execute(int[] data, int left, int right) {
    if (left == right) {
        return new int[]{data[left]};       // 最小子问题：单个元素有序
    }
    int midIndex = (right - left) / 2 + left;
    int leftIndex = 0, rightIndex = 0, resultIndex = 0;
    int[] leftResult = execute(data, left, midIndex);       // 递归排序左半
    int[] rightResult = execute(data, midIndex + 1, right); // 递归排序右半
    int[] result = new int[right - left + 1];
    // 合并两个有序子数组
    while (leftIndex < leftResult.length && rightIndex < rightResult.length) {
        result[resultIndex++] = leftResult[leftIndex] <= rightResult[rightIndex]
            ? leftResult[leftIndex++] : rightResult[rightIndex++];
    }
    while (leftIndex < leftResult.length) result[resultIndex++] = leftResult[leftIndex++];
    while (rightIndex < rightResult.length) result[resultIndex++] = rightResult[rightIndex++];
    return result;
}
```

**时间复杂度**：O(n log n)，合并阶段每层比较 n 次，共 log n 层。

### 分治法在生活中的应用
- **做饭**：将做饭分解为蒸米饭、煮汤、烧菜，三部分完成后整合上桌
- **人口普查**：全国→省→市→区→乡镇→街道，层层分解汇总
