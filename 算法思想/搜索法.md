# 搜索法

## 基本思想

搜索法是在**状态空间**中寻找目标状态的算法思想，核心是系统地探索可能的状态，直到找到目标或确定目标不存在。

搜索法是回溯法和分支限界法的**基础框架**，添加约束判断（剪枝）后升级为回溯法，添加限界函数后升级为分支限界法。

## 深度优先搜索 (DFS)

一条路径走到底，无路可走时回溯到上一个分支点，尝试另一条路径。通常用**递归**或**栈**实现。

**特点**：
- 适合找到所有解或遍历全图
- 空间复杂度 O(h)，h 为深度
- 不保证找到最短路径

```java
// DFS 模板
void dfs(Node node, Set<Node> visited) {
    if (node == null || visited.contains(node)) return;
    visited.add(node);
    for (Node neighbor : node.neighbors) {
        dfs(neighbor, visited);
    }
}
```

## 广度优先搜索 (BFS)

从起始节点开始，逐层向外扩展。通常用**队列**实现。

**特点**：
- 保证找到最短路径（无权图）
- 空间复杂度 O(w)，w 为最大宽度
- 适合逐层遍历

```java
// BFS 模板
void bfs(Node start) {
    Queue<Node> queue = new LinkedList<>();
    Set<Node> visited = new HashSet<>();
    queue.offer(start);
    visited.add(start);
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        for (Node neighbor : node.neighbors) {
            if (!visited.contains(neighbor)) {
                visited.add(neighbor);
                queue.offer(neighbor);
            }
        }
    }
}
```

## DFS vs BFS

| 特性 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈（递归） | 队列 |
| 空间复杂度 | O(深度) | O(宽度) |
| 最短路径 | 不保证 | 保证（无权图） |
| 适用场景 | 树遍历、回溯、连通性 | 层序遍历、最短路径 |
| 经典应用 | N皇后、全排列、图遍历 | 岛屿问题、迷宫、单词接龙 |
