# 贪心法

## 基本思想

在问题的每个决策阶段，都选择当前看起来最优的选择，即贪心地做出局部最优的决策，以期获得全局最优解。

贪心法在解决问题的策略上"目光短浅"，只根据当前已有信息做出选择。一旦做出选择，不管将来有什么结果，这个选择都不会改变。

## 与动态规划对比

| 特性 | 贪心法 | 动态规划 |
|------|--------|----------|
| 决策方式 | 只看当前最优，不回头 | 综合考虑历史所有决策 |
| 最优子结构 | 需要 | 需要 |
| 效率 | 通常 O(n) | 通常 O(n²) |
| 正确性 | 需要证明贪心选择性质 | 自动保证（枚举所有情况） |

## 局限性

贪心法并非总是能得到全局最优解。

**反例**：硬币组合 [1, 20, 50]，总金额 60。贪心选 50+1×10=11 枚，但最优解是 20×3=3 枚。

如果硬币组合间有倍数关系（如人民币），贪心法就是正确的。

## 经典实例：最大子数组和

**问题**：给一个整数数组，找出具有最大和的连续子数组，返回其最大和。

**贪心策略**：如果当前子序列和小于 0，那么负数 + 任何数都会变小，所以应该舍弃当前已选择的子序列。只需考虑当前的最优解，不断向后遍历即可。

```java
public static int execute(int[] data) {
    int result = Integer.MIN_VALUE, thisMaxSub = 0;
    for (int datum : data) {
        thisMaxSub += datum;
        result = Math.max(thisMaxSub, result);
        thisMaxSub = Math.max(thisMaxSub, 0);  // 负数和直接舍弃
    }
    return result;
}
```

**时间复杂度**：O(n)

## 贪心子技巧：只保留极值

### 思想

当决策函数 `f(x)` 对变量 x **单调不减**（或单调不增）时，x 的极值对应的决策也是极值。因此只需要考虑极值，其余候选一定不会更优。

### 经典实例：3633. 最早完成时间 I

固定第二类项目后：`finish2 = max(finish1, start2) + duration2`

`max(x, start2)` 对 x **单调不减** → finish1 越小，finish2 越小 → 第一类项目只需保留最早结束时间。
