# 数学法

## 基本思想

数学法是利用**数学公式、定理和性质**直接求解问题的方法。不同于其他算法思想通过搜索或递推，数学法通常通过推导出**封闭形式的公式**或利用**数学性质**将问题转化为 O(1) 或 O(n) 的简单计算。

## 常见数学技巧

### 1. 位运算
利用二进制位的性质快速计算：
- `n & (n-1)`：消除最低位的 1（Brian Kernighan 算法）
- `n & (-n)`：获取最低位的 1
- 异或 `^`：相同为 0，不同为 1；可用于找出现奇数次的数字

### 2. 素数判定与筛法
- 试除判定：O(√n)
- 埃拉托斯特尼筛法：批量筛选素数 O(n log log n)

### 3. 最大公约数 / 最小公倍数
- 辗转相除法（欧几里得算法）：`gcd(a, b) = gcd(b, a % b)`
- `lcm(a, b) = a * b / gcd(a, b)`

### 4. 组合数学
- 排列：P(n, k) = n! / (n-k)!
- 组合：C(n, k) = n! / (k! * (n-k)!)
- 二项式定理、杨辉三角递推

### 5. 快速幂
用二分思想加速乘方运算：
```java
public double myPow(double x, int n) {
    long N = n;
    return N >= 0 ? quickMul(x, N) : 1.0 / quickMul(x, -N);
}
double quickMul(double x, long N) {
    double ans = 1.0;
    while (N > 0) {
        if ((N & 1) == 1) ans *= x;
        x *= x;
        N >>= 1;
    }
    return ans;
}
```

### 6. 数学归纳法与递推
- 斐波那契数列、杨辉三角等递推公式
- 利用归纳法证明算法正确性
