# 蛮力法（穷举法）

## 基本思想

蛮力法（穷举法、枚举法）是一种简单直接的问题求解方法，所依赖的基本技术就是**遍历**，采用一定策略依次处理待求解问题的所有元素。即**穷举所有可能的解**，逐一检查是否满足条件，直到找到符合条件的解为止。

蛮力法不利用问题的特殊性质或启发式信息，通过暴力的方式尝试所有可能。虽然效率通常较低，但对于小规模问题可能是一种简单有效的方案。

## 蛮力法的意义

1. **理论上万能**：可以解决计算领域中的各种问题
2. **小规模有效**：对于输入规模不大的问题，设计高效算法的代价可能反而更高
3. **辅助算法设计**：蛮力法可以作为启发帮助设计更高效算法，且可作为问题时间性能的**下界**

## 经典实例：选择排序

选择排序的蛮力法思路：每次从未排序部分找出最小值，放到已排序部分的末尾。

```java
public static void selectionSort(int[] data) {
    for (int i = 0; i < data.length - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < data.length; j++) {
            if (data[j] < data[minIndex]) minIndex = j;
        }
        int temp = data[i];
        data[i] = data[minIndex];
        data[minIndex] = temp;
    }
}
```

## 与回溯法的关系

- 蛮力法是回溯法的极端情况（无剪枝）
- 回溯法 = 蛮力法的搜索框架 + 剪枝优化
