# 减治法

## 基本思想

减治法同样把大问题划分为若干个子问题，但与分治法不同，它**并不求解所有的子问题**——因为原问题的解就在其中一个子问题当中，所以只求解其中一个子问题。

与分治法的区别就在于这个"**减**"字：不断地将原问题的规模减小，直到找到最终的解。

## 与分治法的对比

| 特性 | 分治法 | 减治法 |
|------|--------|--------|
| 子问题数量 | 多个，全部求解 | 多个，只解一个 |
| 子问题合并 | 需要合并各子问题的解 | 不需要合并 |
| 典型例子 | 归并排序 | 二分查找 |

## 求解过程

1. 将原问题分解为规模较小的子问题
2. 找到原问题的解所在的子问题
3. 重复 1、2 直到得到子问题的解
4. 根据子问题的解，直接得出或计算出原问题的解

## 经典实例：二分查找

**问题**：在有序数组中找到目标值的位置。

**减治策略**：每次比较中间元素，根据比较结果排除一半的数据，将搜索范围缩小一半。

```java
public static int binarySearch(int[] data, int target) {
    int left = 0, right = data.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 防止溢出
        if (data[mid] == target) return mid;
        else if (data[mid] < target) left = mid + 1;   // 减治：排除左半
        else right = mid - 1;                           // 减治：排除右半
    }
    return -1;
}
```

**时间复杂度**：O(log n)，每次将规模缩小一半。
