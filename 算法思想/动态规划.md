# 动态规划

## 基本思想

动态规划将一个问题分解为若干个互相重叠的子问题，并通过存储子问题的解来避免重复计算，从而大幅提升时间效率。

跟分治有些类似（"**分**"与"**合**"体现在**状态转移方程**），但是通常这些子问题都相互重叠。所以动态规划的重点就是找到这个递推关系，即较小规模问题如何推断出更大问题的解。

## 判断问题是否可用动态规划

**1、最优子结构**：原问题的最优解是从子问题的最优解构建得来的。从状态的角度理解，后面阶段的状态可以由前面阶段的状态推导出来。

**2、无后效性**：给定一个确定的状态，它的未来发展只与当前状态有关，而与过去经历的所有状态无关。各个子问题只与它前面的子问题的解相关。

**3、重叠子问题**：在问题的求解过程中，会反复遇到相同的子问题，解决方法相同。

## 求解过程

**1、划分子问题（定义初始状态）**：将原问题分解为若干个子问题，每个子问题对应一个决策阶段，定义初始状态。

**2、确定动态规划函数（状态转移方程）**：找出最优子结构，找到子问题之间的递推关系，这是动态规划的关键。

**3、填表**：设计表格，自底向上计算各个子问题的解并填写 DP 表。

## 与数学归纳法的关系

动态规划的思想就像数学归纳法：状态转移方程是递推函数，初始状态是归纳基础。

## 举例：爬楼梯（斐波那契数列）

**问题描述**：给定一个共有 n 阶的楼梯，每步可以上 1 阶或者 2 阶，有多少种方案可以爬到楼顶？

**分析**：每轮只能上 1 阶或 2 阶，站在第 i 阶楼梯上时，上一轮只可能站在第 i-1 阶或第 i-2 阶上。

**公式**：dp[i] = dp[i-1] + dp[i-2]，其中 dp[1] = 1, dp[2] = 2

```java
int climbingStairsDP(int n) {
    if (n == 1 || n == 2) return n;
    int[] dp = new int[n + 1];
    dp[1] = 1;
    dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

## 经典实例：01 背包问题

**问题描述**：有 n 个物品，各有体积和价值，给定容量为 V 的背包，如何让背包里装入的物品具有最大价值总和？

### 蛮力法回顾

所有组合情况用二进制表示（如 1=0001 表示第 1 个物品放入），遍历 1 到 2^n 的所有情况。时间复杂度 O(n·2^n)。

### 动态规划解法

定义 `dp[i][j]`：在体积为 j 的情况下，前 i 个物品的最优解。

**状态转移方程**：
```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-Vol(i)] + Val(i))
```

- 不放第 i 个物品：最大价值 = 前 i-1 个物品的最大价值
- 放第 i 个物品：最大价值 = 前 i-1 个物品在体积 j-Vol(i) 的最大价值 + Val(i)

```java
public static int execute(List<Item> itemList, int maxVolume) {
    int[][] dpTable = new int[itemList.size() + 1][maxVolume + 1];
    for (int i = 1; i < itemList.size() + 1; i++) {
        for (int j = 1; j < maxVolume + 1; j++) {
            if (j < itemList.get(i - 1).getVolume()) {
                // 放不下，取前 i-1 个物品在该体积的最大价值
                dpTable[i][j] = dpTable[i - 1][j];
            } else {
                // 放得下，取不放和放中较大值
                dpTable[i][j] = Math.max(dpTable[i - 1][j],
                    dpTable[i - 1][j - itemList.get(i - 1).getVolume()] + itemList.get(i - 1).getValue());
            }
        }
    }
    return dpTable[itemList.size()][maxVolume];
}
```

> 滚动数组优化：将二维 dp 压缩为一维，内层循环**倒序遍历**防止同一物品重复选取。

## 博弈 DP（零和博弈）

博弈 DP 是动态规划在**双人零和博弈**中的应用，核心范式：

```
dp[l][r] = max(拿到的 - 对手在剩下区间的优势)
```

其中 `dp[l][r]` 表示在区间 `[l, r]` 内**当前玩家**相对于对手能领先多少分。由于是零和博弈，对手的优势就是我的劣势，因此状态转移中做减法。

**经典实例：486. 预测赢家**
```java
// dp[l][r] = max(nums[l] - dp[l+1][r], nums[r] - dp[l][r-1])
int[][] dp = new int[n][n];
for (int i = 0; i < n; i++) dp[i][i] = nums[i];
for (int len = 1; len < n; len++) {
    for (int l = 0; l + len < n; l++) {
        int r = l + len;
        dp[l][r] = Math.max(nums[l] - dp[l + 1][r], nums[r] - dp[l][r - 1]);
    }
}
return dp[0][n - 1] >= 0; // 先手至少不输
```

**同类题目**：石子游戏(877)、我能赢吗(464)、石子游戏 VII(1690)
